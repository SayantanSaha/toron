# REQ-022 - HTTP/2 Protocol Server Support and h2c Cleartext Negotiation

## Description

The Toron web server shall support the HTTP/2 binary protocol specification (RFC 7540), including stream multiplexing, header compression (HPACK), and cleartext HTTP/2 (`h2c`) direct/upgrade connections as well as TLS ALPN (`h2`) connections.

The server configuration shall expose HTTP/2 controls (`server.http2.enabled`, `server.http2.max_concurrent_streams`, `server.http2.max_frame_size`, `server.http2.allow_h2c`).

## Acceptance Criteria

- `HTTP2Config` added to `ServerConfig` in `pkg/config/config.go`.
- `pkg/server` detects HTTP/2 connection preface (`PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n`) and handles HTTP/2 streams via `golang.org/x/net/http2`.
- `pkg/server` bridges HTTP/2 requests into `httpparser.Request` / `router.Router` execution chain.
- All Go unit tests pass cleanly.

## Rationale

HTTP/2 delivers significant performance enhancements through single TCP connection multiplexing, header compression, and reduced latency for modern API clients and microservice gateways.
