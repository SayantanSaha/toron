# TC-078 - Verification of Exact-Match Path Exclusion Hardening

## Objective

Verify that `NewAuthMiddleware` and `NewWAFMiddleware` do not disable authentication or threat inspection server-wide when configured with root (`"/"`) or empty (`""`) path exclusions.

## Test Cases

### TC-078-01: Root Exclusion Exemption Boundary
- **Setup**: Configure `AuthMiddleware` with `excluded: ["/"]`.
- **Action 1**: Request `GET / HTTP/1.1`.
- **Expected Outcome 1**: Request is permitted without authentication (status 200).
- **Action 2**: Request `GET /admin/dashboard HTTP/1.1` without credentials.
- **Expected Outcome 2**: Request is rejected with `HTTP 401 Unauthorized`.

### TC-078-02: Empty String Exclusion Ignored
- **Setup**: Configure `AuthMiddleware` with `excluded: [""]`.
- **Action**: Request `GET /api/data HTTP/1.1` without credentials.
- **Expected Outcome**: Request is rejected with `HTTP 401 Unauthorized`.
