# CR-038 - Code Review for Route-Level WAF Overrides and CIDR IP Access Lists

## Scope

Engineering and architecture code review for:
- `pkg/waf/ip_acl.go`
- `pkg/waf/ip_acl_test.go`
- `pkg/waf/waf.go`
- `pkg/waf/middleware.go`
- `pkg/waf/middleware_test.go`
- `pkg/proxy/proxy.go`
- `pkg/router/router.go`
- `pkg/router/router_waf_test.go`
- `cmd/toron/main.go`
- `config.yaml` and `routes.yaml`

## Review Observations

1. **Architecture & Decoupling**:
   - `pkg/waf` defines its own `HandlerFunc` and `MiddlewareFunc`, cleanly avoiding circular dependency with `pkg/router`.
   - Thread safety is guaranteed via `sync.RWMutex` on `WAFEngine`.

2. **Performance & Memory**:
   - Pre-parsed `*net.IPNet` slices avoid parsing CIDRs per request.
   - Stack-allocated `net.IP` checks introduce zero runtime heap allocation in hot paths.

3. **Test Coverage**:
   - Unit tests verify CIDR allowlists, denylists, IPv6 subnets, invalid inputs, IP extraction, and route-level rule bypassing.
   - 100% test pass rate across all packages (`go test ./...`).

## Verdict

**PASSED - Code is clean, maintainable, idiomatic, and approved for merge.**
