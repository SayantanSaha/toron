# TC-057 - Verification of HTTP-to-HTTPS Redirection and Route-Level Exemption Overrides

## Objective

Verify that Toron's auxiliary cleartext HTTP listener correctly redirects non-exempt requests to HTTPS with `HTTP 301 Moved Permanently` while allowing routes configured with `redirect_http: false` to be served directly over HTTP without redirection.

## Test Cases

### TC-057-01: Global Configuration Deserialization & Defaults
- **Input**:
  ```yaml
  server:
    http_redirect:
      enabled: true
      port: 8080
  ```
- **Action**: Parse configuration through `config.LoadFromBytes`.
- **Expected Outcome**:
  - `cfg.Server.HTTPRedirect.Enabled` is `true`.
  - `cfg.Server.HTTPRedirect.Port` is `8080`.
  - When port is omitted or `<= 0`, default port `80` is assigned.

### TC-057-02: Route-Level `redirect_http: false` Exemption Parsing
- **Input**:
  ```yaml
  routes:
    - type: "static"
      prefix: "/.well-known/acme-challenge"
      dir: "/var/www/challenges"
      redirect_http: false
    - type: "static"
      prefix: "/app"
      dir: "/var/www/app"
  ```
- **Action**: Parse `routes.yaml` through `config.LoadRoutesFromBytes`.
- **Expected Outcome**:
  - First route has `RedirectHTTP != nil` and `*RedirectHTTP == false`.
  - Second route has `RedirectHTTP == nil`.

### TC-057-03: HTTP-to-HTTPS 301 Redirection on Non-Exempt Route
- **Setup**: Auxiliary HTTP server running with router containing static route `/app` (default redirect behavior).
- **Request**: `GET /app/dashboard?user=123 HTTP/1.1`, `Host: example.com`.
- **Expected Outcome**:
  - Status: `HTTP/1.1 301 Moved Permanently`.
  - Header `Location`: `https://example.com/app/dashboard?user=123`.
  - Header `Content-Length`: `0`.
  - Query parameters and nested paths are strictly preserved.

### TC-057-04: Route-Level Exemption Direct Serving (`redirect_http: false`)
- **Setup**: Route `/exempt` configured with `redirect_http: false` pointing to a directory containing `token.txt` (`payload: challenge-data`).
- **Request**: `GET /exempt/token.txt HTTP/1.1`, `Host: example.com`.
- **Expected Outcome**:
  - Status: `HTTP/1.1 200 OK`.
  - Content: `challenge-data`.
  - No `Location` header or 301 redirection occurred.

### TC-057-05: Host Header Normalization & Port Stripping
- **Setup**: Request sent to HTTP redirect listener on port 8080 with explicit port in Host header.
- **Request**: `GET /login HTTP/1.1`, `Host: example.com:8080`.
- **Expected Outcome**:
  - `Location`: `https://example.com/login` (port `8080` stripped from redirect host).

### TC-057-06: Prevention of Open Redirect and CRLF Injection (Security)
- **Setup**: Malicious request with CRLF injection in Host header:
  `Host: example.com\r\nSet-Cookie: malicious=true`.
- **Expected Outcome**:
  - Server detects malicious characters and rejects with `HTTP 400 Bad Request`.
  - No response splitting or unauthorized redirect target allowed.

### TC-057-07: Graceful Shutdown Lifecycle
- **Setup**: Primary TLS server and auxiliary HTTP redirect server started concurrently.
- **Action**: Trigger context cancellation / shutdown signal.
- **Expected Outcome**:
  - Both listeners close cleanly within timeout.
  - No lingering sockets or leaked goroutines.
