# SR-005 - Security Review of Header-Based Routing Module

## Description

Security analysis of header matching logic, header spoofing mitigations, and fallback routing order.

## Scope

- Files reviewed:
  - `pkg/router/router.go`
  - `pkg/router/router_test.go`
  - `pkg/config/config.go`
  - `cmd/toron/main.go`

## Findings

### Finding 1: Canonical Case-Insensitive Header Comparison

- Severity: Informational
- Location: `pkg/router/router.go:275`
- Related requirement: `REQ-010`
- Description: `headersMatch` queries request headers via `httpparser.Header.Get(key)`, which normalizes keys to lowercase per RFC 7230 standards.
- Impact: Mitigates header casing spoofing exploits (e.g. `x-version` vs `X-Version`).

### Finding 2: Safe Priority Fallback to Default Handler

- Severity: Informational
- Location: `pkg/router/router.go:235`
- Related requirement: `REQ-010`
- Description: When an incoming request contains unrecognized header values, the router falls back to unconditioned default routes or `404 Not Found`.

## Rationale

Implementation passes all security requirements.
