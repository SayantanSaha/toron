# TC-055: Test Cases for Centralized Version Tracking

## Test Cases

### TC-055.1: Package Version Functions
- **Action**: Call `version.Get()`, `version.Full()`, and `version.Info()` in unit tests.
- **Expected**: Returns valid semantic version strings containing version, commit hash, and build timestamp.

### TC-055.2: CLI Version Flag
- **Action**: Execute `./bin/toron -v` and `./bin/toron -version`.
- **Expected**: Program prints `Toron Edge Gateway v1.5.0 ...` and exits with code 0 without starting server sockets.

### TC-055.3: API Version Output
- **Action**: Query `GET /internal/api/status` and `GET /api/status`.
- **Expected**: JSON responses reflect the exact centralized version from `pkg/version`.
