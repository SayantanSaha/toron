# TC-050: Test Cases for Advanced Load Balancing Engine

## Test Cases

### TC-050-1: Weighted Round-Robin Distribution
- **Target**: `WeightedRoundRobinBalancer`
- **Setup**: 3 targets with weights A=5, B=1, C=1.
- **Action**: Issue 7 sequential `Next()` requests.
- **Expected Outcome**: Targets selected in ratio 5:1:1 without burst clustering (smooth Nginx algorithm).

### TC-050-2: Least Connections Selection
- **Target**: `LeastConnBalancer`
- **Setup**: Target 1 (`ActiveConns=3`), Target 2 (`ActiveConns=1`), Target 3 (`ActiveConns=5`).
- **Action**: Call `Next()`.
- **Expected Outcome**: Target 2 is selected (`ActiveConns=1`).

### TC-050-3: Weighted Least Connections Selection
- **Target**: `WeightedLeastConnBalancer`
- **Setup**: Target 1 (`ActiveConns=4, Weight=2 -> load=2.0`), Target 2 (`ActiveConns=6, Weight=6 -> load=1.0`).
- **Action**: Call `Next()`.
- **Expected Outcome**: Target 2 is selected (lower relative ratio `1.0 < 2.0`).

### TC-050-4: Lowest Response Latency Selection
- **Target**: `LeastLatencyBalancer`
- **Setup**: Target 1 (`AvgLatencyUS=15000`), Target 2 (`AvgLatencyUS=2000`).
- **Action**: Call `Next()`.
- **Expected Outcome**: Target 2 is selected (`2ms < 15ms`).

### TC-050-5: Concurrency Safety & Active Connection Lifecycle
- **Target**: `ReverseProxy.ServeHTTP`
- **Setup**: Launch 50 concurrent goroutines against proxy endpoint.
- **Action**: Verify `ActiveConns` increments during request and decrements to `0` upon completion.
- **Expected Outcome**: All atomic operations complete cleanly with zero race conditions (`go test -race`).
