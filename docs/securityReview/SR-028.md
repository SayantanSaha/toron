# SR-028 - Security Review of ACME HTTP-01 & TLS-ALPN-01 Zero-Touch SSL Provisioning Engine

## Scope

Security audit of ACME account key storage ([`pkg/acme/acme.go`](file:///D:/Work/server/pkg/acme/acme.go)), HTTP-01 key authorization thumbprint calculation, TLS-ALPN-01 certificate generation (`acme-tls/1`), and disk certificate caching permissions.

## Findings

1. **Account Key Permissions**: Account private keys and issued certificates are written to disk (`cache_dir`) with strict POSIX `0600` / `0700` file permissions, preventing unauthorized access by local processes.
2. **JWK Thumbprint Standards**: `AccountKeyThumbprint` conforms strictly to RFC 7638 (JSON Web Key Thumbprint) and RFC 8555 (ACME), computing SHA-256 digests over normalized EC P-256 public key fields.
3. **TLS-ALPN-01 Isolation**: Challenge certificates contain the critical X.509 extension OID `1.3.6.1.5.5.7.1.31` and are served exclusively when `acme-tls/1` ALPN is explicitly negotiated in TLS Client Hello handshakes.

## Conclusion

Approved. No security vulnerabilities identified.
