## 2. Threat Modeling & Boundary Assessment

1. **RFC 7230 §6.1 Conformance (Hop-by-Hop Headers)**:
   Filtering `hopByHopHeaders` (`Connection`, `Keep-Alive`, `Proxy-Authenticate`, `Proxy-Authorization`, `TE`, `Trailers`, `Transfer-Encoding`, `Upgrade`) ensures upstream servers cannot inject hop-by-hop control directives that compromise downstream proxy-to-client connection state (CWE-444 mitigation).
2. **CRLF Injection Prevention (CWE-117)**:
   The fast-path `strings.IndexByte(s, '\r') == -1 && strings.IndexByte(s, '\n') == -1` strictly guarantees that any header containing carriage returns or newlines is directed to `headerReplacer.Replace(s)`, preserving complete defense against HTTP response splitting.
3. **Denial of Service via Socket Exhaustion (CWE-400)**:
   Enabling `MaxIdleConnsPerHost: 1000` with `IdleConnTimeout: 90s` and `KeepAlive: 60s` prevents ephemeral port exhaustion and TIME_WAIT socket buildup under high-rate saturation.
