# TC-039 - Per-Host Dynamic SNI Certificate Mapping & mTLS Verification

## Test Objectives

1. Verify `RegisterHostProfile` correctly parses and maps `cert_file`, `key_file`, and `ca_file`.
2. Verify `GetConfigForClient` returns the dedicated certificate when connecting with `ServerName: "siteA.local"`.
3. Verify `GetConfigForClient` returns a different dedicated certificate when connecting with `ServerName: "siteB.local"`.
4. Verify fallback to default certificate when connecting with unknown `ServerName`.
5. Verify mutual TLS (mTLS): client with valid certificate signed by `ca_file` completes handshake successfully.
6. Verify mutual TLS (mTLS): client without certificate or with untrusted certificate is rejected during TLS handshake when `client_auth: "require_and_verify"`.
7. Verify per-host `min_version: "tls1.3"` rejects TLS 1.2 client handshakes on that specific host.
