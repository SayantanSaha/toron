# TC-005 - Server Integration, Health Endpoint & Graceful Shutdown Verification

## Description

Verify end-to-end server operation including configuration boot, endpoint routing for `/health`, and clean shutdown behavior.

## Preconditions

- Server running on `127.0.0.1:8080` (or dynamic free port).

## Test Data

- HTTP GET request to `http://127.0.0.1:<port>/health`.

## Steps

1. Launch Toron server.
2. Issue HTTP GET to `/health`.
3. Assert response status `200 OK` and body `{"status":"ok"}`.
4. Signal shutdown.
5. Verify server stops listening and exits cleanly with 0 status code.

## Expected Results

- Health endpoint returns `200 OK`.
- Server shuts down without error or hung processes.

## Acceptance Criteria

- End-to-end integration test passes.

## Rationale

Validates complete system assembly.

## Constraints

- End-to-end integration test in `pkg/server` or `cmd/toron`.
