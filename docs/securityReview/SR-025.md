# SR-025 - Security Review of Sticky Session Load Balancing (sticky_cookie & ip_hash)

## Scope

Security audit of cookie-based session affinity ([`StickyCookieBalancer`](file:///D:/Work/server/pkg/proxy/sticky.go)), client IP hashing ([`IPHashBalancer`](file:///D:/Work/server/pkg/proxy/sticky.go)), target identifier hashing (`TargetHash`), cookie security flags (`HttpOnly`, `Path=/`), and unhealthy target failover.

## Findings

1. **Target Hash Obfuscation**: Sticky cookie values store a non-reversible FNV-32 hash hex representation (`TargetHash`) rather than raw backend internal IP addresses or hostnames, preventing internal network disclosure to external clients.
2. **Cookie Security Attributes**: `Set-Cookie` headers enforce `HttpOnly` and `Path=/` attributes to prevent client-side JavaScript manipulation or cross-site scripting (XSS) cookie theft.
3. **Unhealthy Node Failover**: If a pinned sticky target fails active health probes or trips the Circuit Breaker (`StateOpen`), the balancer automatically bypasses the failing node and re-routes requests to a healthy target.

## Conclusion

Approved. No security vulnerabilities identified.
