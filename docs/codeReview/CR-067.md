# CR-067 - Code Review of Connection State Integrity and Hop-by-Hop Stripping

## Description

Engineering code review of `TASK-071` implementation across `pkg/proxy/proxy.go`, `pkg/config/config.go`, `cmd/toron/main.go`, and `pkg/proxy/proxy_test.go`.

## Scope

- Files reviewed:
  - `pkg/proxy/proxy.go`
  - `pkg/config/config.go`
  - `cmd/toron/main.go`
  - `pkg/proxy/proxy_test.go`

## Key Observations & Review Findings

1. **RFC 7230 §6.1 Header Compliance**:
   - Standard hop-by-hop headers (`Connection`, `Keep-Alive`, `Proxy-Authenticate`, `Proxy-Authorization`, `TE`, `Trailers`, `Transfer-Encoding`, `Upgrade`) are removed upfront.
   - Dynamic tokens declared in `req.Header.Get("Connection")` are safely tokenized, trimmed, and removed via `req.Header.Del(...)`.
2. **Robust TLS and Socket Inspection**:
   - `isTLSConnection` accurately distinguishes `*tls.Conn` or interface implementing `ConnectionState()` from cleartext sockets.
   - `isPeerTrusted` verifies caller remote IP against parsed `net.IPNet` CIDRs and direct IP subnets.
3. **Correct Ingress Header Rewriting**:
   - If peer is untrusted: client `X-Forwarded-Proto` is replaced by actual socket TLS state (`https` or `http`), and `X-Forwarded-For` / `X-Real-IP` are reset to `remoteIP`.
   - If peer is trusted: preserves incoming `X-Forwarded-Proto` and appends `remoteIP` to existing `X-Forwarded-For`.
4. **Testing and Race Detector Verification**:
   - Unit tests verify hop-by-hop removal, anti-spoofing for untrusted connections, and chained forwarding for trusted proxies.
   - `go test -race ./pkg/proxy/...` executes with zero race conditions and zero memory leaks.

## Verdict

Approved. Ready for commit.
