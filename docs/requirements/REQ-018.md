# REQ-018 - Configurable Static Path Prefix and Relative Asset Resolution

## Description

The Toron web server static site engine and frontend dashboard assets shall support configurable path prefixes (such as `prefix: "/internal/dashboard"` in `config.yaml`). The frontend HTML, CSS, and JS assets shall use relative paths (`./style.css`, `./app.js`) to resolve correctly under any static prefix. Additionally, the router static handler shall automatically redirect requests missing trailing slashes (`/internal/dashboard` $\rightarrow$ `/internal/dashboard/`) to ensure proper browser relative URL resolution.

## Acceptance Criteria

- `public/index.html` updated to use relative asset links (`./style.css` and `./app.js`).
- `pkg/router/router.go` static handler redirects requests matching `cleanPrefix` without trailing slash to `cleanPrefix + "/"`.
- Dashboard functionality works identically when served under `/` or under subpath prefixes like `/internal/dashboard`.
- All Go unit tests pass cleanly.

## Rationale

Allows mounting the dashboard under custom subpath prefixes without breaking stylesheet and script loading.
