# TC-075 - Verification of Stored DOM-based XSS Mitigation in Dashboard

## Objective

Verify that `public/app.js` contextually sanitizes all user-controlled variables before rendering them into table elements, preventing JavaScript execution from stored audit logs and container labels.

## Test Cases

### TC-075-01: Malicious XSS Payload in WAF Incident Path
- **Setup**: Inject an incident with `path: "/<script>alert(1)</script>?union+select"`.
- **Action**: Invoke `fetchIncidentLogs()` to render rows into `#incidents-tbody`.
- **Expected Outcome**:
  - Script tags render as literal text (`&lt;script&gt;alert(1)&lt;/script&gt;`).
  - No JavaScript execution occurs in the DOM.

### TC-075-02: HTML Tag Injection in Container Label
- **Setup**: Provide a route with `container_name: "<img src=x onerror=alert(2)>"`.
- **Action**: Render route cards via `updateRoutesTable()`.
- **Expected Outcome**:
  - Image tag renders harmlessly as sanitized text.
