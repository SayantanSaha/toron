# TC-051: Test Cases for Universal Auto-Installer (`install.sh`)

## Test Cases

### TC-051.1: Syntax & Privilege Validation
- **Action**: Run `bash -n install.sh` and execute `./install.sh` without root privileges.
- **Expected**: `bash -n` returns 0 syntax errors. Running without `sudo` halts with clear error message.

### TC-051.2: OS & Arch Auto-Detection
- **Action**: Run `install.sh` on macOS ARM64 system.
- **Expected**: Correctly detects `darwin` and `arm64`, resolving `toron-darwin-arm64`.

### TC-051.3: Uninstallation Teardown (`--uninstall`)
- **Action**: Execute `sudo ./install.sh --uninstall`.
- **Expected**: Stops services, removes `/usr/local/bin/toron`, `/etc/toron`, and service files.
