# REQ-041 - Core Web Application Firewall Engine and OWASP Injection Protection Middleware

## Description

The Toron web server and edge reverse proxy gateway shall implement a modular, high-performance **Web Application Firewall (WAF)** middleware (`pkg/waf`) to inspect incoming HTTP requests and intercept Layer 7 security threats (OWASP Top 10) before they can reach application routing handlers or upstream backend microservices.

The WAF subsystem shall provide:

1. **WAF Engine Core & Rule Evaluation**:
   - `mode`: Configurable evaluation mode—`enforce` (immediately blocks malicious requests with HTTP `403 Forbidden`) or `detection` (logs anomaly threat score and sets diagnostic headers without blocking).
   - `anomaly_threshold`: Threat score limit above which an HTTP request is blocked.
   - `custom_rules`: Support for custom pattern matching rules defined in YAML configuration.
2. **OWASP Top 10 Injection Protection Rule Set**:
   - **SQL Injection (SQLi)**: Pattern detection targeting SQL syntax manipulation (`UNION SELECT`, `INSERT INTO`, `DROP TABLE`, `--`, `' OR '1'='1`).
   - **Cross-Site Scripting (XSS)**: Vector detection targeting script injection (`<script>`, `javascript:`, `onerror=`, `onload=`, `eval()`).
   - **Path Traversal / Local File Inclusion (LFI)**: Path normalization and pattern matching targeting directory traversal (`../`, `%2e%2e/`, `/etc/passwd`, `file://`).
   - **Command Injection / Remote Code Execution (RCE)**: Pattern detection targeting OS command execution (`/bin/sh`, `; system(`, `| bash`, backtick execution).
3. **Multi-Location Inspection**:
   - Inspects request URL paths, raw query strings, HTTP request headers (User-Agent, Referer, Cookie, Authorization), and JSON/Form request bodies.
4. **Configuration Integration**:
   - Embeds into `ServerConfig` in `config.yaml` (`server.waf`) and supports granular route-level overrides in `routes.yaml` (`routes[].waf`).
5. **Zero-Allocation & Performance Bounding**:
   - Pre-compiled regex patterns, short-circuit evaluation on early matches, and configurable inspection body limit (`max_inspect_body_size`).

## Acceptance Criteria

- Incoming HTTP requests containing SQLi, XSS, Path Traversal, or RCE payloads are intercepted with `403 Forbidden` in `enforce` mode.
- In `detection` mode, malicious requests pass through to handlers with `X-Toron-WAF-Anomaly-Score` and audit log entries generated.
- Whitelisted URLs and benign requests pass through WAF inspection without performance degradation or false positives.
- WAF configuration can be defined globally in `config.yaml` and overridden per route in `routes.yaml`.
- All Go unit tests pass cleanly (`go test ./...`).
