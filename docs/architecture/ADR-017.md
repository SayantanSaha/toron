# ADR-017 - HTTP/2 Protocol Multiplexing and h2c Cleartext Server Architecture

## Context

To support high-concurrency stream multiplexing and modern gRPC/HTTP2 client workloads, Toron needs HTTP/2 protocol support alongside its existing event-driven HTTP/1.1 engine.

## Decision

1. **Protocol Auto-Negotiation**:
   - For TCP connections, inspect initial 24 bytes for HTTP/2 client connection preface magic (`PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n`).
   - If HTTP/2 preface is detected and `http2.enabled` is true, pass the connection to `http2.Server.ServeConn`.
2. **HTTP/2 to Router Bridge**:
   - `http2.Server` executes an `http.Handler` wrapper that converts `net/http` HTTP/2 requests into Toron `httpparser.Request` and `httpparser.Response` objects, then dispatches them to `s.router.ServeHTTP`.
3. **h2c & TLS ALPN Support**:
   - Cleartext HTTP/2 (`h2c`) direct preface detection is supported by default when `http2.enabled` is true.

## Consequences

- **Positive**: Native HTTP/2 performance and stream multiplexing fully integrated with Toron's router, reverse proxy, and control center.
