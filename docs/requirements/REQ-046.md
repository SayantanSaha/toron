# REQ-046 - Vendor-Agnostic OCI Container Auto-Discovery Engine

## Description

Toron Edge Gateway MUST provide a vendor-agnostic OCI container auto-discovery engine (`pkg/discovery`) capable of auto-detecting and dynamically routing traffic to containerized upstream microservices running under Docker Engine, Podman, Finch, or Nerdctl without external SDK dependencies.

## Acceptance Criteria

1. **Zero External Dependencies**: The engine MUST communicate with container runtime Unix domain sockets (`unix://`) using Go stdlib `net` and `net/http` packages only.
2. **Auto-Detection**: The engine MUST automatically probe standard socket locations (`/var/run/docker.sock`, `/run/podman/podman.sock`, rootless Podman sockets) if socket path is omitted or set to `"auto"`.
3. **Unified Label Taxonomy**: The engine MUST parse `toron.enable`, `toron.host`, `toron.prefix`, `toron.port`, `toron.weight`, and `toron.health_check` container labels.
4. **Real-Time Lifecycle Watching**: The engine MUST listen to container event streams (`start`, `die`, `stop`) and dynamically register/deregister upstreams in `router.Router` with zero downtime.
