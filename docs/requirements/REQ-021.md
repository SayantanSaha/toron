# REQ-021 - Configuration File Syntax Testing and Dry-Run CLI Flag (-test-config)

## Description

The Toron server CLI shall provide a configuration testing option (`-test-config` and short alias `-t`) to validate syntax, YAML structure, network ports, timeout values, target URL schemas, load balancing algorithms, and static directory settings without launching the server or binding network sockets.

## Acceptance Criteria

- CLI flags `-test-config` and `-t` supported in `cmd/toron/main.go`.
- Strict validation function `ValidateConfig(cfg *AppConfig) error` in `pkg/config`:
  - Validates port numbers ($1 \le \text{port} \le 65535$).
  - Validates static directory existence.
  - Validates upstream proxy targets for valid `http://` or `https://` URLs.
  - Validates proxy load balancing algorithm names (`round_robin`, `random`).
- When `-t` / `-test-config` is specified:
  - If valid: Prints `[TORON] Configuration syntax OK` and exits with code `0`.
  - If invalid: Prints `[TORON] Configuration syntax ERROR: <details>` and exits with code `1`.
- All Go unit tests pass cleanly.

## Rationale

Allows CI/CD deployment pipelines, system administrators, and developers to verify configuration file syntax prior to service deployment or restarting live servers.
