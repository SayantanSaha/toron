# SR-014 - Security Review of Dual-File YAML Configuration Loading

## Scope

Security assessment of splitting server configuration into `config.yaml` and `routes.yaml`.

## Findings

1. **Separation of Concerns**: Separating infrastructure settings (`server`, `static`) from proxy routing rules (`routes.yaml`) reduces the risk of accidental server configuration mutation during route updates.
2. **File Validation**: `pkg/config` validates file paths, extensions (`.yaml`, `.yml`), and bounds checking for server ports, header sizes, and body limits.

## Conclusion

Approved. No security issues identified.
