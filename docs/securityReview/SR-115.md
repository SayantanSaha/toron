## 2. Threat Vector Fidelity & Empirical Defect Breakdown

The ablation experiment suite models and evaluates the vulnerability lifecycle across 10 critical systems programming tasks. The empirical findings reveal a stark divergence in security posture between the two conditions:

| Task ID | Target Vulnerability | Condition A (ADR Multi-Agent) | Condition B (Direct Single-Agent) | Critical Security Finding |
| :--- | :--- | :---: | :---: | :--- |
| `TASK-061` | CWE-444 (Request Smuggling) | **0 Defects** (2 arrested by CR/SR) | **2 Defects Injected** | Baseline omitted socket teardown (`conn.Close()`), allowing unread chunk bytes to desynchronize subsequent pipelined requests. |
| `TASK-062` | CWE-306 (API Authorization) | **0 Defects** (1 arrested by SR) | **1 Defect Injected** | Baseline verified bearer token but completely omitted RemoteAddr IP CIDR filtering, leaving management endpoints exposed to the public Internet. |
| `TASK-063` | CWE-525 (Cache Information Leak) | **0 Defects** (2 arrested by CR/SR) | **2 Defects Injected** | Baseline cached responses verbatim without stripping `Set-Cookie` headers, causing session token leakage between distinct clients. |
| `TASK-064` | CWE-770 (Resource Exhaustion) | **0 Defects** (2 arrested by CR/SR) | **3 Defects Injected** | Baseline omitted periodic TTL eviction routine, causing permanent memory retention under IP spoofing and data races during concurrent scans. |
| `TASK-065` | CWE-295 (Improper Cert Validation) | **0 Defects** (1 arrested by SR) | **2 Defects Injected** | Baseline hardcoded `InsecureSkipVerify: true` in WebSocket dialers, exposing upstream proxy traffic to Man-in-the-Middle certificate spoofing. |

## 3. Security Analyst Findings & Insights

1. **Catastrophic Defect Survival in Direct Prompting**:
   In Condition B, every single evaluated task introduced at least one critical or high-severity security vulnerability (mean $1.90$ defects per task). Large language models, when prompted without formal architectural contracts, prioritize the happy-path functional implementation and systematically omit defensive systems programming invariants (e.g., connection teardown, memory bounds, input canonicalization, certificate validation).
2. **100% Pre-Merge Flaw Arrest by Adversarial Roles**:
   In Condition A, all 15 latent defects introduced during initial draft development were intercepted and arrested by the parallel Code Reviewer (`CR`) and Security Analyst (`SR`) roles prior to merging. This empirical evidence validates the hypothesis that adversarial multi-agent review gates are indispensable for safety-critical systems software.
3. **Governance Cost Justification**:
   The token expenditure ratio of 3.29x ($\text{Cost}_A / \text{Cost}_B$) represents a defensible operational trade-off: in production edge infrastructure, preventing a single CWE-444 desynchronization or CWE-525 credential leakage far outweighs the nominal API cost of multi-agent validation.
