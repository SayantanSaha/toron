# ADR-011 - Mobile-First Control Center and Frontend Observability Architecture

## Context

Toron requires a modern, responsive Web Control Center and Proxy Dashboard hosted directly by the static site engine (`./public`) to visualize upstreams, load balancing, health metrics, and proxy routing rules.

## Decision

1. **Tech Stack**: Standard HTML5, Vanilla JavaScript (Fetch API & DOM management), and Tailwind CSS v4 compiled using `@tailwindcss/cli`.
2. **Mobile-First Layout**:
   - Mobile: Fixed bottom tab bar (`fixed bottom-0 left-0 right-0 z-50 md:hidden`).
   - Desktop: Top header bar with tab navigation (`hidden md:block`).
3. **Observability & Probing**:
   - Client-side active HTTP probing to `http://localhost:${port}/` for real-time upstream status determination (`CLOSED` for 200 OK, `OPEN (500 ERR)` for $\ge 500$, `UNREACHABLE` for connection errors).
4. **CORS Support**:
   - Dummy services emit `Access-Control-Allow-Origin: *` to enable browser cross-origin health probing.

## Consequences

- **Positive**: High performance, zero runtime node dependencies, clean mobile-first visual experience.
