# TC-135 - Verification Suite for Next-Generation Observability Dashboard, Time-Series Telemetry Engine, and Circular Tracing

## 1. Test Suite Overview

This test suite verifies:
1. **Time-Series Metric Collection**: Verifies that `TimeSeriesCollector` records 60-bucket rolling snapshots with accurate p50/p95/p99 latency calculations, RPS, and error breakdowns.
2. **Circular Request Tracing**: Verifies that circular trace buffers record request lifecycle spans without exceeding allocated capacity or leaking memory.
3. **Internal API Telemetry Endpoints**: Verifies that `/internal/api/status` and `/internal/api/metrics` serialize telemetry, certificate metadata, and runtime diagnostics under administrative authentication.
4. **Security & Escaping**: Verifies that all dynamic fields rendered in the UI are properly escaped to prevent DOM XSS (CWE-79).
5. **Static Asset Integrity**: Verifies that `public/index.html`, `public/style.css`, and `public/app.js` are properly served by `/internal/dashboard/` and execute with zero external script errors.

---

## 2. Test Cases

### TC-135-01: Time-Series Ring Buffer Accuracy & Bounded Capacity
- **Action**: Emit 500 requests across multiple simulated seconds into `TimeSeriesCollector`.
- **Expected Outcome**: Buffer length never exceeds 60 items; rolling window advances accurately; latency percentiles match recorded observations.

### TC-135-02: Circular Request Trace Buffer Overflow & Lock-Free Recycling
- **Action**: Record 1,000 request traces through `RecordTrace()`.
- **Expected Outcome**: Buffer wraps around cleanly at 300 entries; oldest traces are overwritten without race conditions or memory growth.

### TC-135-03: Internal API Telemetry Serialization & Admin Access Control
- **Action**: Query `GET /internal/api/status` with and without admin credentials.
- **Expected Outcome**: Unauthenticated queries receive 401/403 when configured; authorized requests receive JSON payload containing version, runtime stats, certificate telemetry, discovery metadata, and time-series summaries.

### TC-135-04: Static Dashboard UI Serving & Route Asset Resolution
- **Action**: Issue `GET /internal/dashboard/`, `GET /internal/dashboard/style.css`, and `GET /internal/dashboard/app.js`.
- **Expected Outcome**: Returns HTTP 200 OK with correct `Content-Type` headers and complete file bodies.
