# TC-042 - Protocol Integrity & Request Smuggling Guard Verification

## Test Objectives

1. **HTTP Request Smuggling Prevention**: Verify requests containing both `Content-Length` and `Transfer-Encoding` headers return `400 Bad Request`.
2. **Control Character Filtering**: Verify requests with control characters (`\x00`, `\x07`, `\x1b`, `\x7f`) in URL paths, query parameters, or header names/values return `400 Bad Request`.
3. **Header Value Size Bounding**: Verify request header values exceeding `max_header_value_bytes` return `413 Payload Too Large`.
4. **Query & Parameter Size Bounding**: Verify query parameters exceeding `max_param_bytes` return `413 Payload Too Large`.
5. **Per-Route Body Size Bounding**: Verify route-level `max_body_bytes` limits block oversized request bodies with `413 Payload Too Large`.
6. **Compliant Pass-Through**: Verify benign, RFC-compliant requests pass protocol integrity verification cleanly.
