# REQ-016 - Mobile-First Control Center and Proxy Dashboard UI

## Description

The `/public` directory frontend shall be upgraded to a responsive, mobile-first Web Control Center and Proxy Dashboard built with HTML5, Vanilla JavaScript, and Tailwind CSS. The dashboard shall display static site hosting details, proxy upstreams, routing rules, load balancing algorithms, real-time HTTP health status, circuit breaker states, and an interactive API request tester.

## Acceptance Criteria

- Hosted in `/public` directory (`index.html`, `style.css`, `app.js`, `input.css`).
- Built using Mobile-First design principles with a bottom sticky navigation bar on mobile screens and top header + tabbed navigation on desktop.
- Displays core server runtime metrics (uptime, port 8080, worker pool size 128 threads).
- Displays active proxy upstreams with header matching rules and load balancing algorithm badges.
- Displays static file hosting status and served file manifest.
- Executes real-time HTTP probes to upstream targets and correctly flags 500 Internal Server Errors (`OPEN (500 ERR)`) and connection failures (`UNREACHABLE`).
- Features an interactive Live API & Proxy Route Composer with real-time latency calculation in milliseconds and JSON response preview.
- Compiled using Tailwind CSS CLI into `/public/style.css`.

## Rationale

Replaces the initial landing card with a full-featured observability control panel for Toron.
