# ADR-027 - Internal Control Plane JSON Metrics Architecture

## Context

While Prometheus text format (`/metrics`) is scraped by external monitoring agents, the Web Control Dashboard served on `/internal/dashboard/` requires native JSON responses (`/internal/api/status`, `/internal/api/metrics`) to visualize system health, active connections, and traffic metrics.

## Decision

1. **Metrics Summary Extractor (`pkg/metrics/metrics.go`)**:
   - `GetSummaryJSON()` aggregates current counter maps (`requestCounters`, `circuitBreakerTrips`, `activeQUICStreams`, `activeTCPConnections`) into a thread-safe Go map structure for JSON serialization.

2. **Control Plane Endpoints (`pkg/server/internal_api.go`)**:
   - `GET /internal/api/status`: Includes high-level server stats and embedded `metrics` JSON summary object.
   - `GET /internal/api/metrics`: Dedicated JSON endpoint returning full telemetry metrics breakdown.

## Consequences

- **Positive**: Native JSON integration for Web Control Center and REST management tools without third-party parsing.
- **Consistency**: Metrics exported in JSON align 1-to-1 with Prometheus text metrics.
