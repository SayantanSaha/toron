## 2. Key Code Findings & Verifications

1. **Clean Hierarchical Resolution**:
   - `ResolveTransport` in `pkg/config/config.go` correctly prioritizes route-level overrides over global `config.yaml` settings, which in turn override base preset defaults.
   - Pointer booleans (`*bool`) for `DisableCompression`, `UseEnvProxy`, `PropagateUpstreamClose`, and `ForceAttemptHTTP2` enable distinguishing between an explicit `false` and an unset field.
2. **Safe Dynamic Transport Factory**:
   - In `pkg/proxy/proxy.go`, `NewProxyWithOptions` builds `http.Transport` dynamically using resolved settings while retaining 64KB read/write buffers.
   - Proxy dialer correctly dispatches between `ProxyURL` (explicit static forward proxy), `UseEnvProxy: true` (`http.ProxyFromEnvironment`), and `nil` (direct dial for raw speed).
3. **Upstream Close Propagation**:
   - When `PropagateUpstreamClose: true` is configured and origin signals `Connection: close`, Toron sets `Connection: close` on the downstream response while continuing to filter RFC 7230 hop-by-hop headers, isolating framing while allowing clean socket termination.
4. **Verification Test Coverage**:
   - Tests cover raw speed defaults, custom pool limits, explicit forward proxies, upstream close propagation, transparent decompression, and concurrency backpressure throttling.
