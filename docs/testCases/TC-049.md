# TC-049 - Test Suite for REST-to-gRPC Transcoding Engine

## Test Objectives

Verify that `pkg/transcoder` correctly parses REST path parameters, encodes gRPC 5-byte wire frames, forwards gRPC requests, and maps gRPC trailers to HTTP status codes.

## Test Cases Executed

1. **`TestGRPCWireFraming`**:
   - Verify gRPC 5-byte prefix encoding (`[0x00][length]`) and decoding.
2. **`TestPathParameterExtraction`**:
   - Verify extracting `:id` from `/v1/users/123` into JSON `{"id":"123"}`.
3. **`TestGRPCStatusMapping`**:
   - Verify mapping `grpc-status: 0` to 200, `grpc-status: 5` to 404, and `grpc-status: 16` to 401.
4. **`TestRESTToGRPCTranscoderEngine`**:
   - Issue `GET /v1/users/123` through TranscoderEngine to a mock gRPC backend, verifying wire frame receipt and JSON response output.
5. **Race Detector Validation**:
   - Run `go test -v -race ./pkg/transcoder/...`
