# SR-047: Security Review for Prefix Management & Redirect/Cookie Rewriting

## Status
Approved

## Security Controls
- **Open Redirect Protection**: `RewriteRedirectLocation` strictly distinguishes between internal backend URLs (matching `targetURL.Host`) and external URLs (such as OAuth / SSO providers). External domains are never tampered with or redirected back to the gateway.
- **Cross-Route Cookie Isolation**: `RewriteCookiePath` rewrites root `Path=/` session cookies to `Path=<prefix>`, preventing ambient session leakage across independent microservices hosted on the same domain.
- **Protocol Downgrade Prevention**: Respects `X-Forwarded-Proto` and client TLS state to ensure redirects preserve secure `https://` schemes.
