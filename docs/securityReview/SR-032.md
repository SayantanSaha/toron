# SR-032 - Security Review of Brotli and Zstandard Streaming Response Compression

## Scope

Security assessment of Brotli and Zstandard streaming compression in [`pkg/router/compression.go`](file:///D:/Work/server/pkg/router/compression.go), `sync.Pool` memory boundaries, quality weight parsing, and BREACH mitigation posture.

## Findings

1. **Memory Bounds & Leak Prevention**: All pooled encoders (`brotliPool`, `zstdPool`, `gzipPool`, `flatePool`) are reset upon retrieval and returned to `sync.Pool` via deterministic deferral/cleanup routines, preventing memory leaks and unbounded RAM consumption under high concurrency.
2. **WebSocket & Raw Socket Passthrough**: Confirmed that WebSocket 101 Switching Protocols and hijacked connections bypass compression entirely, preventing socket corruption.
3. **Parser Robustness**: Quality value parser in `selectCompressionEncoding` sanitizes malformed `q=` floats and unknown encoding clauses without panicking.
4. **MIME Restrictions**: Enforces strict MIME type whitelist, bypassing binary images/media to eliminate CPU waste.

## Conclusion

Approved. No security vulnerabilities identified.
