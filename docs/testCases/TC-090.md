# TC-090 - Test Suite for Transcoder Hop-by-Hop Header Sanitization and Protocol Compliance

## Test Objectives

Verify that [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89) in `pkg/transcoder/transcoder.go`:
1. Strips all standard RFC 7230 / RFC 7540 hop-by-hop headers from outgoing gRPC requests.
2. Dynamically strips headers nominated in `Connection` header tokens.
3. Enforces single-valued `TE: trailers` and discards client `TE` values.
4. Strips the client `Host` header.
5. Preserves legitimate application authentication, tracing, and metadata headers intact.
6. Executes with 100% race safety under `go test -race ./pkg/transcoder/...`.

---

## Test Cases Specification

### TC-090-01: Standard Hop-by-Hop Header Stripping
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**: Mock gRPC server inspecting `r.Header`.
- **Action**:
  - Send request with:
    - `Connection: keep-alive`
    - `Keep-Alive: timeout=10`
    - `Upgrade: websocket`
    - `Proxy-Connection: keep-alive`
    - `Transfer-Encoding: chunked`
    - `Proxy-Authenticate: Basic`
    - `Proxy-Authorization: Basic dXNlcjpwYXNz`
- **Assertions**:
  - Upstream receives **none** of: `Connection`, `Keep-Alive`, `Upgrade`, `Proxy-Connection`, `Transfer-Encoding`, `Proxy-Authenticate`, `Proxy-Authorization`.
  - Upstream receives 200 OK.

---

### TC-090-02: Dynamic Connection Token Stripping
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**: Mock gRPC server inspecting `r.Header`.
- **Action**:
  - Send request with:
    - `Connection: X-Custom-Hop, X-Another-Hop, close`
    - `X-Custom-Hop: secret-token`
    - `X-Another-Hop: temporary-value`
    - `X-Valid-Header: keep-me`
- **Assertions**:
  - Upstream does **not** receive `X-Custom-Hop`.
  - Upstream does **not** receive `X-Another-Hop`.
  - Upstream does **not** receive `Connection`.
  - Upstream **does** receive `X-Valid-Header: keep-me`.

---

### TC-090-03: Strict `TE: trailers` Invariant
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**: Mock gRPC server inspecting `r.Header["Te"]` / `r.Header["TE"]`.
- **Action**:
  - Send request with `TE: gzip, deflate`.
- **Assertions**:
  - Upstream receives `TE: [trailers]` only.
  - Upstream does not receive `gzip` or `deflate` in the `TE` header.
