# TC-047 - Test Suite for Native Kubernetes Ingress Controller Engine

## Test Objectives

Verify that `pkg/ingress` correctly parses Kubernetes REST API JSON responses (`Ingress`, `Service`, `Endpoints`, `Secret`), translates rules to Toron `router.Router` definitions, and streams watch events.

## Test Cases Defined

1. **`TestK8sJSONParsing`**:
   - Validate JSON decoding of `networking.k8s.io/v1` `IngressList`, `Service`, `Endpoints`, and `Secret` objects.
2. **`TestIngressTranslator`**:
   - Verify translation of `HTTPIngressPath` rules into Toron `DiscoveredRoute` definitions with host and path prefix matching.
3. **`TestK8sMockAPIServerClient`**:
   - Launch mock HTTPS REST server, issue GET and watch requests with bearer tokens, and verify resource decoding.
4. **`TestIngressControllerOrchestration`**:
   - Verify end-to-end synchronization of Ingress rules and Endpoint IP updates into `router.Router`.
5. **Race Detector Validation**:
   - Run `go test -v -race ./pkg/ingress/...`
