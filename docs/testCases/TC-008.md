# TC-008 - Native Go Benchmark Execution and Memory Allocation Tracking

## Description

Verify that all benchmark targets across `pkg/reactor`, `pkg/httpparser`, `pkg/router`, and `pkg/server` complete successfully, report nanoseconds per operation (`ns/op`), and output allocation metrics (`B/op`, `allocs/op`).

## Preconditions

- Codebase compiled and all unit tests passing.

## Test Data

- Standard HTTP request byte strings and mock connection buffers.

## Steps

1. Run `go test -bench=. -benchmem ./...`.
2. Verify benchmark outputs for `BenchmarkParseRequest_GET`, `BenchmarkResponse_Serialize`, `BenchmarkRouter_Match`, `BenchmarkReactor_BufferPool`, and `BenchmarkServer_EndToEnd`.
3. Assert zero panics, timeouts, or race conditions during benchmark iterations.

## Expected Results

- Benchmarks execute cleanly and report execution speed and memory allocations.

## Acceptance Criteria

- Benchmark execution exits with status code 0.

## Rationale

Ensures performance regression monitoring.

## Constraints

- Standard Go test toolchain.

## Open Questions

- None.
