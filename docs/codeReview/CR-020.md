# CR-020 - Code Review of HTTP/2 Extended CONNECT Protocol (RFC 8441)

## Review Summary

Code review of `pkg/httpparser/request.go`, `pkg/server/server.go`, `pkg/httpparser/parser_test.go`, and `pkg/server/http2_test.go`.

## Verification

1. `IsWebSocketUpgrade()` in `pkg/httpparser/request.go` extended to recognize RFC 8441 CONNECT + `:protocol: websocket` requests.
2. `http2AdapterHandler` in `pkg/server/server.go` transfers `:protocol` pseudo-headers, converts `101 Switching Protocols` to `200 OK` for HTTP/2 streams per RFC 8441, flushes response headers, and bridges streams.
3. Unit tests in `pkg/httpparser/parser_test.go` and `pkg/server/http2_test.go` pass.
4. All package unit tests (`go test -count=1 ./...`) execute with 100% success.

## Recommendation

Approved.
