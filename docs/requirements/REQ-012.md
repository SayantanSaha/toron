# REQ-012 - Dummy Web Services Test Suite for Upstream Verification

## Description

The repository shall include 10 lightweight dummy web services running on distinct HTTP ports (ports 9001 through 9010) inside `dummy-services/`. Each service shall return identification metadata (service name, port, request path, headers) to enable testing reverse proxy forwarding, load balancing algorithms, and header-based routing.

## Acceptance Criteria

- 10 distinct Go service entry points (or a configurable multi-service launcher package) in `dummy-services/` running on ports 9001, 9002, 9003, 9004, 9005, 9006, 9007, 9008, 9009, and 9010.
- Each service responds with JSON output containing `"service"`, `"port"`, `"path"`, `"method"`, and echoed headers.
- Includes a runner/launcher script or single command to spawn/stop all 10 dummy services concurrently.
- Unit tests verify launcher and service response formats.

## Rationale

Provides end-to-end integration testing for Toron's reverse proxy and round-robin load balancer without requiring external third-party dependencies.

## Constraints

- Zero external dependencies beyond standard library `net/http`.
- Lightweight memory footprint.
