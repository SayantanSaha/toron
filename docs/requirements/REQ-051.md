# REQ-051: Universal Auto-Installer & Service Manager (`install.sh`)

## Status
- **State**: APPROVED
- **Type**: Feature / Operations
- **Created**: 2026-08-16

## Description
Provide a production-grade, universal bash auto-installer (`install.sh`) that automatically detects the host operating system (`linux` vs `darwin`) and CPU architecture (`amd64` vs `arm64`), installs the binary to `/usr/local/bin/toron`, sets up `/etc/toron/` configuration directory and static assets (`/etc/toron/public/`), and creates system background services (`systemd` on Linux, `launchd` on macOS).

## Functional Requirements
1. **OS & Arch Auto-Detection**: Detect `uname -s` and `uname -m` to resolve pre-compiled binary names (`toron-linux-amd64`, `toron-linux-arm64`, `toron-darwin-arm64`).
2. **Binary Installation**: Copy binary to `/usr/local/bin/toron` with `0755` permissions.
3. **Configuration & Dashboard Assets**: Create `/etc/toron/` and `/etc/toron/public/`, installing `config.yaml`, `routes.yaml`, and static assets.
4. **Service Registration**:
   - **Linux**: Install systemd unit at `/etc/systemd/system/toron.service`, run `systemctl daemon-reload`, `enable`, and `start`.
   - **macOS**: Install launchd daemon plist at `/Library/LaunchDaemons/com.toron.edgegateway.plist`, run `launchctl load -w`.
5. **Uninstallation Support**: `./install.sh --uninstall` cleanly stops background services, removes system binaries, `/etc/toron/`, and log directories.
