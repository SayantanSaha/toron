# TC-054: Test Cases for Dashboard v2.0 UI & Multi-Theme Engine

## Test Cases

### TC-054.1: Theme Switching & Persistence
- **Action**: Switch theme to Light, verify `html` has no `dark` class and `localStorage.theme === 'light'`. Switch to Dark, verify `html` has `dark` class. Switch to System, verify it adopts the OS `prefers-color-scheme`.
- **Expected**: Visual theme updates instantly without page reload, and state is preserved across page refreshes.

### TC-054.2: Mobile Responsive Layout
- **Action**: Render dashboard at viewport width 375px (iPhone).
- **Expected**: Cards stack vertically without horizontal overflow; tab navigation scrolls horizontally with touch pills; all interactive buttons have >= 44px touch targets.

### TC-054.3: Route Search Filter
- **Action**: Type `/autotrader` in the route search input.
- **Expected**: Non-matching route cards are hidden in real time, and only `/autotrader` routes remain visible.
