# TC-081 - Verification of Request Body Preservation in Sidecar Proxy

## Objective

Verify that `pkg/sidecar/proxy.go` preserves incoming request bodies and forwards them completely to target upstream services during sidecar proxying.

## Test Cases

### TC-081-01: JSON POST Body Forwarding
- **Setup**: Start test upstream HTTP server capturing received request body. Configure `ProxyEngine` pointing to upstream.
- **Action**: Client sends `POST /api/data` with body `{"account":"123","amount":500}`.
- **Expected Outcome**:
  - Upstream receives exact JSON payload `{"account":"123","amount":500}`.
  - Body is not dropped or corrupted.

### TC-081-02: Empty GET Request Body Handling
- **Setup**: Upstream test server.
- **Action**: Client sends `GET /api/data` with nil body.
- **Expected Outcome**:
  - Handled cleanly without errors or memory allocations.
