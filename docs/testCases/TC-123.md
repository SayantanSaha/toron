# TC-123 - Test Cases for Configurable Upstream Reverse Proxy Transport Architecture

## 1. Test Specifications

### TC-123.1: Default "Raw Speed" Preservation Verification
- **Objective**: Verify that when transport config is omitted, `NewProxyWithOptions` initializes `http.Transport` with `MaxIdleConns: 10000`, `MaxIdleConnsPerHost: 1000`, `MaxConnsPerHost: 0`, `DisableCompression: true`, `Proxy: nil`, and `ForceAttemptHTTP2: false`.
- **Expected Result**: 100% parity with REQ-122 performance defaults.

### TC-123.2: Hierarchical Override & Route Precedence Verification
- **Objective**: Verify that route-level `ProxyRouteConfig.Transport` takes precedence over global `ProxyConfig.Transport`.
- **Expected Result**: Route-specific overrides take effect for that route without altering other routes or global fallbacks.

### TC-123.3: Egress Proxy Resolution Verification
- **Objective**: Verify that setting `ProxyURL` or `UseEnvProxy: true` configures the underlying transport proxy dialer appropriately.
- **Expected Result**: When `ProxyURL` is specified, `tr.Proxy` routes through that URL; when `UseEnvProxy: false`, `tr.Proxy` is strictly `nil`.

### TC-123.4: Upstream Concurrency Limiting (`MaxConnsPerHost > 0`)
- **Objective**: Configure `MaxConnsPerHost: 5` and verify that concurrent requests beyond 5 are throttled/queued.
- **Expected Result**: Backend never receives more than 5 concurrent in-flight connections.

### TC-123.5: Transparent Upstream Decompression Toggle
- **Objective**: When `DisableCompression: false`, verify that an upstream gzip response is transparently decompressed before downstream delivery.
- **Expected Result**: Downstream response body contains decompressed plaintext when requested without gzip.

### TC-123.6: Upstream Close Propagation Verification
- **Objective**: When `PropagateUpstreamClose: true` and upstream responds with `Connection: close`, verify that Toron cleanly signals connection close to the client while stripping raw hop-by-hop headers per REQ-071.
- **Expected Result**: Client connection terminates, but no raw RFC 7230 hop-by-hop headers leak into payload.

### TC-123.7: Upstream HTTP/2 Negotiation Toggle
- **Objective**: Verify that `ForceAttemptHTTP2: true` enables `tr.ForceAttemptHTTP2` on the proxy transport.
- **Expected Result**: `tr.ForceAttemptHTTP2` matches configured boolean.

### TC-123.8: Preset Profiles (`"raw_speed"` vs `"balanced"`)
- **Objective**: Verify preset profile expansion for `"raw_speed"` and `"balanced"`.
- **Expected Result**: Expected default values are populated for both presets.
