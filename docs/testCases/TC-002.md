# TC-002 - HTTP/1.1 Request Parsing and Response Generation Verification

## Description

Verify that the HTTP parser accurately parses valid HTTP request streams (methods, headers, query parameters, bodies) and generates properly formatted HTTP response status lines and payload bytes.

## Preconditions

- `httpparser` module instantiated.

## Test Data

- Valid HTTP GET request: `GET /test?query=val HTTP/1.1\r\nHost: localhost\r\n\r\n`
- Valid HTTP POST request: `POST /submit HTTP/1.1\r\nHost: localhost\r\nContent-Length: 11\r\n\r\nhello world`

## Steps

1. Feed HTTP GET raw bytes into parser.
2. Assert request method is `GET`, path is `/test`, query param `query` is `val`.
3. Feed HTTP POST raw bytes with body into parser.
4. Assert request method is `POST`, body content is `hello world`.
5. Construct a Response with Status `200 OK`, Header `Content-Type: text/plain`, Body `OK`.
6. Serialize response to bytes and verify standard wire format matching HTTP/1.1 specification.

## Expected Results

- Request parameters and body extracted cleanly.
- Wire response contains `HTTP/1.1 200 OK\r\nContent-Length: 2\r\nContent-Type: text/plain\r\n\r\nOK`.

## Acceptance Criteria

- Table-driven unit tests pass for all HTTP methods (`GET`, `POST`, `HEAD`, `OPTIONS`, `PUT`, `DELETE`).

## Rationale

Ensures compliance with HTTP protocol standards.

## Constraints

- Standard unit tests in `pkg/httpparser`.
