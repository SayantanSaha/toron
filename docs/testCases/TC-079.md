# TC-079 - Verification of Container Route Prefix Scoping & Shadowing Guards

## Objective

Verify that `ParseContainerLabels` rejects container routes that attempt to bind to root (`""` or `"/"`) without an explicit host or attempt to shadow `/internal` management endpoints.

## Test Cases

### TC-079-01: Wildcard Root Prefix Without Host Rejection
- **Setup**: Container with `toron.enable: "true"`, `toron.prefix: "/"`, and empty `toron.host`.
- **Action**: Call `ParseContainerLabels(container, 1)`.
- **Expected Outcome**: Returns `(nil, false)`. Route is not registered with the router.

### TC-079-02: Administrative Path Shadowing Rejection
- **Setup**: Container with `toron.enable: "true"` and `toron.prefix: "/internal/api"`.
- **Action**: Call `ParseContainerLabels(container, 1)`.
- **Expected Outcome**: Returns `(nil, false)`. Protected route is not shadowed.

### TC-079-03: Legitimate Scoped Route Registration
- **Setup**: Container with `toron.enable: "true"` and `toron.prefix: "/services/payments"`.
- **Action**: Call `ParseContainerLabels(container, 1)`.
- **Expected Outcome**: Returns `(*DiscoveredRoute, true)`. Route registers successfully.
