# SR-031 - Security Review of Multi-Scheme Authentication Middleware (JWT, API Key, Basic Auth)

## Scope

Security audit of JWT verification ([`pkg/router/auth.go`](file:///D:/Work/server/pkg/router/auth.go)), constant-time secret comparison (`crypto/subtle`), RFC 7519 claim validation (`exp`, `nbf`, `iss`, `aud`), API Key allowlist matching, and Basic Authentication credential parsing.

## Findings

1. **Timing Attack Immunity**: All cryptographic signature checks, API keys, and password comparisons utilize `subtle.ConstantTimeCompare`, neutralizing side-channel timing attack vectors.
2. **JWT Algorithm Substitution Protection**: `VerifyJWT` strictly validates the `alg` header against supported HMAC algorithms (`HS256`, `HS384`, `HS512`) and rejects the `none` algorithm vulnerability.
3. **Claim Validation Enforcements**: Mandatory verification of `exp` prevents replay of expired tokens, and `nbf` ensures premature tokens are rejected.
4. **Header Injection Safety**: `X-Authenticated-User` header is set on downstream requests only after successful authentication, ensuring downstream microservices receive authenticated identity context.

## Conclusion

Approved. No security vulnerabilities identified.
