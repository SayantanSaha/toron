# TC-006 - Static File Serving and Path Traversal Security Verification

## Description

Verify that `router.Static()` correctly serves HTML, CSS, JS files from a local directory, falls back to `index.html` for root directory hits, and blocks path traversal attempts (`/public/../../secret.txt`).

## Preconditions

- Temporary test folder created with `index.html` and `app.js`.

## Test Data

- Request `GET /static/index.html`
- Request `GET /static/app.js`
- Path Traversal Request `GET /static/../../etc/passwd`

## Steps

1. Dispatch request for `index.html` -> Verify 200 OK with `Content-Type: text/html`.
2. Dispatch request for `app.js` -> Verify 200 OK with `Content-Type: application/javascript` or `text/javascript`.
3. Dispatch request with `../` path traversal attempt -> Verify `403 Forbidden` or `404 Not Found`.

## Expected Results

- Files served with correct MIME types and path traversal rejected.

## Acceptance Criteria

- All static serving and security test assertions pass.

## Rationale

Ensures secure static site hosting.

## Constraints

- Standard unit tests in `pkg/router`.
