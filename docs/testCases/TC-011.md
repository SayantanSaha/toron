# TC-011 - Reverse Proxy Load Balancer Verification

## Test Objectives

Verify that the reverse proxy load balancer:
1. Sequentially distributes requests across configured upstreams using Round-Robin.
2. Correctly parses `targets` and `algorithm` from YAML configurations.
3. Successfully handles single-target backwards compatibility.
4. Returns HTTP 502 Bad Gateway on empty or unreachable targets.
