# ADR-049: Minimalist Mobile-First Architecture & Multi-Theme Design System for Dashboard v2.0

## Context
Toron Edge Gateway requires a modern, professional, and accessible administrative control dashboard that operates seamlessly across desktop workstations and mobile devices during on-call monitoring, with full support for light, dark, and system-synced display themes.

## Decision
1. **Theme State Machine**: Implement a 3-state theme controller (`light`, `dark`, `system`) using standard CSS variables and Tailwind's `class="dark"` strategy. When in `system` mode, attach a listener to `window.matchMedia('(prefers-color-scheme: dark)')` to dynamically transition themes when the user's OS changes.
2. **Mobile-First UX**: Structure the layout using CSS Grid and Flexbox with mobile-first breakpoints (`w-full` on mobile -> `sm:grid-cols-2` -> `lg:grid-cols-3` -> `xl:grid-cols-6`), touch-friendly targets, and a sticky header.
3. **Pure Vanilla Implementation**: Maintain zero external npm/runtime dependencies. Use pure ES6+ JavaScript (`app.js`) and standalone Tailwind CSS.

## Consequences
- **Positive**: High performance, zero build complexity, instant load time, full dark/light theme versatility, and excellent mobile ergonomics.
- **Negative**: Requires maintaining dual-theme CSS variables for high contrast and accessibility.
