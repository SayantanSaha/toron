# TC-107 - Test Specification for Socket Teardown on Protocol and WAF Violations

## 1. Test Suite Objectives

Verify that Toron sets `Connection: close` and physically terminates the underlying TCP socket upon issuing security rejections (IP ACL blocks, protocol integrity errors, OWASP threat detections, and filesystem traversal attempts), while preserving persistent keep-alive connections for benign requests.

## 2. Test Cases

### TC-107-01: WAF Middleware Security Rejection Connection Header Verification
- **Target**: `pkg/waf/middleware_test.go`
- **Assertion**:
  - A request blocked by IP ACL contains `Connection: close` in `res.Header`.
  - A request blocked by `ValidateProtocolIntegrity` contains `Connection: close` in `res.Header`.
  - A request blocked by OWASP threat signatures contains `Connection: close` in `res.Header`.
- **Expected Outcome**: `res.Header.Get("Connection") == "close"`.

### TC-107-02: Server Egress Response-Driven Socket Teardown
- **Target**: `pkg/server/server_test.go`
- **Methodology**: Dial Toron server over loopback TCP with `Connection: keep-alive` in request headers, targeting a route that returns `res.Header.Set("Connection", "close")` (or an IP ACL / WAF blocked path).
- **Expected Outcome**:
  - Response status is returned to client.
  - Response contains `Connection: close`.
  - Subsequent read on client socket returns `io.EOF` or connection reset, proving physical TCP teardown.

### TC-107-03: Benign Request Persistent Connection Preservation
- **Target**: `pkg/server/server_test.go`
- **Methodology**: Send consecutive valid `GET /health` requests on a single TCP connection without `Connection: close`.
- **Expected Outcome**: Sockets remain open across requests; multiple requests succeed on the same TCP socket.

### TC-107-04: Differential Protocol Security Fuzzer ExpectClose Invariant Verification
- **Target**: `benchmarks/fuzzer/diff_fuzzer_test.go` & `diff_fuzzer.go`
- **Assertion**: All security rejection vectors (`CONTROL-001..003`, `RESOURCE-002`, `TRAVERSAL-001..003`) assert `ExpectClose: true` and verify `ConnectionClose: true` via `verifySocketClosed`.
- **Expected Outcome**: 100% pass rate.
