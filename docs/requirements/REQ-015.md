# REQ-015 - Standardized HTTP Endpoint Test Suite File

## Description

The repository root shall include a standardized `test_endpoint.http` file formatted for HTTP REST client extensions (VS Code REST Client, JetBrains HTTP Client, curl tools). The file shall define runnable test requests covering all Toron endpoints: health check, server status, static site hosting, header-based proxy routing (v1 and v2), path-based prefix proxy routing, multi-target round-robin load balancing, and POST requests.

## Acceptance Criteria

- File created at repository root: `test_endpoint.http`.
- Requests separated by standard `###` delimiters with descriptive comments.
- Covers `/health`, `/api/status`, `/`, `/style.css`, `/app.js`.
- Covers `X-Version: v2` and `X-Version: v1` header routes.
- Covers `/services/cluster`, `/services/auth`, `/services/analytics` proxy routes.

## Rationale

Provides one-click interactive endpoint testing for developers using IDE REST clients without requiring manual curl typing.

## Constraints

- Standard `.http` / `.rest` RFC-2616 file syntax.
