# REQ-013 - Dummy Service Integration in Configuration Specification

## Description

The default configuration file `config.yaml` shall enable reverse proxying (`proxy.enabled: true`) and configure routes for all supported routing methods (path-based prefix routing, header-based conditional routing, single-target proxying, and multi-target round-robin load balancing) mapping to dummy web services on ports 9001 through 9010.

## Acceptance Criteria

- `proxy.enabled` set to `true` in `config.yaml`.
- Header-based routing route (e.g. `X-Version: v2`) mapped to multi-target round-robin load balancer across ports 9001, 9002, 9003.
- Header-based routing route (e.g. `X-Version: v1`) mapped to single target port 9004.
- Path-based prefix route (e.g. `/services/cluster`) mapped to multi-target round-robin load balancer across ports 9005, 9006, 9007.
- Path-based prefix route (e.g. `/services/auth`) mapped to single target port 9008.
- Path-based prefix route (e.g. `/services/analytics`) mapped to ports 9009, 9010.
- `config.yaml` passes validation and unit tests.

## Rationale

Provides out-of-the-box working configuration matching the 10 dummy web services suite for immediate end-to-end testing.

## Constraints

- Standard YAML format compliant with `pkg/config`.
