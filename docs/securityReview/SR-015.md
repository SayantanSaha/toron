# SR-015 - Security Review of Domain-Based Virtual Host Routing

## Scope

Security assessment of Host header domain matching logic and port sanitization in `pkg/router/router.go`.

## Findings

1. **Host Header Sanitization**: `extractHost(req)` strips optional port numbers (e.g. `api.toron.local:8080` $\rightarrow$ `api.toron.local`), normalizes to lowercase, and trims whitespace to prevent Host header spoofing and bypasses.
2. **Virtual Host Isolation**: Requests with unconfigured `Host` headers safely fall back to default path routes or 404 Not Found without leaking internal route definitions.

## Conclusion

Approved. No security vulnerabilities identified.
