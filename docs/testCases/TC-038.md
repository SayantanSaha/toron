# TC-038 - Native gRPC Health Probing Protocol and HTTP/2 Trailers Verification

## Test Objectives

1. Verify `EncodeGRPCHealthCheckRequest` generates accurate 5-byte gRPC prefix and Protobuf payload for both empty and named services.
2. Verify `DecodeGRPCHealthCheckResponse` parses `ServingStatus` values (`SERVING=1`, `NOT_SERVING=2`, `UNKNOWN=0`, `SERVICE_UNKNOWN=3`).
3. Verify `ProbeGRPCHealth` connects to an HTTP/2 gRPC mock health endpoint and reports healthy when status is `SERVING` and `grpc-status: 0`.
4. Verify `ProbeGRPCHealth` reports unhealthy when the gRPC server returns `NOT_SERVING (2)` or returns a non-zero `grpc-status`.
5. Verify gRPC reverse proxy forwards upstream `grpc-status` and `grpc-message` trailing headers to the client.
6. Verify full test suite passes cleanly (`go test ./...`).
