# TC-067 - Verification of Upstream Path Canonicalization and Route Traversal Guards

## Objective

Verify that Toron router canonicalizes incoming request paths (resolving dot-segments `.` and `..` and collapsing redundant slashes) prior to route dispatch, and that reverse proxy upstream path synthesis (`JoinProxyPath`) prevents directory traversal attacks from escaping configured target URL path boundaries.

## Test Cases

### TC-067-01: Pre-Routing Dot-Segment Normalization
- **Setup**: Register routes `/public` and `/internal` on `Router`.
- **Action**: Dispatch request with path `/public/../internal`.
- **Expected Outcome**:
  - Request path is canonicalized to `/internal`.
  - `/internal` handler is invoked.
  - `/public` handler is NOT invoked.

### TC-067-02: Redundant Slashes Normalization
- **Setup**: Register route `/internal`.
- **Action**: Dispatch request with path `//internal`.
- **Expected Outcome**:
  - Request path is canonicalized to `/internal`.
  - `/internal` handler is executed successfully.

### TC-067-03: Above-Root Traversal Containment
- **Setup**: Register root handler `/`.
- **Action**: Dispatch request with path `/../../`.
- **Expected Outcome**:
  - Request path is cleaned to `/`.
  - Root handler is executed without panic or route escape.

### TC-067-04: Upstream Subpath Containment (StripPrefix True)
- **Setup**: Configure route with `prefix: "/api"`, `target: "http://upstream/subpath"`, and `stripPrefix: true`.
- **Action**: Invoke `JoinProxyPath` with `reqPath: "/api/../admin"`.
- **Expected Outcome**:
  - Joined path produces `/subpath/admin`.
  - Path does NOT escape above `/subpath`.

### TC-067-05: Upstream Subpath Containment (StripPrefix False)
- **Setup**: Configure route with `prefix: "/v1"`, `target: "http://upstream/v1"`, and `stripPrefix: false`.
- **Action**: Invoke `JoinProxyPath` with `reqPath: "/v1/../../etc/passwd"`.
- **Expected Outcome**:
  - Joined path produces `/v1/etc/passwd`.
  - Traversal above `/v1` root is prevented.
