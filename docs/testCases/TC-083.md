# TC-083 - Verification of Automated wrk2 Harness and Differential Security Fuzzer

## Purpose

Verify that the automated benchmark scripts and differential security fuzzer in `benchmarks/` execute cleanly, produce valid statistical outputs, correctly test Toron's security invariants, and generate reproduction artifacts for academic review.

## Test Scenarios

### Scenario 1: Standalone Load Generator Execution (`loadgen.go`)
- **Precondition**: Toron server running or started in mock mode.
- **Action**: Run `go run benchmarks/wrk2/loadgen.go -url http://127.0.0.1:8080/health -c 10 -d 3s -rate 1000 -json benchmarks/results/test_loadgen.json`.
- **Expected Result**: Exits with code 0; produces valid JSON with total requests, actual RPS, p50, p90, p99, and p99.9 latencies.

### Scenario 2: wrk2 Shell Harness Fallback Verification (`run_wrk2.sh`)
- **Precondition**: `wrk2` not installed in PATH.
- **Action**: Run `bash benchmarks/wrk2/run_wrk2.sh -u http://127.0.0.1:8080/health -d 2s -c 20 -r 2000`.
- **Expected Result**: Script detects absence of `wrk2`, displays notice of fallback, executes `loadgen.go` seamlessly, and writes summary results to `benchmarks/results/`.

### Scenario 3: Differential Protocol Security Fuzzer Execution (`diff_fuzzer.go`)
- **Precondition**: Toron server listening on target address.
- **Action**: Run `go run benchmarks/fuzzer/diff_fuzzer.go -target 127.0.0.1:8080 -out benchmarks/results/fuzz_test.json`.
- **Expected Result**:
  - Sends full test matrix: CL.TE desync, multiple Content-Length, leading colon whitespace, non-printable control chars, directory traversal variants, and query pollution.
  - Verifies that Toron correctly rejects violations with status 400 or 501 and terminates the connection where required by RFC.
  - Computes pass rate, rejection latency, and outputs structured JSON and Markdown reports.

### Scenario 4: Master Runner Execution (`run_all.sh`)
- **Action**: Run `bash benchmarks/run_all.sh --auto-start`.
- **Expected Result**: Starts Toron server in background, executes benchmark suite, executes differential fuzzer, shuts down Toron gracefully, and populates `benchmarks/results/` with all artifacts.
