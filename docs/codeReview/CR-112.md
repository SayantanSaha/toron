### 4.1 Layer 7 WAF Raw Wire URI Inspection ([`pkg/waf/waf.go`](file:///Users/sneha/Developer/toron-research/toron/pkg/waf/waf.go#L282-L374))

1. **Wire Path Extraction ([`pkg/waf/waf.go:288-306`](file:///Users/sneha/Developer/toron-research/toron/pkg/waf/waf.go#L288-L306), [`pkg/waf/waf.go:338-356`](file:///Users/sneha/Developer/toron-research/toron/pkg/waf/waf.go#L338-L356))**:
   - Both `Inspect` (stdlib `*http.Request`) and `InspectToron` (`*httpparser.Request`) inspect `req.RequestURI` first.
   - Query strings (delimited by `?`) and URL fragments (delimited by `#`) are cleanly stripped using `strings.IndexByte`, preserving the wire path string without heap allocations.
   - If `req.RequestURI` is empty (e.g. synthetic or internal unit test requests), the methods gracefully fall back to `req.URL.Path` or `req.Path`.
2. **Dual-Path Pattern Evaluation ([`pkg/waf/waf.go:414`](file:///Users/sneha/Developer/toron-research/toron/pkg/waf/waf.go#L414))**:
   - In `inspectInternal`:
     ```go
     if (rule.Locations&InspectURL != 0) && ((normPath != "" && rule.Pattern.MatchString(normPath)) || (urlPath != "" && rule.Pattern.MatchString(urlPath))) {
         matchFound = true
     }
     ```
   - This evaluates regex patterns against both the normalized unescaped path (`normPath`) and the raw wire path (`urlPath`).
   - For `TRAVERSAL-001` (`(?i)(\.\./|\.\.\\|%2e%2e/|%2e%2e%2f|%2e%2e\\|%2e%2e%5c)`), raw dot-dots (`../`) match against `urlPath` directly, while uppercase percent-encoded forms (`%2E%2E/`) match both directly via case-insensitive regex and via unescaped `normPath`.
   - Score accumulation and blocking in `enforce` mode operate cleanly.

### 4.2 Route-Aware Static Prefix Escape Guard ([`pkg/router/router.go`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L789-L885))

1. **Dead-Code Contradiction Resolution**:
   - Previously, `cleanRequestPath(req.Path)` in `Router.ServeHTTP` prematurely collapsed `/internal/dashboard/../../canary_traversal.txt` into `/canary_traversal.txt`. Because `/canary_traversal.txt` did not match the static prefix `/internal/dashboard`, the request fell through to `r.NotFound` (404), leaving the static traversal guard in `createStaticHandler` unreachable.
   - The new implementation captures `rawPath` and performs iterative unescaping (`url.PathUnescape`) prior to path canonicalization.
2. **Prefix Boundary Matching Logic ([`pkg/router/router.go:851-884`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L851-L884))**:
   - The guard specifically targets routes where `pr.routeType == string(RouteTypeStatic)` and `pr.prefix != ""` (ignoring root `/`).
   - Prefix normalization (`prefix := "/" + strings.Trim(pr.prefix, "/")`, `prefixSlash := prefix + "/"`) ensures consistent boundary checks.
   - Evaluates whether the request targeted the static prefix:
     ```go
     targeted := rawPath == prefix || strings.HasPrefix(rawPath, prefixSlash) ||
         unescaped == prefix || strings.HasPrefix(unescaped, prefixSlash)
     ```
   - Evaluates whether canonicalization escapes that prefix:
     ```go
     cleanRaw := cleanRequestPath(rawPath)
     cleanUnesc := cleanRequestPath(unescaped)
     escapes := (!strings.HasPrefix(cleanRaw, prefixSlash) && cleanRaw != prefix) ||
         (!strings.HasPrefix(cleanUnesc, prefixSlash) && cleanUnesc != prefix) ||
         (req != nil && !strings.HasPrefix(req.Path, prefixSlash) && req.Path != prefix)
     ```
   - When `targeted && escapes`, `staticEscapeDetected = true`, assigning a defensive rejection handler:
     - Status: `403 Forbidden` (`http.StatusForbidden`).
     - Header: `Connection: close`.
     - Header: `Content-Type: application/json`.
     - Payload: `{"error":"403 Forbidden: Path Traversal Disallowed"}`.
3. **ADR-062 Non-Static Route Preservation**:
   - Routes with `pr.routeType != string(RouteTypeStatic)` (such as `RouteTypeUpstream` and exact API routes) are excluded from the static prefix escape check.
   - Legitimate canonicalization of non-static routes (e.g., `/public/../internal` resolving to `/internal`) continues to function without false-positive blocks.

## 5. Findings & Recommendations

### Finding 1: Unbounded Iterative Path Unescaping Loop
- **Severity**: Low
- **Location**: [`pkg/router/router.go:807-813`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L807-L813)
- **Related Artifact**: `REQ-116`, `TASK-139.2`
- **Description**: In `Router.ServeHTTP`, the router executes an unconstrained `for` loop to unescape percent-encoded paths:
  ```go
  unescaped = rawPath
  for {
      u, err := url.PathUnescape(unescaped)
      if err != nil || u == unescaped {
          break
      }
      unescaped = u
  }
  ```
- **Impact**: While mathematically bounded because every successful unescaping iteration strictly shortens the string length (e.g. `%25` -> `%`), an adversarial payload containing thousands of consecutive `%25` tokens could cause unnecessary CPU cycles on malicious requests.
- **Recommendation**: Introduce a bounded iteration counter (e.g. `maxUnescapeDepth := 5`) to prevent CPU exhaustion on deep recursive encodings while fully covering standard multi-encoding evasion techniques (double and triple encodings).

### Finding 2: Potential Duplicate Regex Evaluation on Unencoded URL Paths
- **Severity**: Informational
- **Location**: [`pkg/waf/waf.go:414`](file:///Users/sneha/Developer/toron-research/toron/pkg/waf/waf.go#L414)
- **Related Artifact**: `REQ-116`, `TASK-139.1`
- **Description**: In `WAFEngine.inspectInternal`, if `urlPath` does not contain any percent encodings, `normPath` equals `urlPath`. The condition:
  ```go
  (normPath != "" && rule.Pattern.MatchString(normPath)) || (urlPath != "" && rule.Pattern.MatchString(urlPath))
  ```
  relies on short-circuit evaluation. If `normPath` matches, the second expression is skipped. If `normPath` does not match, the second expression is evaluated with `urlPath`. If `urlPath == normPath`, the second evaluation will also evaluate false, consuming regex matching time.
- **Impact**: Negligible CPU cycle difference for benign requests when rules do not match.
- **Recommendation**: Optimize to `(normPath != "" && rule.Pattern.MatchString(normPath)) || (urlPath != "" && urlPath != normPath && rule.Pattern.MatchString(urlPath))` to avoid evaluating identical strings twice.

## 7. Positive Observations

1. **Strict Defense-in-Depth**:
   The dual-layered architecture provides robust security containment. Even if an operator disables the WAF middleware for performance or deploys Toron's router as an embedded component without WAF, Layer 2 (Router Static Prefix Escape Guard) independently catches and blocks directory traversal attempts with `403 Forbidden` and `Connection: close`.
2. **Explicit Canary Secret Leakage Guards**:
   The integration tests in `router_test.go` deploy a real canary secret file (`TORON_TRAVERSAL_CANARY_SECRET_DATA_DO_NOT_LEAK`) on disk and explicitly assert `!strings.Contains(body, canaryContent)`, providing verifiable proof of filesystem isolation.
3. **Zero Allocation on Benign Requests**:
   The router prefix escape check only triggers when `targetHandler == nil` (i.e. after exact route matching fails). Benign API and static routes registered exactly incur zero overhead.
4. **Clean Concurrency Synchronization**:
   Reader locking (`r.mu.RLock()`, `e.mu.RLock()`) is meticulously scoped. Locks are never held across I/O operations or handler dispatching, completely avoiding lock contention and priority inversion.
