# ADR-046: Cross-Platform Service Integration & Configuration Directory Standard

## Status
Approved

## Context
Deploying Toron Edge Gateway across Linux servers and macOS developer workstations requires standard system paths (`/usr/local/bin`, `/etc/toron`) and native OS service integration (`systemd` vs `launchd`).

## Decision
1. **Directory Standard**: Install binary to `/usr/local/bin/toron`, configuration and web assets to `/etc/toron/`, and system logs to `/var/log/toron/`.
2. **Linux Daemon**: Use native systemd unit file (`/etc/systemd/system/toron.service`) with `Restart=on-failure` and `LimitNOFILE=65536`.
3. **macOS Daemon**: Use launchd plist (`/Library/LaunchDaemons/com.toron.edgegateway.plist`) with `RunAtLoad=true` and `KeepAlive=true`.

## Consequences
- **Positive**: Enables 1-command installation (`sudo ./install.sh` / `make install`) with automatic background service management.
- **Negative**: Requires root / `sudo` privileges during installation/uninstallation.
