# SR-064 - Security Review of Upstream Path Canonicalization and Route Traversal Guards

## Description

Security evaluation of the implementation for `TASK-067` / `SEC-07` (Pre-routing dot-segment bypass and upstream reverse proxy path traversal).

## Scope

- Files reviewed:
  - `pkg/router/router.go`
  - `pkg/proxy/proxy.go`
  - `pkg/router/router_test.go`
  - `pkg/proxy/proxy_test.go`

## Security Evaluation & Analysis

1. **Pre-Routing Dot Segment Normalization (CWE-22)**:
   - In `pkg/router/router.go`, incoming request paths are canonicalized via `cleanRequestPath(req.Path)` in `ServeHTTP`, `ShouldRedirectHTTP`, and `MatchPrefixRoute`.
   - Traversal attempts like `/public/../internal` are resolved to `/internal` before route lookup, preventing attackers from bypassing route-level authentication or access controls configured on prefix routes.
2. **Upstream Path Boundary Containment**:
   - In `pkg/proxy/proxy.go`, `JoinProxyPath` normalizes trimmed subpaths and asserts target prefix containment.
   - Even if crafted paths containing `../` reach upstream URL joining, the joined path is constrained to remain within the configured `targetPath` root, neutralizing directory traversal attacks against backend microservices.
3. **Exploit Verification**:
   - Verified that `/public/../internal` does not trigger `/public` middleware or handlers.
   - Verified that proxy requests with `/api/../admin` and `/v1/../../etc/passwd` cannot escape configured proxy targets (`/subpath` and `/v1`).

## Conclusion

`SEC-07` is completely resolved. Directory traversal and path bypass vulnerabilities are mitigated. The implementation is approved.
