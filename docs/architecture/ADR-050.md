# ADR-050: Centralized Version Management & Build Linker Injection

## Status
Approved

## Context
Toron previously maintained version strings in multiple distinct locations (`install.sh`, `install.bat`, `internal_api.go`, `main.go`, and documentation files), risking drift during release iterations.

## Decision
1. **Root `VERSION` as SSOT**: A single text file `VERSION` defines the semantic version number.
2. **`pkg/version` Package with Fallback Default**: `pkg/version.Version` defaults to the current release constant but can be overridden at build-time using `-ldflags "-X toron/pkg/version.Version=..."`.
3. **Build Metadata Injection**: The build pipeline attaches Git commit hash and ISO-8601 build timestamp directly into the compiled binary via `go build -ldflags`.
4. **Programmatic Consumption**: All subsystems (`cmd/toron`, `pkg/server`, `/api/status`, and HTTP responses) reference `version.Version` exclusively.

## Consequences
- **Positive**: Eliminates version discrepancy, simplifies release automation, and embeds verifiable provenance into every compiled binary.
