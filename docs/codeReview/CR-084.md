## Detailed Evaluation

### 1. Code Quality, Go Idiomatic Patterns & Clean Structure
- **Configuration Schema & Hierarchy**:
  - `UpgradeIdleTimeout time.Duration` is cleanly modeled in [`server.Config`](file:///Users/sneha/Developer/toron-research/toron/pkg/server/config.go) and [`ServerConfig`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/config.go).
  - Production default of `60 * time.Second` is enforced in [`DefaultConfig()`](file:///Users/sneha/Developer/toron-research/toron/pkg/server/config.go) and [`DefaultAppConfig()`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/config.go).
  - 3-tier hierarchical resolution in [`ToServerConfig()`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/config.go) (`Server.UpgradeIdleTimeout` -> `Server.IdleTimeout` -> `60s`) ensures graceful fallback when operators do not supply an explicit value.
  - Validation in [`ValidateConfig()`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/loader.go) defensively checks for negative values (`< 0`).
- **HTTP/1.1 Upgraded Connection Relay**:
  - Unconditional clearance via `SetDeadline(time.Time{})` and unbounded `io.Copy` in [`handleConn`](file:///Users/sneha/Developer/toron-research/toron/pkg/server/server.go) are replaced with `relayUpgradedStreams(conn, res.UpgradedConn, idleTimeout)` and `relayStreams`.
  - Directional relays use 32 KB buffers, refreshing read deadlines on source sockets and write deadlines on destination sockets before every I/O call.
  - Sockets are closed deterministically across concurrent directions using `sync.Once`, preventing double-close errors.
  - Full support for TCP half-close (`CloseWrite()`) upon `io.EOF`, allowing reverse responses to drain while maintaining deadline enforcement.
  - Diagnostic logs are cleanly formatted with `[Server]` prefix, avoiding false-positive error logs on clean peer disconnects.
- **HTTP/2 Extended CONNECT Protection**:
  - [`http2AdapterHandler`](file:///Users/sneha/Developer/toron-research/toron/pkg/server/server.go) uses `relayHTTP2UpgradedStream`, maintaining an atomic `lastActivity` timestamp on each transferred chunk.
  - A background watchdog enforces `UpgradeIdleTimeout`, closing `res.UpgradedConn` when inactivity occurs.
  - Listens on `r.Context().Done()` to immediately tear down the upstream socket when the client stream resets (`RST_STREAM`) or aborts.
  - Goroutines are synchronized via `sync.WaitGroup` and joined before handler return.

### 2. Zero 3rd-Party Dependencies Invariant
- Verified that all modified source files and unit tests rely exclusively on the Go standard library:
  - `bytes`, `context`, `errors`, `fmt`, `io`, `log`, `net`, `net/http`, `os`, `strings`, `sync`, `sync/atomic`, `testing`, `time`.
- Zero external dependencies introduced. Invariant is **100% compliant**.

### 3. Concurrency Safety & Race Freedom under `go test -race`
- Executed `go test -v -race -count=1 ./pkg/server/... ./pkg/config/...`: **PASSED** cleanly with zero data races reported.
- Atomic types (`atomic.Int64`), mutexes, `sync.Once`, and channels are applied with proper synchronization.

### 4. Resource Leak Prevention & Lifecycle Management
- **Normal Completion**: Sockets and registries are cleaned via deferred blocks upon stream/task termination.
- **Idle Timeout**: Both directions of HTTP/1.1 streams and HTTP/2 Extended CONNECT upstream sockets are closed after `UpgradeIdleTimeout` of inactivity, unblocking worker goroutines and freeing socket descriptors.
- **Context Cancellation**: Client HTTP/2 stream abort immediately tears down the backend socket.
- **Peer Close**: Immediate clean teardown occurs when either peer disconnects without waiting for the full idle timeout.
