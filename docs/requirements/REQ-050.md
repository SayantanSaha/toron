# REQ-050: Advanced Load Balancing Algorithms Engine

## Overview
Expand Toron Edge Gateway's core reverse proxy engine to support 5 advanced load balancing algorithms with 0 external dependencies (pure Go stdlib):
1. **Weighted Round-Robin (`weighted_round_robin`)**: Nginx smooth weighted round-robin.
2. **Weighted Random (`weighted_random`)**: Weighted cumulative random target selection.
3. **Least Connections (`least_conn`)**: Directs traffic to the node handling the fewest active in-flight connections.
4. **Weighted Least Connections (`weighted_least_conn`)**: Directs traffic based on `ActiveConns / Weight`.
5. **Lowest Response Latency (`least_latency`)**: Directs traffic to the node with the fastest moving average latency.

## Functional Requirements
1. **Target Weight Configuration**:
   - Upstream targets can be configured with numerical weights (default `1`, min `1`).
   - Supports config syntax in `routes.yaml` / `config.yaml`.
2. **Real-time Connection Tracking**:
   - `UpstreamTarget` tracks atomic `ActiveConns` counter (`atomic.AddInt64`).
   - Proxy handler increments `ActiveConns` when proxying starts and decrements via `defer` when request finishes.
3. **Response Latency Tracking**:
   - `UpstreamTarget` tracks exponential moving average (EMA) response latency (`AvgLatencyUS`).
   - Proxy handler measures request-response duration and updates latency.
4. **Dashboard & Internal API Integration**:
   - Dynamic route list endpoint `/internal/api/routes` returns algorithm names.
   - Web Control Center UI renders algorithm badges for all 5 new load balancing strategies.

## Non-Functional Requirements
- **Performance**: Zero allocation overhead on `Next()` target selection calls.
- **Thread Safety**: Concurrent safe across thousands of worker goroutines using `sync/atomic` and `sync.RWMutex`.
- **Zero-Dependency Guarantee**: Must rely strictly on standard library (`sync/atomic`, `math/rand`, `time`).
