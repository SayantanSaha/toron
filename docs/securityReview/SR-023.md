# SR-023 - Security Review of Dynamic Route Hot Reloading via fsnotify

## Scope

Security audit of background file watcher implementation ([`pkg/config/watcher.go`](file:///D:/Work/server/pkg/config/watcher.go)), path resolution sanitization, syntax error isolation, and thread-safe atomic route swapping ([`pkg/router/router.go`](file:///D:/Work/server/pkg/router/router.go)).

## Findings

1. **Validation Isolation**: If `routes.yaml` is modified to contain malformed YAML syntax or invalid definitions, the hot reloader rejects the update and logs a warning while retaining the current active route table intact without dropping service.
2. **Path Sanitization**: `RouteWatcher` resolves absolute file paths and watches only specified route files to prevent arbitrary filesystem directory traversal.
3. **Concurrency Safety**: Atomic `Router.Reset()` locking under `sync.RWMutex` prevents race conditions or partially applied route states when serving parallel HTTP/TCP/UDP/QUIC requests.

## Conclusion

Approved. No security vulnerabilities identified.
