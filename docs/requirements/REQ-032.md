# REQ-032 - Enhance Internal Control Plane JSON Endpoints with Comprehensive System Metrics

## Description

The Toron web server shall extend its internal JSON control plane endpoints (`/internal/api/status`, `/internal/api/metrics`) to export real-time system metrics, active connection counts, status code breakdowns, active QUIC stream counts, and circuit breaker trip events to the Web Dashboard and monitoring APIs.

The `GET /internal/api/status` and `GET /internal/api/metrics` endpoints shall return structured JSON payloads containing:
- `total_requests`: Total request count across all HTTP routes.
- `active_quic_streams`: Gauge count of active HTTP/3 QUIC streams.
- `active_tcp_connections`: Gauge count of active client TCP socket connections.
- `circuit_breaker_trips`: Breakdown of circuit breaker trips per backend target node.
- `requests_by_status`: Map of request counts grouped by HTTP status codes (`200`, `404`, `429`, `502`).
- `requests_by_method`: Map of request counts grouped by HTTP methods (`GET`, `POST`).
- `requests_by_route`: Request distribution per route prefix.

## Acceptance Criteria

- `pkg/metrics`: Adds `GetSummaryJSON()` method returning a structured map of system metrics.
- `pkg/server`: `GET /internal/api/status` embeds system metrics summary in its JSON response.
- `pkg/server`: Registers `GET /internal/api/metrics` returning structured JSON metrics.
- Frontend JavaScript (`public/app.js`) can consume structured JSON metrics for live dashboard rendering.
- Automated unit tests in `pkg/server` and `pkg/metrics` pass cleanly.

## Rationale

Exposing structured JSON metrics on `/internal/api/` allows web management dashboards and REST clients to visualize real-time proxy telemetry alongside Prometheus text scraping.
