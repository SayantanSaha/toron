# TC-089 - Verification Suite for REST-to-gRPC Transcoder Request Body Limits

## Test Objectives

Verify that the REST-to-gRPC Transcoding Engine ([`Engine`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L24)) enforces configurable `MaxBodyBytes` limits across all routes, verifying:
1. Fast-fail rejection on declared `Content-Length` exceeding `MaxBodyBytes` returning `HTTP 413 Payload Too Large`.
2. Bounded stream over-read rejection via `io.LimitReader` for chunked or undeclared streams returning `HTTP 413 Payload Too Large`.
3. Upstream gRPC backend receives **zero requests** on rejected payloads.
4. Default 4 MB limit fallback when unset or $\le 0$, and configurable overrides.
5. In-limit payloads are forwarded with 100% byte fidelity.
6. Non-mutating and nil body requests pass through without error.
7. Zero data races under `go test -race ./pkg/transcoder/...` and `./pkg/config/...`.

---

## Test Cases Specification

### TC-089-01: Declared Content-Length Fast-Fail Rejection
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**:
  - `Engine` configured with `MaxBodyBytes: 1024` (1 KB).
  - Mock gRPC upstream server recording received requests count.
- **Action**:
  - Send request with `Content-Length: 2048` (2 KB).
- **Assertions**:
  - `res.StatusCode == http.StatusRequestEntityTooLarge` (413).
  - `res.Header.Get("Content-Type") == "application/json"`.
  - Response body contains `"Payload Too Large: request Content-Length 2048 exceeds limit of 1024 bytes"`.
  - Mock gRPC backend received count is exactly `0`.

### TC-089-02: Bounded Stream Over-Read Rejection
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**:
  - `Engine` configured with `MaxBodyBytes: 1024` (1 KB).
  - Mock gRPC upstream server recording received requests count.
- **Action**:
  - Send streaming request with `ContentLength: 0` (or omitted) but body stream contains 1500 bytes.
- **Assertions**:
  - `res.StatusCode == http.StatusRequestEntityTooLarge` (413).
  - `res.Header.Get("Content-Type") == "application/json"`.
  - Response body contains `"Payload Too Large: request body exceeds limit of 1024 bytes"`.
  - Mock gRPC backend received count is exactly `0`.

### TC-089-03: Configuration Schema, Default Fallback & Loader Validation
- **Target**: [`pkg/config/config.go`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/config.go), [`pkg/config/loader.go`](file:///Users/sneha/Developer/toron-research/toron/pkg/config/loader.go)
- **Preconditions**: Uninitialized or custom `TranscoderConfig`.
- **Action**:
  1. Evaluate `GetMaxBodyBytes()` when `MaxBodyBytes == 0`. Assert returns `4 * 1024 * 1024` (4 MB).
  2. Evaluate `GetMaxBodyBytes()` when `MaxBodyBytes == -50`. Assert returns `4 * 1024 * 1024` (4 MB).
  3. Evaluate `GetMaxBodyBytes()` when `MaxBodyBytes == 8388608` (8 MB). Assert returns `8388608`.
  4. Parse YAML config with negative `max_body_bytes: -1`. Assert config validator returns an error.

### TC-089-04: Full-Fidelity In-Limit Payload Forwarding
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**:
  - `Engine` configured with `MaxBodyBytes: 4096` (4 KB).
  - Mock gRPC backend echoing parsed JSON request fields.
- **Action**:
  - Send valid JSON payload: `{"id":"usr-42","name":"Valid User","role":"admin"}` (54 bytes).
- **Assertions**:
  - `res.StatusCode == http.StatusOK` (200).
  - Upstream backend received exactly `1` request.
  - Decoded gRPC request wire frame contains identical fields.

### TC-089-05: Non-Mutating & Nil Body Request Bypass
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**:
  - `Engine` configured with `MaxBodyBytes: 1024`.
  - Route mapping `GET /v1/users/:id` $\to$ `/user.UserService/GetUser`.
- **Action**:
  - Send `GET` request with `req.Body == nil` and path `/v1/users/usr-100`.
- **Assertions**:
  - `res.StatusCode == http.StatusOK` (200).
  - Upstream received `1` request with `{"id":"usr-100"}`.
  - Zero errors or nil pointer dereferences.

### TC-089-06: Concurrency & Race Safety Verification
- **Target**: [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L89)
- **Preconditions**:
  - `Engine` configured with `MaxBodyBytes: 2048` (2 KB).
  - Mock gRPC backend.
- **Action**:
  - Launch 50 concurrent goroutines sending an equal mix of valid requests and oversized requests.
- **Assertions**:
  - All valid requests receive 200 OK.
  - All oversized requests receive 413 Payload Too Large.
  - Zero data races detected under `go test -race`.
