## 2. Threat Modeling & Security Assessment

### 2.1 Threat Vectors Evaluated

1. **Path Traversal & Arbitrary File Overwrite (CWE-22 / CWE-23)**:
   - *Risk*: Malicious or corrupted artifact paths passed via CLI flags causing writes outside the designated retention or canonical directories.
   - *Mitigation Verified*: `ReplicateArtifacts` explicitly extracts `filepath.Base(cleanPath)` before creating destination file paths (`filepath.Join(historyDir, baseName)` and `filepath.Join(canonicalDir, baseName)`). Paths with directory traversals (`../../`) are collapsed and restricted strictly to their base filename, preventing directory escape attacks.
2. **Race Conditions & Partial Manifest Writes (CWE-362 / CWE-377)**:
   - *Risk*: Simultaneous or interrupted benchmark runs writing to `manifest.json`, corrupting JSON data or causing partial file truncations.
   - *Mitigation Verified*: `UpdateManifest` uses mutex locking (`fileLock.Lock()`), writes the serialized payload to a PID- and nanosecond-tagged temporary file (`manifest.json.tmp.<pid>_<nano>`), syncs it to disk, and executes an atomic POSIX rename (`os.Rename`). If process termination occurs mid-write, the existing `manifest.json` remains uncorrupted.
3. **Command Injection via Metadata Sourcing (CWE-78)**:
   - *Risk*: Execution parameters, git branch names, or command arguments containing shell metacharacters (`$(...)`, backticks) being executed during evaluation.
   - *Mitigation Verified*: Git metadata retrieval uses direct executable invocations via `exec.Command` without invoking a subshell. JSON serialization handles escaping safely via `encoding/json`.
4. **Denial of Service via Unbounded Disk Consumption (CWE-400)**:
   - *Risk*: Continuous automated benchmark loops exhausting storage with large historical logs.
   - *Mitigation Verified*: Retained artifacts consist strictly of lightweight JSON/Markdown/CSV structured reports. Suffix collision protection avoids infinite directory generation loops. An explicit `--no-history` flag allows automated CI/CD runners to bypass historical persistence when running in ephemeral environments.
