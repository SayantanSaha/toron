# CR-066 - Code Review of Host Header Validation in Cleartext HTTP-to-HTTPS Redirection

## Description

Engineering code review of `TASK-070` changes across `pkg/server/server.go`, `pkg/server/sni.go`, `pkg/server/config.go`, `pkg/config/config.go`, `pkg/router/router.go`, `cmd/toron/main.go`, and `pkg/server/server_test.go`.

## Scope

- Files reviewed:
  - `pkg/server/server.go`
  - `pkg/server/sni.go`
  - `pkg/server/config.go`
  - `pkg/config/config.go`
  - `pkg/router/router.go`
  - `cmd/toron/main.go`
  - `pkg/server/server_test.go`

## Key Observations & Review Findings

1. **Layered Host Discovery**:
   - `isRecognizedHost` checks 6 tiers of domain authority: explicit `AllowedHosts` whitelist, canonical `DefaultHost`, `SNIRegistry` TLS certificates, `Router` route entries, server listener address, and local loopback.
2. **Deterministic Port Stripping & Sanitization**:
   - `net.SplitHostPort` safely handles ports before domain comparison, while `strings.ContainsAny(rawHost, "\r\n\t /\\")` continues to prevent HTTP response splitting.
3. **Comprehensive Integration Testing**:
   - Added table-driven and subtest coverage for standard HTTPS redirection, port stripping, non-standard HTTPS target ports, malformed host rejection, unrecognized host 400 rejection, and canonical DefaultHost fallback.
4. **Zero Race Conditions**:
   - `SNIRegistry.HasHost` and `Router.HasHost` utilize read locks (`RLock`/`RUnlock`), safely supporting dynamic route and TLS updates.
   - All tests run cleanly with `-race`.

## Verdict

Approved. Ready for commit.
