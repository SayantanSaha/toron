# TC-059 - Verification of Upstream Reverse Proxy Path Rewriting and Target Subpath Preservation

## Objective

Verify that Toron's reverse proxy correctly resolves upstream target paths when `strip_prefix: true` is enabled, without injecting unwanted trailing slashes for subpath targets, while preserving client trailing slashes and nested subpath joins.

## Test Cases

### TC-059-01: Exact Prefix Match to Upstream Subpath Target (No Trailing Slash)
- **Configuration**:
  - `prefix`: `"/kite/postback"`
  - `target`: `http://upstream:8082/postback`
  - `strip_prefix`: `true`
- **Request**: `POST /kite/postback`
- **Expected Outcome**: Upstream receives `POST /postback` (no trailing slash).

### TC-059-02: Exact Prefix Match with Explicit Client Trailing Slash
- **Configuration**:
  - `prefix`: `"/kite/postback"`
  - `target`: `http://upstream:8082/postback`
  - `strip_prefix`: `true`
- **Request**: `POST /kite/postback/`
- **Expected Outcome**: Upstream receives `POST /postback/` (preserves client trailing slash).

### TC-059-03: Nested Subpath Join under Subpath Target
- **Configuration**:
  - `prefix`: `"/kite/postback"`
  - `target`: `http://upstream:8082/postback`
  - `strip_prefix`: `true`
- **Request**: `POST /kite/postback/status`
- **Expected Outcome**: Upstream receives `POST /postback/status`.

### TC-059-04: Non-Subpath Target Regression
- **Configuration**:
  - `prefix`: `"/kite/api"`
  - `target`: `http://upstream:8080`
  - `strip_prefix`: `true`
- **Request 1**: `GET /kite/api` $\rightarrow$ upstream receives `GET /`
- **Request 2**: `GET /kite/api/` $\rightarrow$ upstream receives `GET /`
- **Request 3**: `GET /kite/api/v1/trades` $\rightarrow$ upstream receives `GET /v1/trades`

### TC-059-05: Target Explicit Trailing Slash Preservation
- **Configuration**:
  - `prefix`: `"/kite/postback"`
  - `target`: `http://upstream:8082/postback/`
  - `strip_prefix`: `true`
- **Request**: `POST /kite/postback`
- **Expected Outcome**: Upstream receives `POST /postback/` (target explicitly specified trailing slash).

### TC-059-06: StripPrefix Disabled (`strip_prefix: false`)
- **Configuration**:
  - `prefix`: `"/kite/postback"`
  - `target`: `http://upstream:8082`
  - `strip_prefix`: `false`
- **Request**: `POST /kite/postback`
- **Expected Outcome**: Upstream receives `POST /kite/postback`.
