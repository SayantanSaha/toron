# TC-072 - Verification of HTTP Parameter Pollution (HPP) Mitigation in Target Query Merging

## Objective

Verify that `pkg/proxy/proxy.go` enforces strict target URL query parameter precedence over client-supplied query parameters, discards colliding keys and duplicate parameter injection attempts, strips semicolon-delimited delimiter confusion payloads, and preserves non-colliding client parameters with intact percent-encoding and formatting.

## Test Cases

### TC-072-01: Colliding Query Parameter Stripping & Target Precedence
- **Setup**: Create `ReverseProxy` with upstream target `http://upstream/api?role=guest&env=production`.
- **Action**: Client sends request with `GET /api?role=admin&user=alice&action=view`.
- **Expected Outcome**:
  - Upstream receives `role=guest&env=production&user=alice&action=view`.
  - The client's attempt to overwrite `role=guest` with `role=admin` is stripped.
  - Non-colliding parameters `user=alice` and `action=view` are forwarded intact.

### TC-072-02: Duplicate Colliding Parameter Injection Defense
- **Setup**: Upstream target has `http://upstream/api?role=guest&env=production`.
- **Action**: Client sends multiple duplicate parameters `GET /api?role=admin&role=root&env=dev`.
- **Expected Outcome**:
  - Upstream receives strictly `role=guest&env=production`.
  - All colliding occurrences of `role` and `env` are discarded.
  - No trailing delimiters or duplicate keys are generated.

### TC-072-03: Semicolon Delimiter Injection Prevention
- **Setup**: Upstream target has `http://upstream/api?role=guest&env=production`.
- **Action**: Client sends semicolon-delimited subpart attempt `GET /api?user=alice&other=1;role=admin`.
- **Expected Outcome**:
  - Upstream receives `role=guest&env=production&user=alice`.
  - The segment containing `;role=admin` is recognized as a collision and discarded.

### TC-072-04: Verbatim Forwarding When Target Has No Query Parameters
- **Setup**: Upstream target has `http://upstream/plain` (no query parameters).
- **Action**: Client sends `GET /plain?q=hello+world&debug`.
- **Expected Outcome**:
  - Upstream receives `q=hello+world&debug` verbatim without mutation or key reordering.
