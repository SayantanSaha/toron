# REQ-047 - Native Zero-Dependency Kubernetes Ingress Controller

## Description

Toron Edge Gateway MUST provide a native, zero-dependency Kubernetes Ingress Controller (`pkg/ingress`) capable of discovering `networking.k8s.io/v1` `Ingress`, `Service`, `Endpoints`, and TLS `Secret` resources from the Kubernetes API server and translating them into dynamic routing matrix entries and mTLS/SNI configurations in `router.Router` with zero downtime.

## Acceptance Criteria

1. **Zero External Dependencies**: The controller MUST communicate with the Kubernetes API server using Go stdlib `net/http`, `crypto/tls`, and `encoding/json` only, without importing `k8s.io/client-go`.
2. **In-Cluster & Out-of-Cluster Auth**: The controller MUST support in-cluster ServiceAccount token & CA certificate loading (`/var/run/secrets/kubernetes.io/serviceaccount`) as well as custom kubeconfig / API server endpoints.
3. **IngressClass Filtering**: The controller MUST process Ingress resources matching `ingressClassName: toron` (or `kubernetes.io/ingress.class: "toron"`).
4. **Real-Time Resource Sync**: The controller MUST watch Ingress and Endpoints event streams (`watch=true`) and dynamically update `router.Router` load balancing targets upon pod scaling, deployment updates, or service endpoint shifts.
