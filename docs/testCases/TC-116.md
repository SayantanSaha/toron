# TC-116 - Test Specification for Layered Route-Aware Path Traversal Defense Architecture (CWE-22)

## 1. Test Suite Objectives & Scope

This specification defines the rigorous verification suite for Toron's **Layered Route-Aware Path Traversal Defense Architecture (CWE-22)** as specified in [`REQ-116`](file:///Users/sneha/Developer/toron-research/toron/docs/requirements/REQ-116.md), [`ADR-116`](file:///Users/sneha/Developer/toron-research/toron/docs/architecture/ADR-116.md), and broken down in [`TASK-139`](file:///Users/sneha/Developer/toron-research/toron/docs/tasks/TASK-139.md).

### 1.1 Architectural Vulnerability Addressed
Prior to this architecture, automated differential fuzzer evaluation in `benchmarks/results/differential_fuzz_report.md` achieved **89.47% (17/19)** pass rate due to failures in `TRAVERSAL-001` (Raw dot-dot traversal) and `TRAVERSAL-002` (Uppercase percent-encoded `%2E%2E` traversal). Requests targeting static routes with directory traversal probes were prematurely canonicalized by `cleanRequestPath` in `Router.ServeHTTP` prior to route matching, causing:
1. **Routing Desynchronization**: Transformed paths missed the prefix route and fell through to `r.NotFound` (`404 Not Found`) with an open persistent connection (`Connection: keep-alive`).
2. **Dead-Code Contradiction**: The static directory boundary escape guard in `createStaticHandler` (`filepath.Rel` checking for `..`) was rendered unreachable dead code.
3. **WAF Inspection Blind Spot**: `WAFEngine.InspectToron` inspected sanitized `req.Path`, missing raw dot-dot sequences on the wire URI.

### 1.2 Target Components & Defense Layers
The test suite systematically validates the two-layered defense-in-depth model across three core subsystems:
1. **Layer 1: Layer 7 WAF Raw Wire URI Inspection (`pkg/waf/`)**:
   - Extraction of uncleaned wire path from `req.RequestURI` (stripping query string and fragment).
   - Dual-path pattern evaluation across raw wire URL path and unescaped/normalized URL path (`url.PathUnescape`).
   - Active blocking with `403 Forbidden`, `Connection: close`, JSON payload (`FormatBlockedResponse`), and structured audit logging.
2. **Layer 2: Route-Aware Static Prefix Escape Guard (`pkg/router/`)**:
   - Router-level prefix boundary validation before falling back to `NotFound`.
   - Detection of requests targeting registered static prefix routes ($P$) where canonical path (`cleanRequestPath`) escapes outside $P$.
   - Active rejection with `403 Forbidden: Path Traversal Disallowed` and `Connection: close` without WAF dependency.
   - Strict preservation of ADR-062 canonicalization on non-static routes (exact API and upstream reverse proxy routes).
3. **Differential Protocol Security Fuzzer Realignment (`benchmarks/fuzzer/`)**:
   - Realignment of test oracle in `diff_fuzzer.go` for `TRAVERSAL-001..003` with `ExpectClose: true`.
   - Elevation of protocol security fuzzer pass rate to **100.0% (19/19)**.
4. **Cross-Cutting Invariants**:
   - Sub-microsecond rejection latency budget (Mean $< 300\ \mu\text{s}$, Median $< 70\ \mu\text{s}$).
   - Race detector cleanliness under `go test -race -count=1 ./...`.

## 3. Test Cases Specification

### TC-116-01: WAF Raw Wire URI Dot-Dot Traversal Inspection
- **Subsystem**: `pkg/waf/`
- **Source Target**: `pkg/waf/waf.go` (`InspectToron`, `inspectInternal`), `pkg/waf/waf_test.go`
- **Objective**: Verify that `WAFEngine.InspectToron` extracts the raw wire path from `req.RequestURI` (stripping query strings and fragments), evaluates URL-scoped threat rules against both raw and unescaped representations, detects dot-dot traversal sequences, and blocks the request with `403 Forbidden` and `Connection: close`.
- **Preconditions**:
  - `WAFEngine` initialized with `DefaultConfig()` in `enforce` mode with `AnomalyThreshold = 5`.
  - Rule `TRAVERSAL-001` loaded with score 5.
- **Test Data**:
  1. `req.RequestURI = "/internal/dashboard/../../canary_traversal.txt"`
  2. `req.RequestURI = "/internal/dashboard/%2E%2E/%2E%2E/canary_traversal.txt"`
  3. `req.RequestURI = "/internal/dashboard/%2e%2e/%2e%2e/canary_traversal.txt?query=test#section1"`
  4. `req.RequestURI = "/assets/..%2f..%2fetc/passwd"`
- **Execution Steps**:
  1. Construct `httpparser.Request` for each test payload, ensuring `req.RequestURI` contains the wire string and `req.Path` contains canonicalized or uncleaned path.
  2. Invoke `blocked, score, matched, err := engine.InspectToron(req)`.
  3. Format response using `FormatBlockedResponse(score, matched)`.
- **Expected Results**:
  - `err` is `nil`.
  - `blocked` is `true`.
  - `score` $\ge 5$.
  - `matched` contains rule ID `"TRAVERSAL-001"`.
  - Formatted JSON body contains `"error":"Forbidden"` and references `"TRAVERSAL-001"`.
- **Traceability**: `REQ-116` (FR-1), `ADR-116` (§2.1), `TASK-139.1`.

### TC-116-03: Router Route-Aware Static Prefix Escape Guard - Raw Dot-Dot Traversal
- **Subsystem**: `pkg/router/`
- **Source Target**: `pkg/router/router.go` (`ServeHTTP`), `pkg/router/router_test.go` (`TestRouter_RouteAwareStaticPrefixEscapeGuard`)
- **Objective**: Verify that when WAF middleware is omitted/disabled, the router's prefix dispatch layer independently identifies raw dot-dot sequences escaping a static mount boundary and actively rejects with `403 Forbidden: Path Traversal Disallowed` and `Connection: close`.
- **Preconditions**:
  - Router instance created without WAF middleware.
  - Temporary static directory mounted at prefix `/internal/dashboard` via `r.Static("/internal/dashboard", tempDir)`.
  - Canary file `canary_traversal.txt` created outside `tempDir`.
- **Test Data**:
  - Ingress request: `GET /internal/dashboard/../../canary_traversal.txt HTTP/1.1`
  - `req.RequestURI = "/internal/dashboard/../../canary_traversal.txt"`
  - `req.Path = "/internal/dashboard/../../canary_traversal.txt"`
- **Execution Steps**:
  1. Construct `httpparser.Request` and `httpparser.Response`.
  2. Invoke `r.ServeHTTP(req, res)`.
- **Expected Results**:
  - HTTP Status Code: `403 Forbidden` (`http.StatusForbidden`).
  - Response Header `Connection`: `"close"`.
  - Response Header `Content-Type`: `"application/json"`.
  - Response Body: `{"error":"403 Forbidden: Path Traversal Disallowed"}`.
  - Status is NOT `404 Not Found` (eliminating the dead-code contradiction).
  - Canary content is NOT returned.
- **Traceability**: `REQ-116` (FR-2), `ADR-116` (§2.2), `TASK-139.2`.
