# SR-057 - Security Review of Query Parameter Forwarding and Ingress Normalization

## Description

Security assessment of query parameter preservation and ingress adapter normalization. The review evaluates WAF inspection effectiveness on query parameters, potential query parameter injection vulnerabilities, HTTP request smuggling vectors, and log injection defenses.

## Scope

- Files reviewed:
  - `pkg/httpparser/request.go`
  - `pkg/server/server.go`
  - `pkg/sidecar/proxy.go`
  - `pkg/proxy/proxy.go`
  - `pkg/router/router.go`

## Security Evaluation & Analysis

1. **WAF Inspection Integrity**:
   - The WAF engine inspects `req.QueryParams` and `req.RequestURI`.
   - By ensuring `req.QueryParams` is consistently populated in `NewRequestFromStd` across HTTP/2 and HTTP/3, WAF query parameter inspection rules (SQL injection, XSS, command injection in query strings) are guaranteed to execute reliably regardless of protocol.

2. **Query Parameter Smuggling & Injection**:
   - Upstream queries are concatenated using clean delimiter boundaries (`&`).
   - Standard Go `http.NewRequest` enforces RFC 7230 validation on the generated URI, preventing illegal character injections.

3. **Access Log Sanitization**:
   - Log entries use structured formats (JSON) or standard Combined log formatting where CRLF characters in request lines are escaped, preventing log injection/splitting.

## Conclusion

No security vulnerabilities identified. The implementation is approved.
