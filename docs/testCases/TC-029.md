# TC-029 - Token Bucket Rate Limiting Middleware Verification

## Test Objectives

1. Verify `pkg/config` `ParseRateLimit` correctly parses rate limit strings (e.g. `10/sec`, `100/min`, `1000/hour`).
2. Verify `TokenBucket` in `pkg/router/rate_limiter.go` allows requests up to capacity limit and rejects excess requests.
3. Verify rate limit middleware returns HTTP status `429 Too Many Requests` and `Retry-After` header when limit is exceeded.
4. Verify requests from different IP addresses or API keys maintain independent token buckets.
5. Verify all Go unit tests pass cleanly (`go test ./...`).
