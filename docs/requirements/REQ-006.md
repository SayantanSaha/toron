# REQ-006 - Static File Serving and Asset Delivery

## Description

The Toron server shall provide a static file handler capable of serving static web assets (HTML, CSS, JS, images, fonts) from a designated file system directory.

## Acceptance Criteria

- Serves static files matching request paths under a configured URL prefix (e.g., `/public/*` or `/`).
- Automatically resolves `index.html` when a directory path is requested.
- Detects and sets appropriate `Content-Type` headers based on file extensions.
- Strictly prevents Directory Traversal / Path Traversal attacks (`../`).
- Returns HTTP `404 Not Found` for non-existent files and `403 Forbidden` for inaccessible/traversal attempts.

## Rationale

Enables Toron to serve complete frontend static web applications (HTML/CSS/JS single-page or multi-page sites) alongside REST APIs.

## Constraints

- Path sanitization must use `filepath.Clean` and verify rooted directory boundaries.
