# REQ-033 - ACME HTTP-01 and TLS-ALPN-01 Challenge Handlers for Zero-Touch Production SSL Provisioning

## Description

The Toron web server shall integrate an Automated Certificate Management Environment (ACME) engine supporting HTTP-01 and TLS-ALPN-01 challenge handlers for zero-touch automated issuance, caching, and background renewal of production TLS/SSL certificates from ACME certificate authorities (e.g., Let's Encrypt, ZeroSSL).

The ACME engine shall:
1. Intercept `/.well-known/acme-challenge/{token}` request paths for `HTTP-01` validation.
2. Negotiate ALPN `acme-tls/1` for `TLS-ALPN-01` validation.
3. Automatically cache account keys and issued certificates on disk (`cache_dir`).
4. Perform background certificate expiration checks and trigger non-disruptive automated renewals prior to certificate expiry.

## Acceptance Criteria

- `pkg/acme`: `ACMEManager` implements HTTP-01 challenge responder (`/.well-known/acme-challenge/`), TLS-ALPN-01 responder (`acme-tls/1`), token key authorization hashing, and disk caching.
- `pkg/config`: `config.yaml` supports `server.acme` properties (`enabled`, `directory_url`, `email`, `domains`, `cache_dir`, `challenge_type`).
- `pkg/server`: TLS configuration dynamically retrieves ACME certificates via `GetCertificate` callback and routes HTTP-01 challenge tokens on port 80/8080.
- Automated unit and integration tests in `pkg/acme` and `pkg/server` pass cleanly.

## Rationale

Zero-touch ACME production SSL issuance eliminates manual certificate deployment and prevents service outages caused by expired TLS certificates.
