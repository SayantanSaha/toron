# TC-101 - Verification Suite for Physical TCP Socket Termination in Differential Fuzzer

## 1. Test Suite Objectives

Verify that `benchmarks/fuzzer/diff_fuzzer.go` reliably detects physical TCP socket closures, enforces `ExpectClose` invariant assertions, preserves latency measurement fidelity, and exports accurate connection state data in both JSON and Markdown formats.

## 2. Test Cases

### TC-101-01: Verification of Closed Connection Following Error Response
- **Objective**: Confirm that when a mock server writes an HTTP error response (status line + headers) and closes the socket (`c.Close()`), `verifySocketClosed` returns `true`.
- **Expected Outcome**: `result.ConnectionClose == true`, `result.Passed == true`.

### TC-101-02: Verification of Keep-Alive Connection Detection
- **Objective**: Confirm that when a mock server writes an HTTP response with `Connection: keep-alive` and keeps the socket open, `verifySocketClosed` returns `false`.
- **Expected Outcome**: `result.ConnectionClose == false`, `result.Passed == true` (for `ExpectClose: false`).

### TC-101-03: Invariant Failure When `ExpectClose: true` but Connection Remains Open
- **Objective**: Confirm that if `tc.ExpectClose == true` and the mock server returns the expected status code but does not close the connection, `executeRawTest` marks the test as failed.
- **Expected Outcome**: `result.Passed == false`, `result.FailureReason` contains "connection remained open".

### TC-101-04: Isolation of Rejection Latency From Probe Deadline
- **Objective**: Verify that `result.LatencyUs` reflects only the duration until the response status line was received and is not inflated by the 250ms socket probe deadline.
- **Expected Outcome**: `result.LatencyUs < 100000` (substantially less than the 250,000 µs probe timeout).

### TC-101-05: Markdown and JSON Report Generation Integrity
- **Objective**: Verify that reports contain the `Conn Closed` column and valid JSON `"connection_closed"` booleans.
- **Expected Outcome**: Reports render without error and accurately depict socket state.
