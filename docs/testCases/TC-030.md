# TC-030 - Sticky Session Load Balancing Verification

## Test Objectives

1. Verify `NewLoadBalancer` constructs `StickyCookieBalancer` for `sticky_cookie` and `IPHashBalancer` for `ip_hash`.
2. Verify `StickyCookieBalancer` injects `Set-Cookie` header on initial request and routes subsequent requests with matching cookie to the same target node.
3. Verify `IPHashBalancer` consistently maps requests from identical client IP addresses to the same backend node.
4. Verify fallback to an alternative healthy target when the pinned sticky node trips the circuit breaker (`StateOpen`).
5. Verify all Go unit tests pass cleanly (`go test ./...`).
