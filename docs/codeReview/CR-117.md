## 3. Detailed Component Findings

### 3.1 Reverse Proxy Configurations
- **Toron**: Configured with 256 worker pools, disabled WAF/cache/compression for unthrottled baseline measurement, and upstream persistent connections.
- **NGINX**: Configured with `worker_processes auto`, `multi_accept on`, `keepalive 128` upstream pools, and trailing-slash prefix stripping.
- **Traefik**: Configured with file provider, `StripPrefix` middlewares, and `loadBalancer` services with connection reuse.
- **Caddy**: Configured with `handle_path` prefix stripping and `reverse_proxy` transport keepalives.
- **HAProxy**: Configured with `backend`-level `http-request replace-path` ensuring frontend route matching and prefix removal before proxying.

### 3.2 Benchmark Runner & Metrics
- The runner collects high-resolution microsecond response timings and produces calibrated percentile distributions.
- In-flight cancellations upon duration expiry are properly segregated from upstream communication failures.
- `docker_compare_report.json` and `docker_compare_report.md` provide full empirical transparency.
