# TC-053: Test Cases for Dynamic Upstream Health & Dashboard Telemetry

## Test Cases

### TC-053.1: Dynamic Upstream Health Extraction
- **Action**: Register multiple proxy routes on `router.Router` with distinct targets (e.g. `http://127.0.0.1:9991`, `http://127.0.0.1:9992`). Call `GET /internal/api/upstreams/health`.
- **Expected**: JSON response contains only the actively registered target ports with their respective route names and health states.

### TC-053.2: Empty Upstream Handling
- **Action**: Register only static routes without upstream targets. Call `GET /internal/api/upstreams/health`.
- **Expected**: JSON returns `{"upstreams": []}` cleanly with HTTP 200 OK.

### TC-053.3: Dynamic Route Options in Tester
- **Action**: Load dashboard with custom route `/my-service/v1` with `host: "api.mycorp.internal"`.
- **Expected**: Tester dropdown contains `/my-service/v1` and selecting it automatically populates the `Host` input with `api.mycorp.internal`.
