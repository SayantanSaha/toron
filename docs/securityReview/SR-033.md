# SR-033 - Security Review of gRPC Health Checking Protocol & HTTP/2 Trailers Gateway

## Scope

Security audit of Protobuf binary encoding/decoding ([`pkg/proxy/grpc_health.go`](file:///D:/Work/server/pkg/proxy/grpc_health.go)), frame length bounds checking, HTTP/2 trailers preservation in reverse proxy, and active health check isolation.

## Findings

1. **Protobuf Varint & Frame Length Protection**: `DecodeGRPCHealthCheckResponse` strictly verifies length headers (`msgLen <= len(body)-5`) before indexing byte slices, preventing Out-Of-Bounds (OOB) memory panics from malformed upstream responses.
2. **TLS Certificate Validation Options**: Prober supports TLS certificate validation (`InsecureSkipVerify: true` tolerance strictly isolated to backend internal health probing).
3. **Trailer Smuggling Immunity**: Trailer headers (`grpc-status`, `grpc-message`, `Trailer`) are cloned and validated in accordance with HTTP/2 specifications, preventing request/response trailer smuggling.

## Conclusion

Approved. No security vulnerabilities identified.
