## Technical Evaluation

### 1. Architectural Adherence to ADR-051 & Functional Compliance (REQ-056 / TASK-056)

- **Native Static Router Architecture**: Consistent with Option 3 in [`ADR-051`](file:///Users/sneha/Developer/toron/docs/architecture/ADR-051.md), SPA fallback logic is implemented directly within Toron's static route handler pipeline without requiring external reverse proxy containers (Option 1) or global status code interceptors (Option 2).
- **Declarative Route Configuration**: [`ProxyRouteConfig`](file:///Users/sneha/Developer/toron/pkg/config/config.go#L230) cleanly defines `SPA` (`bool`) and `Fallback` (`string`) with standard `yaml` and `json` tags.
- **Implicit SPA Activation**: Evaluated via `spaMode := opts.SPA || strings.TrimSpace(opts.Fallback) != ""` in [`pkg/router/router.go:320`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L320), correctly activating SPA routing whenever a non-empty `fallback` document is configured, even if `spa: true` was omitted.
- **Default Document Resolution**: When `opts.Fallback` is empty, whitespace, or relative navigation tokens (`.` or `..`), it defaults reliably to `"index.html"`.
- **HTTP Method Guard**: Requests with methods other than `GET` and `HEAD` are rejected with `405 Method Not Allowed` at handler entry ([`pkg/router/router.go:272-275`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L272-L275)), upholding HTTP specification conformance.
- **HEAD Method Handling**: When an SPA virtual navigation route receives an HTTP `HEAD` request, status code `200 OK` and `Content-Type: text/html; charset=utf-8` are emitted while suppressing the body payload ([`pkg/router/router.go:352-354`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L352-L354)).

### 2. Code Quality, Go Idioms & Separation of Concerns

- **Clean Closure Encapsulation**: The fallback resolution routine is cleanly encapsulated as a local closure `serveFallback := func()` inside [`createStaticHandler`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L319). This avoids redundant code across missing file paths, missing directory indices, and unreadable targets while capturing route options (`opts`) and directory paths (`absDir`, `realAbsDir`).
- **Standard Library Utilization**: Pure Go standard library packages (`path/filepath`, `strings`, `net/http`, `os`, `mime`) are employed with zero external dependencies, staying true to Toron's core design philosophy.
- **Option Forwarding Pipeline**: Option forwarding follows Toron's existing architecture:
  `ProxyRouteConfig` (in `pkg/config`) $\rightarrow$ `ProxyOptions` (in `pkg/proxy`) $\rightarrow$ `RoutePrefix` / `createStaticHandler` (in `pkg/router`).
- **Error Propagation**: Non-existence errors (`os.IsNotExist(err)`) cleanly trigger fallback evaluation, while unexpected filesystem errors return `500 Internal Server Error` without leaking OS-level path or permission diagnostics.

### 3. Path Traversal & Symlink Boundary Robustness

The implementation enforces defense-in-depth against directory traversal (CWE-22) and symlink escapes (CWE-59):

1. **Input Normalization & Lexical Verification**:
   - For primary request paths:
     ```go
     cleanRel := filepath.Clean(filepath.FromSlash(strings.TrimPrefix(fileRelPath, "/")))
     targetPath := filepath.Join(absDir, cleanRel)
     relFromDir, err := filepath.Rel(absDir, targetPath)
     if err != nil || strings.HasPrefix(relFromDir, "..") || (strings.HasPrefix(relFromDir, ".") && len(relFromDir) > 1 && relFromDir[1] == '.') {
         // Return 403 Forbidden
     }
     ```
   - Normalization with `filepath.FromSlash` and `filepath.Clean` eliminates redundant separators and relative tokens before joining.
   - `filepath.Rel` verifies that the target remains within the static root directory.

2. **Symlink Resolution Containment**:
   - `filepath.EvalSymlinks` resolves symlink destinations against the canonicalized root `realAbsDir`.
   - Any breakout pointing to external directories (e.g., `/etc` or `/var`) is blocked with `403 Forbidden: Symlink Path Traversal Disallowed`.

3. **Fallback Filename Sanitization**:
   - `fallbackName := filepath.Base(opts.Fallback)` forcefully strips any leading path elements or directory separators.
   - Traversal tokens (`.`, `..`) are replaced with `"index.html"`.
   - The resolved `fallbackPath` is re-validated through the identical lexical `filepath.Rel` and symlink `filepath.EvalSymlinks` checks as primary file requests.
   - Tested and verified against malicious configurations (`Fallback: "../../../../etc/passwd"`) in `TestRouter_SPA_SecurityPathTraversal`.

### 4. Asset Masking Prevention (`filepath.Ext(relPath) == ""`)

A critical requirement of [`REQ-056`](file:///Users/sneha/Developer/toron/docs/requirements/REQ-056.md) and [`ADR-051`](file:///Users/sneha/Developer/toron/docs/architecture/ADR-051.md) is preventing asset masking:
- **Separation between Navigation and Assets**:
  - `relPath` preserves the original URL relative path under the prefix (e.g. `/assets/missing.js`, `/logo.png`, `/users/42`).
  - `filepath.Ext(relPath) == ""` identifies virtual client-side navigation routes, which proceed to serve the fallback HTML document with `200 OK`.
  - `filepath.Ext(relPath) != ""` identifies physical asset requests. If absent on disk, the router bypasses fallback and executes `r.NotFound(req, res)` (returning HTTP 404 Not Found).
- **Impact**: Missing `.js`, `.css`, `.png`, and `.json` requests will never receive an HTML document. This prevents frontend runtime syntax crashes (`Uncaught SyntaxError: Unexpected token '<'`), stylesheet MIME rejection, and false 200 OK reporting in CDN/APM telemetry.
- **MIME & Charset Correctness**: When the fallback document is served, `Content-Type: text/html; charset=utf-8` is explicitly asserted, preventing MIME sniffing and UTF-7 XSS vulnerabilities.

### 5. Concurrency Safety & Performance

- **Thread Safety**: All route additions are synchronized under `r.mu sync.RWMutex`. During request serving, `r.mu.RLock()` is acquired. Handlers access read-only configuration options (`opts.SPA`, `opts.Fallback`) without shared mutable state.
- **Minimal Filesystem I/O Overhead**: Fallback resolution is strictly reactive; it executes only upon filesystem miss (`os.IsNotExist(err)`). Valid physical file requests experience zero additional syscall overhead.
- **Race Detector Clean**: Running `go test -race ./...` reported zero data races across all 16 workspace packages.

## Findings

### Finding 1: Fallback Document Scope Restricted to Static Root Directory

- **Severity**: Informational
- **Location**: [`pkg/router/router.go:322-326`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L322-L326)
- **Related Artifact**: `TASK-056`, `ADR-051`, `SR-052`
- **Description**: In `serveFallback`, `fallbackName := filepath.Base(opts.Fallback)` extracts the base filename, stripping any subpath components. For example, if an operator configures `fallback: "dist/app.html"`, it resolves to `app.html` directly under `absDir`.
- **Impact**: Ensures complete immunity against directory traversal attacks, but restricts fallback documents to the root of the static directory.
- **Recommendation**: Document in operator configuration guides that fallback documents must reside in the static directory root. No code modification required as this conforms to [`ADR-051`](file:///Users/sneha/Developer/toron/docs/architecture/ADR-051.md) Constraint 2.

### Finding 2: In-Memory Caching Opportunity for SPA Fallback Document

- **Severity**: Informational
- **Location**: [`pkg/router/router.go:348`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L348)
- **Related Artifact**: `TASK-056`, `ADR-051`
- **Description**: On each SPA fallback request, `os.ReadFile(fallbackPath)` reads the fallback file from disk. Under extreme traffic spikes where thousands of virtual client-side navigation requests hit the server concurrently, caching the fallback file content in memory (or relying on Toron's response cache middleware) would reduce disk I/O syscalls.
- **Impact**: Under standard workloads, operating system page caching minimizes disk latency. For high-throughput edge deployments, in-memory caching of the entry document would yield slight throughput improvements.
- **Recommendation**: Consider caching the fallback file byte slice in the handler struct or integrating with Toron's internal cache engine in a future release.

### Finding 3: Default `X-Content-Type-Options: nosniff` Header Defense-in-Depth

- **Severity**: Informational
- **Location**: [`pkg/router/router.go:351`](file:///Users/sneha/Developer/toron/pkg/router/router.go#L351)
- **Related Artifact**: `REQ-056`, `SR-052`
- **Description**: When serving the fallback document, `Content-Type: text/html; charset=utf-8` is explicitly set. Adding `res.Header.Set("X-Content-Type-Options", "nosniff")` directly in the fallback branch would provide additional defense-in-depth against legacy browser MIME sniffing in setups where security header middleware is not configured on the route.
- **Impact**: Minimal; Toron provides dedicated `SecurityHeaders` middleware to enforce this globally.
- **Recommendation**: Consider adding `nosniff` as a default header on static HTML fallback responses.

## Positive Observations

1. **Total Immunity to Asset Masking**: Strict discrimination between extensionless routes (`filepath.Ext(relPath) == ""`) and asset files (`filepath.Ext(relPath) != ""`) prevents browser runtime syntax errors and maintains frontend observability.
2. **Robust Multi-Layered Traversal Defenses**: Employs both lexical canonicalization (`filepath.Clean`, `filepath.Rel`) and filesystem symlink evaluation (`filepath.EvalSymlinks`) on both request URIs and fallback paths.
3. **Idiomatic Clean Implementation**: The closure pattern in `createStaticHandler` is concise, readable, and avoids code duplication across directory and file miss paths.
4. **Full Backward Compatibility**: Standard static routes without `spa` or `fallback` remain completely unaffected and return standard 404 responses.
5. **Comprehensive Test Quality**: Tests use deterministic `t.TempDir()` fixtures, execute in milliseconds without sleeps, and test both explicit and implicit SPA activations.
6. **Zero Regressions & Race Freedom**: All 16 packages pass cleanly under `go test -race ./...`.
