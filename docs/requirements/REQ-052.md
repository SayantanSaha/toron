# REQ-052: Reverse Proxy Prefix Management, 3xx Redirect & Cookie Path Rewriting

## Status
- **State**: APPROVED
- **Type**: Feature / Reverse Proxy
- **Created**: 2026-08-31

## Description
Provide comprehensive reverse proxy prefix management and transparent redirect/cookie path rewriting to allow upstream microservices and legacy off-the-shelf web applications (unaware of their gateway subpath mount points) to function seamlessly when routed behind URL prefixes.

## Functional Requirements
1. **`X-Forwarded-Prefix` Header Injection**: When a route is configured with a path prefix (e.g. `prefix: "/api"`), the gateway MUST inject `X-Forwarded-Prefix: <prefix>` into all forwarded HTTP and WebSocket requests.
2. **Configurable Prefix Stripping (`strip_prefix`)**: Support an optional `strip_prefix` boolean flag on upstream routes (default: `true`). When `true`, strips the prefix before forwarding; when `false`, forwards the original full URL path.
3. **3xx `Location` Header Rewriting (`rewrite_redirects`)**: Support an optional `rewrite_redirects` boolean flag (default: `true`). When enabled, intercepts `301`, `302`, `303`, `307`, and `308` responses:
   - **Relative Redirects**: Prepend the route prefix (`/login` -> `/api/login`).
   - **Target-Internal Absolute Redirects**: Rewrite internal backend URLs (`http://127.0.0.1:9001/dashboard`) to the public gateway URL using the client's host and scheme (`https://example.com/api/dashboard`).
   - **External Third-Party Redirects**: Preserve external URLs (OAuth/CDN) without modification.
4. **`Set-Cookie` Path Scoping (`rewrite_cookie_path`)**: Support an optional `rewrite_cookie_path` boolean flag (default: `true`). When enabled, rewrites upstream `Set-Cookie: Path=/` attributes to `Path=<prefix>` to keep session cookies properly scoped to the gateway route.
5. **Configuration Schema**: Support `strip_prefix`, `rewrite_redirects`, and `rewrite_cookie_path` in `routes.yaml` (`ProxyRouteConfig`).
6. **OCI Container Label Discovery**: Support `toron.strip_prefix`, `toron.rewrite_redirects`, and `toron.rewrite_cookie_path` container labels for automatic discovery and zero-downtime routing registration.
