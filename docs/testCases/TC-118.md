# TC-118 - Verification of Disaggregated Latency Distributions and Report Formatting (HARN-02)

## 1. Test Suite Objectives & Problem Statement

### 1.1 Academic Peer Review Context & Critique (HARN-02 / REV-02)
In academic and technical review dossiers (`AER-001.md`, `MSR-001.md`, `AR-001.md`), reviewers cited methodological flaws in Section 5.2 of `docs/research/paper1_agentic_systems.tex`:
1. **Conflated Evaluation Mode**: Claims of $K=1,000$ repeated statistical trials with 50 warm-up runs were contradicted by raw benchmark data generated in single-shot mode ($K=1$, $W=0$).
2. **Percentile Mislabeling**: Mislabeled $p90$ ($712.08\ \mu\text{s}$) as $p99$, while the true tail across all runs is $2,378.00\ \mu\text{s}$.
3. **Conflation of Rejection Defense vs. Baseline Traffic**: Aggregating the 18 fail-fast rejections with the 1 benign baseline vector (`BASELINE-001`) obscured both the fail-fast defense performance and the comprehensive cross-vector profile.
4. **Suppression in Single-Shot Mode**: When $K=1$, the terminal summary and Markdown report suppressed $p50$, $p90$, and $p99$.

This test specification defines automated test cases to verify the implementation in [`benchmarks/fuzzer/diff_fuzzer.go`](file:///Users/sneha/Developer/toron-research/toron/benchmarks/fuzzer/diff_fuzzer.go).

## 2. Test Case Specifications

### TC-118-01: Cohort Disaggregation and Statistical Calculation
- **Objective**: Verify that `calculateCohortMetrics` accurately calculates mean, median ($p50$), 90th percentile ($p90$), 99th percentile ($p99$), and maximum for both sample cohorts.
- **Input Data**:
  - Sample dataset simulating the empirical 19-vector latencies:
    `[87.29, 100.29, 131.25, 148.46, 165.58, 169.58, 177.04, 179.04, 187.96, 208.75, 210.92, 238.79, 250.08, 362.13, 577.00, 582.58, 708.58, 712.08, 2378.00]`
  - Cohort A (N=18 rejections): Excludes `2378.00`.
  - Cohort B (N=19 comprehensive): All 19 samples.
- **Expected Results**:
  - Cohort A:
    - Count: 18
    - Mean: $\approx 288.75\ \mu\text{s}$
    - $p50$: Index $\lfloor 18/2 \rfloor = 9 \implies 208.75\ \mu\text{s}$
    - $p90$: Index $\lceil 0.90 \times 18 \rceil - 1 = 17 - 1 = 16 \implies 708.58\ \mu\text{s}$ (or 17 $\implies 712.08\ \mu\text{s}$)
    - Max: $712.08\ \mu\text{s}$
  - Cohort B:
    - Count: 19
    - Mean: $\approx 398.71\ \mu\text{s}$
    - $p50$: Index $\lfloor 19/2 \rfloor = 9 \implies 208.75\ \mu\text{s}$
    - $p90$: Index $\lceil 0.90 \times 19 \rceil - 1 = 18 - 1 = 17 \implies 712.08\ \mu\text{s}$
    - $p99$: Index $\lceil 0.99 \times 19 \rceil - 1 = 19 - 1 = 18 \implies 2,378.00\ \mu\text{s}$
    - Max: $2,378.00\ \mu\text{s}$

### TC-118-02: Unconditional Distribution Output in Terminal Summary
- **Objective**: Verify that the execution summary printed to stdout includes both Fail-Fast Defense Latency and Cross-Vector Comprehensive Latency when `*trials == 1` and when `*trials > 1`.
- **Method**: Capture stdout or test formatting helper functions.
- **Expected Results**: Output contains distinct lines for Fail-Fast Defense and Cross-Vector Comprehensive Latency with $p50$, $p90$, and $p99$.

### TC-118-03: Calibrated Markdown Report Generation
- **Objective**: Verify that `differential_fuzz_report.md` generation includes:
  - Fail-Fast Rejection Latency: Mean, Median (p50), Tail Latency (p90), Max.
  - Cross-Vector Comprehensive Latency: Mean, Median (p50), Percentile (p90), Tail Latency (p99), Max.
  - Distinct column headers for single-shot and repeated trials.
- **Expected Results**: The Markdown string contains no ambiguous combined labels and clearly distinguishes $p90$ ($712.08\ \mu\text{s}$) from $p99$ ($2,378.00\ \mu\text{s}$).

### TC-118-04: JSON Schema Serialization & Backwards Compatibility
- **Objective**: Verify that serializing `DifferentialReport` to JSON produces:
  - Top-level fields: `average_latency_us`, `median_latency_us`, `p90_latency_us`, `p99_latency_us`.
  - Nested objects: `fail_fast_defense` and `comprehensive_suite` with correct metrics.
- **Expected Results**: Unmarshaling JSON yields valid non-zero values for all fields without loss of precision.

### TC-118-05: Live Invariant Test Suite Execution & Artifact Validation
- **Objective**: Execute the actual 19-vector suite against a mock or live server and verify generated JSON and Markdown files.
- **Expected Results**: All 19 tests pass (100% pass rate) and report artifacts reflect calibrated distributions.
