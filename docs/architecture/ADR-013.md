# ADR-013 - Subpath Static Routing and Relative Asset Resolution Architecture

## Context

When configuring static site hosting under a non-root subpath prefix (e.g., `prefix: "/internal/dashboard"` in `config.yaml`), absolute asset URLs (`/style.css`, `/app.js`) fail to resolve because browsers request them at domain root `/`. Furthermore, requests without trailing slashes cause browser relative URL calculations to fail.

## Decision

1. **Relative Asset Links**: Update `public/index.html` references to `./style.css` and `./app.js`.
2. **Canonical Trailing Slash Redirect**:
   - In `pkg/router/router.go`, when `req.Path == cleanPrefix` (e.g. `/internal/dashboard`), the server responds with `302 Found` and `Location: /internal/dashboard/`.
   - Browser follows redirect to `/internal/dashboard/`, establishing `/internal/dashboard/` as the document base URI for relative assets.

## Consequences

- **Positive**: Enables zero-configuration subpath mounting for static web applications.
