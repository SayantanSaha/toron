# TC-141 - Verification Test Cases for Modular ES Dashboard Architecture and Feature Parity

## 1. Overview & Test Objectives

Verify that the modular ECMAScript Modules (`ESM`) architecture designed under [`REQ-141`](../requirements/REQ-141.md), [`TASK-164`](../tasks/TASK-164.md), and [`ADR-141`](../architecture/ADR-141.md) satisfies all structural, functional, behavioral, performance, and security requirements. Ensure 100% parity with existing telemetry metric derivations, view rendering, drawer interactivity, and automated test execution without adding external dependencies or build pipelines.

## 3. Detailed Verification Procedures

### TC-141-01: Module Structure Verification
Verify that `public/js/` contains:
- `app.js`, `state.js`, `utils.js`, `api.js`, `model.js`
- `components/icons.js`, `components/charts.js`, `components/sankey.js`, `components/drawer.js`
- `views/overview.js`, `views/routes.js`, `views/upstreams.js`, `views/logs.js`, `views/certs.js`, `views/modules.js`, `views/alerts.js`, `views/console.js`

### TC-141-02: ESM Import/Export Graph Validity
Confirm that:
- Every `import ... from './...'` path references an existing relative `.js` file with an explicit file extension.
- No circular dependencies exist between layers.
- Modules export expected functions and objects.

### TC-141-03: Zero External Dependencies & Footprint
Verify that:
- No `package.json` dependencies are added to runtime.
- No bundler configuration is required.
- [Dockerfile](../../Dockerfile) remains a Go-only builder.
- Total JavaScript assets under `public/js/` do not exceed 100 KB.

### TC-141-04 to 06: Telemetry Data Model Invariants
Run the automated fixture suite to verify that `model.buildDataModel()` produces identical output for:
- Distinct route pools (`_kite_callback`, `_kite_api`, `_kite_broker`, `_kite_auth`).
- Subpath rollups (`/kite/api/v1/business` -> `/kite/api`).
- Dynamic health probe latency bindings and p95 calculations.
- Error rate tone escalations.

### TC-141-09: Automated Test Suite Execution
Execute `node tests/dashboard_telemetry_test.js` and verify all test assertions pass cleanly with zero errors.
