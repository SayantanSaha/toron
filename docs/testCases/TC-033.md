# TC-033 - ACME HTTP-01 and TLS-ALPN-01 Challenge Verification

## Test Objectives

1. Verify `ACMEManager.ComputeKeyAuthorization()` returns valid token thumbprint concatenation.
2. Verify HTTP-01 challenge handler responds to `GET /.well-known/acme-challenge/{token}` with HTTP status `200 OK` and key authorization payload.
3. Verify TLS-ALPN-01 challenge responder constructs a valid ALPN `acme-tls/1` certificate with OID `1.3.6.1.5.5.7.1.31`.
4. Verify certificate caching creates, loads, and validates PEM cert/key files from `cache_dir`.
5. Verify all Go unit tests pass cleanly (`go test ./...`).
