# SR-021 - Security Review of TCP and UDP Layer 4 Transport Layer Proxying

## Scope

Security review of raw TCP stream proxying ([`pkg/proxy/tcp.go`](file:///D:/Work/server/pkg/proxy/tcp.go)), UDP datagram proxying ([`pkg/proxy/udp.go`](file:///D:/Work/server/pkg/proxy/udp.go)), target endpoint address sanitization, connection timeouts, and socket resource lifecycle management.

## Findings

1. **Target Address Sanitization**: Target backend strings are sanitized by stripping protocol prefixes (`http://`, `https://`, `tcp://`, `udp://`) to prevent invalid network dial strings.
2. **Socket Timeout Guards**: TCP dialing enforces `net.DialTimeout`, and UDP reads enforce socket deadlines to prevent hung sockets or unreleased goroutines.
3. **Stream Teardown**: Bi-directional TCP stream copying uses `sync.WaitGroup` and `CloseWrite` to ensure socket resources are released cleanly on completion or error.

## Conclusion

Approved. No security vulnerabilities identified.
