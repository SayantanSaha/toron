# TC-115 - Test Specification for 10-Task Controlled Ablation Experiment Suite (BMK-05)

## 1. Test Suite Objectives

Verify that the 10-Task Controlled Ablation Experiment Suite (`BMK-05`):
1. Correctly models and archives experimental data for all 10 evaluated tasks (`TASK-061` to `TASK-070`) across both experimental conditions (Condition A: Multi-Agent with ADRs vs. Condition B: Direct Single-Agent Prompting).
2. Computes the 5 core comparative metrics with mathematical rigor:
   - Specification Drift Rate (%)
   - Defect Injection Count
   - Unit & Integration Test Pass Rate (%)
   - Token Expenditure & Cost Overhead Ratio
   - Reviewer Flaw Arrest Rate (%)
3. Generates complete, valid machine-readable JSON (`benchmarks/results/ablation_study_report.json`).
4. Generates publication-grade Markdown (`benchmarks/results/ablation_study_report.md`) with executive summaries and qualitative failure mode analyses.
5. Executes cleanly with zero third-party dependencies and zero race warnings under `go test -race -count=1 ./benchmarks/ablation/...`.

---

## 2. Test Cases

### TC-115-01: Task Catalog & Data Model Completeness
- **Target**: `benchmarks/ablation/tasks.go`, `benchmarks/ablation/schema.go`
- **Methodology**: Validate that the task catalog contains exactly 10 tasks (`TASK-061` through `TASK-070`), that each task possesses a unique ID, subsystem identifier, target vulnerability, criteria list, and valid document cross-references (`REQ`, `ADR`, `TC`, `CR`, `SR`).
- **Pass Criteria**: All 10 tasks present; criteria count $\ge 2$ per task; non-empty titles and subsystem paths.

### TC-115-02: Data Archival Integrity (Condition A & Condition B)
- **Target**: `benchmarks/ablation/data/`
- **Methodology**: Verify that each task folder in `data/condition_b/` contains `prompt.txt`, `response_raw.md`, `patch.diff`, `test_execution.log`, and `telemetry.json`, and that `data/condition_a/` contains complete metadata records.
- **Pass Criteria**: All expected files exist, are readable, non-empty, and contain valid JSON where applicable.

### TC-115-03: Metric Calculation & Scoring Rigor
- **Target**: `benchmarks/ablation/runner.go`
- **Methodology**: Provide synthetic and real task evaluation inputs to verify mathematical computation of:
  - Drift Rate: $D = (N_{\text{violated}} / N_{\text{total}}) \times 100\%$
  - Defect Count: $E = \text{omissions} + \text{vulnerabilities} + \text{regressions} + \text{races}$
  - Pass Rate: $P = (N_{\text{passed}} / N_{\text{total}}) \times 100\%$
  - Flaw Arrest Rate: $A = (N_{\text{arrested}} / N_{\text{total\_premerge}}) \times 100\%$
  - Cost Ratio: $R_T = T_A / T_B$
- **Pass Criteria**: Zero division-by-zero errors; metric outputs within valid domains ($[0, 100]$ for rates, non-negative for counts and tokens).

### TC-115-04: Aggregate Statistics & Confidence Bounds
- **Target**: `benchmarks/ablation/runner.go`
- **Methodology**: Assert that aggregate statistics (sample mean $\bar{x}$, sample standard deviation $s$, and percentage improvements) are computed correctly across both cohorts.
- **Pass Criteria**: Computed means and standard deviations match expected values within $10^{-4}$ tolerance.

### TC-115-05: Machine-Readable JSON Report Output
- **Target**: `benchmarks/results/ablation_study_report.json`
- **Methodology**: Serialize evaluation results to JSON, reload via `json.Unmarshal`, and assert schema conformance.
- **Pass Criteria**: Valid JSON; schema matches `AblationReport`; all 10 task entries populated for both conditions.

### TC-115-06: Publication-Grade Markdown Report Output
- **Target**: `benchmarks/results/ablation_study_report.md`
- **Methodology**: Generate Markdown report and verify presence of required sections:
  - Executive Summary responding to `AER-001`, `MSR-001`, and `PDR-001`.
  - Task-by-task comparative metric table.
  - Statistical summary table.
  - Qualitative failure mode analysis for Condition B.
- **Pass Criteria**: Non-empty markdown containing all required section headers and markdown tables.

### TC-115-07: Concurrency & Race Cleanliness
- **Target**: `benchmarks/ablation/...`
- **Methodology**: Run `go test -race -count=1 ./benchmarks/ablation/...`.
- **Pass Criteria**: 0 race warnings, 0 failures, exit code 0.
