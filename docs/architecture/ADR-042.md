# ADR-042 - Native Zero-Dependency Kubernetes Ingress Controller Architecture

## Context

To run Toron as an Ingress Controller inside Kubernetes clusters without pulling in `k8s.io/client-go` (which imports ~150 external packages and bloats binaries by 30+ MB), Toron requires a native K8s REST API client written strictly with Go stdlib (`net/http`, `crypto/tls`, `encoding/json`).

## Decision

1. **Stdlib Kubernetes REST Client (`pkg/ingress/client.go`)**:
   - Reads ServiceAccount bearer token from `/var/run/secrets/kubernetes.io/serviceaccount/token`.
   - Loads cluster CA certificate from `/var/run/secrets/kubernetes.io/serviceaccount/ca.crt`.
   - Uses HTTP chunked transfer / line-delimited JSON streams (`?watch=true`) for resource watching.
2. **K8s Spec Translator (`pkg/ingress/translator.go`)**:
   - Converts `networking.k8s.io/v1` `HTTPIngressPath` rules (`Prefix`, `Exact`) into Toron `router.RoutePrefix` definitions.
   - Extracts base64 `tls.crt` / `tls.key` from K8s Secrets (`kubernetes.io/tls`) into SNI route certificate configurations.
3. **Event Controller (`pkg/ingress/controller.go`)**:
   - Maintains an in-memory cache of resolved `Endpoints` for each `Service` backend target.
   - Dynamically updates `router.Router` upstreams when pod IP endpoints scale or shift.

## Consequences

- **Positive**: Zero external dependencies added. Total binary size (<30MB) and fast boot time (<5ms) preserved.
- **Positive**: Full support for both in-cluster ServiceAccounts and out-of-cluster dev API servers.
- **Negative**: Requires maintaining compact JSON struct representations of target `Ingress`, `Service`, `Endpoints`, and `Secret` resources in `pkg/ingress/types.go`.
