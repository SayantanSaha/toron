# TC-001 - Event Reactor TCP Connection & Signal Lifecycle Verification

## Description

Verify that the `reactor` engine listens on a designated TCP port, accepts concurrent incoming client connections, dispatches read/write events, and shuts down gracefully without leaking goroutines or connections.

## Preconditions

- Reactor engine initialized on local TCP port (e.g. `127.0.0.1:0`).

## Test Data

- Concurrent client connections (10 simultaneous TCP clients).

## Steps

1. Start the reactor listener.
2. Dial 10 concurrent TCP connections to the listener port.
3. Send data payloads over each connection and verify echo / processing.
4. Signal graceful shutdown via `context.CancelFunc`.
5. Check that all client sockets are closed cleanly.

## Expected Results

- Connections accepted and processed without error.
- All worker goroutines terminate cleanly upon context cancellation.

## Acceptance Criteria

- Zero goroutine leaks (`goleak` check passes).
- All active connections closed gracefully.

## Rationale

Validates the core asynchronous networking engine behavior under concurrent load.

## Constraints

- Pure Go unit / integration test using `net.Dial`.
