# SR-004 - Security Review of Reverse Proxy Module

## Description

Security analysis of reverse proxy request forwarding, header injection (`X-Forwarded-*`), and error sanitization.

## Scope

- Files reviewed:
  - `pkg/proxy/proxy.go`
  - `pkg/proxy/proxy_test.go`
  - `pkg/router/router.go`
  - `cmd/toron/main.go`

## Findings

### Finding 1: Proxy Header Injection and Client IP Isolation

- Severity: Informational
- Location: `pkg/proxy/proxy.go:68`
- Related requirement: `REQ-009`
- Description: Injects `X-Forwarded-Host`, `X-Forwarded-Proto`, and `X-Forwarded-For` headers prior to dispatching outbound upstream requests.
- Impact: Provides upstream servers with client network origin metadata.

### Finding 2: Safe Error Output on Upstream Failure

- Severity: Informational
- Location: `pkg/proxy/proxy.go:94`
- Related requirement: `REQ-009`
- Description: `writeBadGateway` returns standard HTTP `502 Bad Gateway` without exposing internal memory addresses or internal system state.

## Rationale

Implementation passes security checks and enforces safe proxying boundaries.
