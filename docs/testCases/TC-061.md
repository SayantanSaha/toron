# TC-061 - Verification of HTTP Request Smuggling Prevention and Transfer-Encoding Protocol Guard

## Objective

Verify that Toron strictly rejects any request containing `Transfer-Encoding: chunked` or custom transfer codings with `HTTP 501 Not Implemented` and immediate socket connection termination, preventing HTTP Request Smuggling and connection desynchronization attacks.

## Test Cases

### TC-061-01: Standalone Transfer-Encoding Rejection in Parser
- **Input Request**: `POST /submit HTTP/1.1\r\nHost: localhost\r\nTransfer-Encoding: chunked\r\n\r\n5\r\nhello\r\n0\r\n\r\n`
- **Action**: Parse via `httpparser.ParseRequest(buf, opts)`.
- **Expected Outcome**:
  - Returns non-nil error wrapping `httpparser.ErrUnsupportedTransferEncoding`.
  - Request object is not returned.

### TC-061-02: Conflicting Content-Length and Transfer-Encoding
- **Input Request**: `POST /submit HTTP/1.1\r\nHost: localhost\r\nContent-Length: 10\r\nTransfer-Encoding: chunked\r\n\r\n0\r\n\r\n`
- **Action**: Parse via `httpparser.ParseRequest(buf, opts)`.
- **Expected Outcome**:
  - Returns non-nil error wrapping `httpparser.ErrBadRequest`.

### TC-061-03: Server HTTP 501 Response and Socket Closure Integration
- **Client Action**: Send chunked request followed by pipelined smuggled request on persistent TCP socket:
  `POST /upload HTTP/1.1\r\nHost: localhost\r\nTransfer-Encoding: chunked\r\n\r\n5\r\nhello\r\n0\r\n\r\nGET /smuggled HTTP/1.1\r\nHost: localhost\r\n\r\n`
- **Expected Outcome**:
  - Server emits `HTTP/1.1 501 Not Implemented`.
  - Server sets `Connection: close`.
  - Underlying socket is closed immediately (`io.EOF` on client read).
  - Pipelined `/smuggled` request is never parsed or executed.
