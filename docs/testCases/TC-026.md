# TC-026 - TCP and UDP Layer 4 Transport Layer Proxy Verification

## Test Objectives

1. Verify `RouteConfig` in `pkg/config` correctly parses `type: "tcp"` and `type: "udp"` routes and listener port settings.
2. Verify `TCPProxy` in `pkg/proxy/tcp.go` accepts TCP connections and bidirectionally relays bytes to upstream TCP servers.
3. Verify `UDPProxy` in `pkg/proxy/udp.go` listens for UDP datagrams and relays packets to/from upstream UDP targets.
4. Verify `Server` in `pkg/server` starts and stops auxiliary TCP and UDP listeners during server startup and shutdown.

## Executed Tests

- `TestTCPProxy_Forwarding` in `pkg/proxy/tcp_test.go`.
- `TestUDPProxy_Forwarding` in `pkg/proxy/udp_test.go`.
- `TestConfig_L4Routes` in `pkg/config/config_test.go`.
- Full project test suite execution (`go test ./...`).
