# TC-046 - Test Suite for OCI Container Auto-Discovery Engine

## Test Objectives

Verify that `pkg/discovery` correctly parses container labels, auto-probes Unix domain sockets, streams container lifecycle events, and registers/deregisters upstreams in `router.Router`.

## Executed Test Cases

1. **`TestParseContainerLabels`**:
   - Verify parsing of `toron.enable=true`, `toron.host`, `toron.prefix`, `toron.port`, `toron.weight`, and port fallbacks.
   - Result: **PASS**
2. **`TestManagerOrchestration`**:
   - Verify initial container scan, route registration, and dynamic deregistration upon `EventStop`.
   - Result: **PASS**
3. **`TestUnixRESTProviderMockServer`**:
   - Spin up a mock Unix domain socket server, issue HTTP `/containers/json`, and decode `Container` structs.
   - Result: **PASS**
4. **Race Detector Validation**:
   - Run `go test -v -race ./pkg/discovery/...`
   - Result: **PASS**
