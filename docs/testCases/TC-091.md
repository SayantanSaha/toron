# TC-091 - Test Suite for Parameterized Subpath Routing and Empty Prefix Proxy Elimination

## Test Objectives

Verify that:
1. Parameterized REST-to-gRPC endpoints route cleanly through [`Router.ServeHTTP`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L453) directly to [`Engine.HandleTranscode`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L112), returning `200 OK` (resolving [`SEC-30`](file:///Users/sneha/Developer/toron-research/toron/SECURITY_AUDIT.md#L411-L419) and Missing Security Test 5 in [`SR-081`](file:///Users/sneha/Developer/toron-research/toron/docs/securityReview/SR-081.md#L221)).
2. Zero empty upstream reverse proxies are registered, eliminating false `502 Bad Gateway` rejections.
3. Multi-level parameterized routes sharing the same prefix (e.g. `/v1/users/:id` and `/v1/users/:id/orders/:orderId`) dispatch to their respective distinct gRPC targets without collision.
4. Method mismatch on parameterized prefix routes returns `405 Method Not Allowed`.
5. Segment count mismatch returns `404 Not Found` without upstream leakage.
6. Execution is 100% race-clean under `go test -race ./...`.

## Test Cases Specification

### TC-091-01: Direct Parameterized Subpath Dispatch via `router.ServeHTTP`
- **Target**: [`Engine.registerRoutes`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go#L68) & [`Router.ServeHTTP`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L453)
- **Preconditions**: Mock gRPC upstream server recording incoming paths and request payloads.
- **Action**:
  - Register route: `GET /v1/users/:id -> /user.UserService/GetUser`.
  - Issue request: `GET /v1/users/usr-777` through `router.ServeHTTP(req, res)`.
- **Assertions**:
  - Response status code is `200 OK` (NOT `502 Bad Gateway`).
  - Response body contains `{"id":"usr-777", ...}`.
  - Upstream gRPC server receives exactly 1 request with `id: "usr-777"`.

---

### TC-091-02: Multi-Level Route Segregation on Shared Prefix
- **Target**: Parameterized pattern matching with shared literal prefix.
- **Preconditions**: Mock gRPC server with multiple methods.
- **Action**:
  - Register Route A: `GET /v1/users/:id -> /user.UserService/GetUser`.
  - Register Route B: `GET /v1/users/:id/orders/:orderId -> /order.OrderService/GetOrder`.
  - Issue Request A: `GET /v1/users/usr-100` via `router.ServeHTTP`.
  - Issue Request B: `GET /v1/users/usr-100/orders/ord-500` via `router.ServeHTTP`.
- **Assertions**:
  - Request A routes to `/user.UserService/GetUser` with `id: "usr-100"`.
  - Request B routes to `/order.OrderService/GetOrder` with `id: "usr-100"` and `orderId: "ord-500"`.
  - Zero cross-talk or route shadowing.

### TC-091-03: Method Gating on Parameterized Subpath
- **Target**: [`Router.ServeHTTP`](file:///Users/sneha/Developer/toron-research/toron/pkg/router/router.go#L453) method enforcement on prefix routes.
- **Action**:
  - Register route: `GET /v1/users/:id -> /user.UserService/GetUser`.
  - Issue request: `POST /v1/users/usr-777` via `router.ServeHTTP`.
- **Assertions**:
  - Response status code is `405 Method Not Allowed`.
  - Upstream receives 0 requests.

---

### TC-091-04: Segment Count and Pattern Mismatch Fall-Through
- **Target**: Pattern boundary validation.
- **Action**:
  - Register route: `GET /v1/users/:id -> /user.UserService/GetUser`.
  - Issue request: `GET /v1/users` (missing parameter).
  - Issue request: `GET /v1/users/usr-777/extra/segments` (excess segments).
- **Assertions**:
  - Both requests return `404 Not Found`.
  - Upstream receives 0 requests.

### TC-091-05: Unit Test Coverage for `MatchPathPattern`
- **Target**: [`MatchPathPattern`](file:///Users/sneha/Developer/toron-research/toron/pkg/transcoder/transcoder.go)
- **Assertions**:
  - Matches single parameter: `MatchPathPattern("/v1/users/:id", "/v1/users/123") == true`.
  - Matches multi parameter: `MatchPathPattern("/v1/orgs/:org/users/:user", "/v1/orgs/acme/users/alice") == true`.
  - Rejects segment count mismatch: `MatchPathPattern("/v1/users/:id", "/v1/users") == false`.
  - Rejects literal mismatch: `MatchPathPattern("/v1/users/:id", "/v1/items/123") == false`.
  - Rejects empty parameter: `MatchPathPattern("/v1/users/:id", "/v1/users//") == false`.
