# SR-020 - Security Review of HTTP/2 Extended CONNECT Protocol (RFC 8441)

## Scope

Security review of HTTP/2 RFC 8441 Extended CONNECT method request parsing, `:protocol` pseudo-header mapping, response status 200 OK translation, and bi-directional stream copying.

## Findings

1. **Protocol Verification**: Extended CONNECT requests are validated strictly to require both `Method == "CONNECT"` and `:protocol == "websocket"`, preventing misuse of standard CONNECT proxy tunneling.
2. **Stream Isolation**: HTTP/2 multiplexing isolates WebSocket stream channels without compromising or blocking parallel HTTP/2 REST streams over the same connection.
3. **Graceful Teardown**: Bi-directional goroutine stream copying ensures both HTTP/2 request stream body and upstream raw connection sockets are closed cleanly on termination.

## Conclusion

Approved. No security vulnerabilities identified.
