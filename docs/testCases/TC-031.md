# TC-031 - Prometheus Metrics Endpoint and W3C Traceparent Header Verification

## Test Objectives

1. Verify `pkg/metrics` `ExportPrometheus()` generates valid Prometheus exposition format output containing `# TYPE` and `# HELP` declarations.
2. Verify GET `/metrics` endpoint returns status `200 OK` and `Content-Type: text/plain; version=0.0.4`.
3. Verify `pkg/metrics` W3C `traceparent` extraction and generation produces valid 32-hex trace ID and 16-hex span ID values.
4. Verify reverse proxy propagates existing `traceparent` headers or injects generated W3C trace headers to backend targets.
5. Verify all Go unit tests pass cleanly (`go test ./...`).
