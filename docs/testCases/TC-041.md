# TC-041 - Core Web Application Firewall (WAF) Engine Verification

## Test Objectives

1. **SQL Injection (SQLi) Detection**: Verify WAF engine blocks requests with SQLi patterns (`UNION SELECT`, `OR 1=1`, `DROP TABLE`) in URL parameters, query strings, headers, and body with `403 Forbidden`.
2. **Cross-Site Scripting (XSS) Detection**: Verify WAF engine blocks XSS vectors (`<script>`, `onerror=`, `javascript:`) with `403 Forbidden`.
3. **Path Traversal / LFI Detection**: Verify WAF engine blocks directory traversal (`../`, `%2e%2e/`, `/etc/passwd`) with `403 Forbidden`.
4. **Command Injection / RCE Detection**: Verify WAF engine blocks OS command execution (`/bin/sh`, `; system()`, `| bash`) with `403 Forbidden`.
5. **Detection Mode Verification**: Verify WAF in `detection` mode lets malicious requests pass to next handler while attaching `X-Toron-WAF-Anomaly-Score`.
6. **Benign Request Pass-Through**: Verify benign GET/POST requests pass WAF inspection without false positives or status mutation.
7. **Body Inspection Restoration**: Verify `req.Body` is fully preserved for downstream handlers after WAF inspection.
