# TC-080 - Verification of Case-Insensitive WAF Traversal Matching

## Objective

Verify that default WAF rule `TRAVERSAL-001` detects uppercase percent-encoded directory traversal sequences across headers, queries, and request bodies.

## Test Cases

### TC-080-01: Uppercase Hex Dot-Dot-Slash in Header
- **Setup**: WAF engine with default rules.
- **Action**: Inspect request with header `X-Path: %2E%2E/secret.txt`.
- **Expected Outcome**:
  - `TRAVERSAL-001` is triggered.
  - Threat score increases by 5.

### TC-080-02: Mixed-Case Hex Dot-Dot-Slash in Body
- **Setup**: WAF engine with `InspectBody` enabled.
- **Action**: Inspect POST request with body `{"file":"%2e%2E%2Fetc/passwd"}`.
- **Expected Outcome**:
  - `TRAVERSAL-001` matches successfully.

### TC-080-03: Encoded Backslash Sequence Detection
- **Setup**: WAF engine.
- **Action**: Inspect request with query `?file=%2e%2e%5cwindows%5cwin.ini`.
- **Expected Outcome**:
  - `TRAVERSAL-001` matches successfully.
