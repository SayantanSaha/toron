# TC-113 - Test Specification for Heterogeneous Multi-Hop Backend Origin Testbed (BMK-03)

## 1. Test Suite Objectives

Verify that Toron edge gateway fronting three distinct, heterogeneous backend runtimes (Node.js `llhttp`, Python `uvicorn`/`h11`, and Go `net/http`):
1. Reliably intercepts and blocks cross-protocol and HTTP request smuggling attack vectors at the edge.
2. Enforces fail-fast transport socket closure on malformed inputs, ensuring zero residual bytes leak into upstream connection pools.
3. Successfully delivers benign requests and canaries without response desynchronization, pool poisoning, or session corruption.
4. Generates publication-grade evaluation artifacts (`benchmarks/results/multihop_report.json` and `benchmarks/results/multihop_report.md`).

---

## 2. Test Cases

### TC-113-01: VECTOR-01 - H2.TE Smuggling Probe
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Send HTTP/2 request with `Transfer-Encoding: chunked` directed to `/node`, `/python`, and `/go`.
- **Expected Outcome**:
  - Edge rejects with `400 Bad Request`.
  - Upstream backend receives 0 bytes.
  - Subsequent canary `GET /canary` returns `200 OK` with valid canary response.

### TC-113-02: VECTOR-02 - H2.CL Duplicate Content-Length
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Send HTTP/2 request with duplicate/conflicting `Content-Length` headers (`10` and `20`) directed to `/node`, `/python`, and `/go`.
- **Expected Outcome**:
  - Edge rejects with `400 Bad Request`.
  - Zero backend leakage.
  - Subsequent canary `GET /canary` returns `200 OK`.

### TC-113-03: VECTOR-03 - H2.CL Payload Mismatch
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Send HTTP/2 request with declared `Content-Length: 50` but providing only 10 body bytes directed to `/node`, `/python`, and `/go`.
- **Expected Outcome**:
  - Edge rejects with `400 Bad Request`.
  - Zero backend leakage.
  - Subsequent canary `GET /canary` returns `200 OK`.

### TC-113-04: VECTOR-04 - H1-CL.TE Dual Framing
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit HTTP/1.1 request containing both `Content-Length: 6` and `Transfer-Encoding: chunked` with smuggled payload prefix.
- **Expected Outcome**:
  - Edge blocks with `400 Bad Request`.
  - Connection socket is physically closed (`conn_closed == true`).
  - Subsequent canary `GET /canary` over fresh connection returns `200 OK`.

### TC-113-05: VECTOR-05 - H1-TE.CL Whitespace Obfuscation
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit HTTP/1.1 request with `Transfer-Encoding : chunked` (whitespace before colon) and `Content-Length: 4`.
- **Expected Outcome**:
  - Edge rejects with `400 Bad Request` (RFC 7230 §3.2.4 whitespace violation).
  - Physical socket closed.
  - Subsequent canary returns `200 OK`.

### TC-113-06: VECTOR-06 - H1 Pipelined Smuggle Injection
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit pipelined sequence containing a malformed request followed immediately by a smuggled prefix, testing residual buffer eviction.
- **Expected Outcome**:
  - Malformed request triggers fail-fast termination.
  - Unconsumed pipelined bytes on closed socket are discarded; backend connection pool is not poisoned.
  - Canary request returns `200 OK`.

### TC-113-07: VECTOR-07 - CRLF Header Injection
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit request with injected `\r\n` characters in header values (`X-Injected: test\r\nInjected-Header: evil`).
- **Expected Outcome**:
  - Edge rejects with `400 Bad Request`.
  - Backend receives zero split headers.
  - Canary returns `200 OK`.

### TC-113-08: VECTOR-08 - HTTP/2 Pseudo-Header Upstream Isolation
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit valid HTTP/2 request with pseudo-headers (`:path`, `:authority`, `:scheme`, `:protocol`).
- **Expected Outcome**:
  - Edge forwards to upstream HTTP/1.1 backend.
  - Backend verifies that zero headers starting with `:` were received in the upstream HTTP/1.1 request.
  - Backend returns `200 OK`.

### TC-113-09: VECTOR-09 - Baseline Benign GET
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit standard benign `GET /health` to `/node/health`, `/python/health`, and `/go/health`.
- **Expected Outcome**:
  - Edge forwards transparently ($200\text{ OK}$).
  - Backend returns expected runtime metadata JSON.
  - Subsequent canary returns `200 OK`.

### TC-113-10: VECTOR-10 - Baseline Benign POST Body
- **Target**: `benchmarks/multihop/multihop_test.go`
- **Methodology**: Transmit standard benign `POST /echo` with 1KB payload body.
- **Expected Outcome**:
  - Edge forwards transparently ($200\text{ OK}$).
  - Backend receives exact body byte count and echoes payload back.
  - Subsequent canary returns `200 OK`.

## 3. Telemetry & Cross-Runtime Invariant Verification

For all 30 evaluations ($10 \text{ vectors} \times 3 \text{ backends}$):
- `Desynchronization Detected`: MUST be `0`.
- `Pool Poisoning Detected`: MUST be `0`.
- `Canary Success Rate`: MUST be `100%`.
- `Test Report`: Successfully generated in `benchmarks/results/multihop_report.json` and `benchmarks/results/multihop_report.md`.
