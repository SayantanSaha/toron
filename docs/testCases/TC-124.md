# TC-124 - Automated Verification of Configurable Distributed Tracing in Reverse Proxy

## 1. Test Overview

This test suite verifies the configurable W3C distributed tracing context generation and propagation introduced in [`REQ-124`](file:///Users/sneha/Developer/toron-research/toron/docs/requirements/REQ-124.md) and [`ADR-124`](file:///Users/sneha/Developer/toron-research/toron/docs/architecture/ADR-124.md).

---

## 2. Test Specifications

### TC-124.1: Profile Defaults Verification
- **Package**: `pkg/config`
- **Objective**: Verify that `DefaultProxyTransportConfig("raw_speed")` sets `Tracing = &false` and `DefaultProxyTransportConfig("balanced")` sets `Tracing = &true`.
- **Expected Outcome**: `raw_speed` returns non-nil `Tracing` with `*Tracing == false`; `balanced` returns non-nil `Tracing` with `*Tracing == true`.

### TC-124.2: Hierarchical Override Resolution
- **Package**: `pkg/config`
- **Objective**: Verify route-level `tracing` overrides global settings.
  1. Global `tracing: true`, Route `tracing: false` $\rightarrow$ resolves to `false`.
  2. Global `tracing: false`, Route `tracing: true` $\rightarrow$ resolves to `true`.
  3. Route `tracing: nil`, Global `tracing: false` $\rightarrow$ resolves to `false`.
- **Expected Outcome**: Exact pointer boolean resolution according to ADR-124.

### TC-124.3: Proxy Dispatch with `tracing: false` and Missing Traceparent
- **Package**: `pkg/proxy`
- **Objective**: When a client sends a request without a `traceparent` header to a proxy configured with `Tracing: &false`, the outbound upstream request must NOT contain a `traceparent` header.
- **Expected Outcome**: `upstreamReq.Header.Get("traceparent") == ""`.

### TC-124.4: Proxy Dispatch with `tracing: false` and Incoming Traceparent
- **Package**: `pkg/proxy`
- **Objective**: When a client sends an existing `traceparent` header (`00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01`) to a proxy configured with `Tracing: &false`, the upstream request must receive that header verbatim without re-generating IDs.
- **Expected Outcome**: `upstreamReq.Header.Get("traceparent") == "00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01"`.

### TC-124.5: Proxy Dispatch with `tracing: true` and Missing Traceparent
- **Package**: `pkg/proxy`
- **Objective**: When a client sends a request without a `traceparent` header to a proxy configured with `Tracing: &true`, the proxy generates and injects a valid W3C header.
- **Expected Outcome**: Outbound header starts with `00-`, has 4 hyphen-separated parts, 32-hex trace ID, and 16-hex span ID.

### TC-124.6: Proxy Dispatch with `tracing: true` and Incoming Traceparent
- **Package**: `pkg/proxy`
- **Objective**: When a client sends a valid `traceparent` header to a proxy configured with `Tracing: &true`, the proxy preserves the trace ID and generates a new child span ID.
- **Expected Outcome**: Outbound header preserves incoming `trace_id` and has a distinct `span_id`.
