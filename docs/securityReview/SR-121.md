## 2. Threat Modeling & Boundary Assessment

| Threat Vector ID | Security Risk | Mitigation Strategy | Status |
|:---|:---|:---|:---|
| **SEC-001** | Docker socket exposure or privileged container access | No proxy or backend container mounts `/var/run/docker.sock` in `docker-compose.compare.yml`. Non-privileged mode. | ✅ SECURE |
| **SEC-002** | Host port collision with production/developer services | Proxy ports mapped to `8881`-`8885`, avoiding active developer containers on ports 8081-8085. | ✅ SECURE |
| **SEC-003** | Upstream Request Injection / Smuggling (CWE-444) | All proxies enforce strict HTTP parsing and strip URI path prefixes deterministically before dispatching to upstream origins. | ✅ SECURE |
| **SEC-004** | Denial of Service via Resource Exhaustion (CWE-400) | Bounded worker pools and idle socket timeouts configured across all proxies and the benchmark runner. | ✅ SECURE |
| **SEC-005** | Sensitive Information Disclosure via Reports (CWE-200) | Generated JSON and Markdown benchmark reports contain only performance metrics, latency percentiles, and resource utilization; no internal tokens or secrets. | ✅ SECURE |

---

## 3. Concurrency & Network Safety Audit

1. **Keep-Alive & Connection Teardown**:
   - Connection pools are properly closed upon duration expiry.
   - Graceful cancellation handling eliminates goroutine leaks or dangling connections during benchmark transitions.
2. **Network Isolation**:
   - `compare-net` bridge network isolates benchmark traffic from external network interfaces.
   - Only explicitly declared proxy ports and origins are exposed on loopback `127.0.0.1`.
