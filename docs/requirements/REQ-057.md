# REQ-057 - HTTP-to-HTTPS Redirection with Route-Level Exemption Override

## Description

The Toron web server shall support cleartext HTTP-to-HTTPS 301 redirection on an auxiliary HTTP port (default port 80) when TLS is enabled on the primary port (default port 443), while providing a declarative route-level configuration override (`redirect_http: false`) in `routes.yaml` and `config.yaml` to exempt specific routes from redirection.

Production edge gateways enforce encrypted communication by upgrading unencrypted HTTP client requests to HTTPS. However, specific protocols and automated workflows—such as ACME HTTP-01 challenge validations (`http://<domain>/.well-known/acme-challenge/<token>`), unencrypted webhook ingestion, and internal health checks—require cleartext HTTP access without being redirected.

Rather than hardcoding arbitrary path prefixes into the server binary, Toron decouples protocol redirect policies from application routing by providing a generic route-level override `redirect_http: false` (or `https_redirect: false`). When an incoming request arrives on the HTTP cleartext listener:
1. Toron checks if the request matches a configured route that has `redirect_http: false`.
2. If matched with `redirect_http: false`, the request is served directly over HTTP using the route's configured handler (static file serving or upstream reverse proxy) with HTTP 200 OK or the appropriate status code.
3. If no route matches or the matched route does not disable HTTP redirection (default behavior), Toron immediately responds with an `HTTP/1.1 301 Moved Permanently` status and a sanitized `Location: https://<host><request_uri>` header.

## Acceptance Criteria

1. **Global Server Configuration**:
   - `server.http_redirect` configuration block in `config.yaml` supporting:
     - `enabled` (boolean): Enables the auxiliary cleartext HTTP listener when TLS is active.
     - `port` (integer): Listening port for HTTP traffic (defaults to `80` if unspecified or `<= 0`).
   - If `server.http_redirect.enabled` is `false` or omitted, no auxiliary listener is started.

2. **Route-Level Redirect Override**:
   - `ProxyRouteConfig` in `routes.yaml` and `config.yaml` accepts an optional boolean pointer `redirect_http: true | false`.
   - When `redirect_http: false` is configured for a route (e.g. static route `/.well-known/acme-challenge` or an upstream proxy route), requests matching this route on the HTTP listener are NOT redirected to HTTPS.
   - Routes with `redirect_http: true` or omitted (nil) inherit default redirection behavior.

3. **HTTP Port Request Processing**:
   - Incoming HTTP requests matching an exempt route (`redirect_http == false`) execute the route handler directly, returning the target content (e.g., validation tokens, static assets, or proxied upstream responses).
   - Incoming HTTP requests not matching an exempt route return `HTTP/1.1 301 Moved Permanently`.
   - The redirect `Location` header must preserve the full request URI, including URL path, query string parameters, and URL fragment indicators if provided.
   - The redirect response must include standard headers: `Connection: keep-alive` (or `close` if client requested), `Content-Length: 0`, and no leaking sensitive response headers.

4. **Security & Input Sanitization**:
   - Host Header Sanitization: The target host in the redirect URL must be derived from the sanitized incoming `Host` header. Any port component in `Host` (e.g., `example.com:80`) must be stripped, and the redirect target must use the standard HTTPS scheme (`https://example.com/path`).
   - Prevention of Open Redirects (CWE-601): Malicious host values containing line breaks, whitespace, CRLF sequences, backslashes, or control characters must be rejected with `HTTP 400 Bad Request`.
   - Path Traversal Protection: Route handlers executed on HTTP preserve all standard route traversal protections.

5. **Lifecycle Management**:
   - The auxiliary HTTP listener shares the application's lifecycle context and shuts down cleanly on SIGINT / SIGTERM alongside the primary HTTPS listener, without orphaned sockets or hanging goroutines.
