# REQ-023 - HTTPS TLS Encryption and Self-Signed Development Certificate Generation

## Description

The Toron web server shall support HTTPS TLS/SSL encrypted connections (`tls.Listen`), X.509 certificate loading from disk (`cert_file`, `key_file`), automatic self-signed development certificate generation (`auto_dev_cert`), ALPN protocol negotiation (`h2`, `http/1.1`), and modern TLS version enforcement (TLS 1.2 / TLS 1.3).

## Acceptance Criteria

- `TLSConfig` added to `ServerConfig` in `pkg/config/config.go` (`enabled`, `cert_file`, `key_file`, `auto_dev_cert`, `min_version`).
- `config.yaml` updated with `server.tls` parameters.
- `pkg/server` updated with `ListenAndServeTLS` and automatic development certificate generator (`GenerateDevCert`).
- TLS listener configures ALPN next protocols (`h2`, `http/1.1`) so HTTP/2 over TLS works seamlessly.
- All Go unit tests pass cleanly.

## Rationale

HTTPS encryption is mandatory for production web security, browser compatibility, data confidentiality, and HTTP/2 ALPN negotiation.
