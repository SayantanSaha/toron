# REQ-066 - Access Log CRLF Sanitization and Log Forgery Prevention

## Description

The Toron multi-stream logging engine shall sanitize all untrusted, client-supplied HTTP request fields prior to emitting text-format access logs (Combined Log Format), preventing CRLF Log Injection (CWE-117) and audit log forgery.

Control characters—specifically carriage return (`\r`) and line feed (`\n`)—present in client-controlled headers such as `User-Agent`, `Referer`, `Host`, and request lines shall be stripped or replaced with safe representations before disk write.

## Acceptance Criteria

### 1. Control Character Stripping in Text Format
- When logging in text mode (`Format: "text"`), all fields containing client-controlled strings (`UserAgent`, `Referer`, `Host`, `Method`, `Path`) shall have carriage returns (`\r`), line feeds (`\n`), and non-printable control characters stripped or replaced with whitespace or escape sequences.
- A single HTTP transaction shall strictly emit exactly one newline-terminated line in the access log sink.

### 2. Multi-Line Injection Neutralization
- An attacker providing payload sequences such as `User-Agent: Mozilla/5.0\r\n127.0.0.1 - - [01/Jan/2026:00:00:00] "GET /fake HTTP/1.1" 200 0` shall not be capable of creating a second line in the log file.

### 3. Preservation of JSON Log Integrity
- When logging in structured JSON mode (`Format: "json"`), values shall be properly encoded via standard JSON serialization so that embedded special characters are safely escaped.

### 4. Zero Performance Degradation
- The sanitization routine shall operate with zero or negligible allocation overhead on common path lengths.

## Rationale

Unsanitized text log formats allow malicious actors to fabricate synthetic log entries, falsifying client IPs, timestamps, and request statuses to confuse security incident responders and corrupt SIEM parsers.

## Constraints

- Backward-compatible with Combined Log Format (CLF) specifications.
- Must execute efficiently inside the `AccessLoggerMiddleware`.

## Open Questions
