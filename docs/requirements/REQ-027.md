# REQ-027 - HTTP/3 Protocol Engine & QUIC Transport Listener Support

## Description

The Toron web server shall support the HTTP/3 protocol over QUIC (UDP transport layer) alongside HTTP/1.1 and HTTP/2 cleartext (`h2c`) / TLS listeners.

This includes adding HTTP/3 configuration options in `config.yaml` (`server.http3.enabled`, `server.http3.port`), initializing an HTTP/3 QUIC server engine (`http3.Server`), advertising `Alt-Svc: h3=":443"` header responses on HTTPS/TLS endpoints for seamless protocol negotiation, and routing HTTP/3 requests through Toron's core router and reverse proxy engine.

## Acceptance Criteria

- `pkg/config`: `ServerConfig` includes `HTTP3` configuration settings (`enabled`, `port`).
- `pkg/server`: `Server` supports initializing and running a QUIC HTTP/3 listener engine (`http3.Server`) bound to the configured UDP address.
- `pkg/server`: HTTPS/TLS responses automatically include `Alt-Svc` headers advertising HTTP/3 availability to client browsers and HTTP/3 clients.
- `pkg/server`: HTTP/3 requests are parsed, matched against router rules, and handled seamlessly through the existing handler pipeline.
- All Go unit tests pass cleanly without regressions.

## Rationale

HTTP/3 uses QUIC over UDP to eliminate head-of-line blocking, provide faster connection setup (0-RTT), and improve resilience over mobile and lossy networks. Supporting HTTP/3 ensures Toron stays state-of-the-art with modern web protocol standards.
