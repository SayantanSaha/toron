# CR-075 - Code Review of Container Route Prefix Scoping and Shadowing Guards

## Description

Engineering code review of `TASK-079` implementation in `pkg/discovery/parser.go`, `pkg/discovery/manager.go`, and `pkg/discovery/discovery_test.go`.

## Scope

- Files reviewed:
  - `pkg/discovery/parser.go`
  - `pkg/discovery/manager.go`
  - `pkg/discovery/discovery_test.go`

## Key Observations & Review Findings

1. **Deterministic Path Scoping in Parser**:
   - `ParseContainerLabels` enforces that wildcard root routes (`""` or `"/"`) require an explicit non-empty `host`.
   - Prevents unhosted containers from stealing root routing priority.
   - Enforces blacklist against `/internal` and `/api/status` paths (both exact match and slash-prefixed subpaths).
2. **Audit Visibility in Manager**:
   - `Manager.handleContainerStart` logs clear security warning when a container with `toron.enable=true` is rejected by the policy, aiding troubleshooting and intrusion awareness.
3. **Comprehensive Test Suite**:
   - Tests verify rejection of wildcard root without host, rejection of empty prefix without host, rejection of administrative path shadowing, acceptance of scoped services, and acceptance of host-scoped root.
   - All tests pass with race detector enabled.

## Verdict

Approved. Ready for commit.
