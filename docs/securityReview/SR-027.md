# SR-027 - Security Review of Internal Control Plane JSON Metrics Endpoints

## Scope

Security audit of `/internal/api/status` and `/internal/api/metrics` JSON endpoints, response payload sanitization, memory safety under concurrent metric extraction, and PII protection.

## Findings

1. **Information Leakage**: JSON metrics return aggregate counters, active QUIC streams, active TCP connections, and status code distributions without leaking sensitive user authorization headers or body payloads.
2. **Race Safety**: `GetSummaryJSON()` acquires read locks (`RUnlock`/`RLock`) on the underlying `MetricsRegistry`, ensuring thread-safe JSON serialization without data races under heavy traffic.

## Conclusion

Approved. No security vulnerabilities identified.
