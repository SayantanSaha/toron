# TC-036 - Multi-Scheme Authentication Middleware Verification

## Test Objectives

1. Verify valid JWT token (HS256) passes authentication and forwards request with `X-Authenticated-User` header.
2. Verify expired JWT token (`exp < now`) is rejected with `401 Unauthorized`.
3. Verify tampered JWT signature is rejected with `401 Unauthorized`.
4. Verify JWT with mismatched issuer (`iss`) or audience (`aud`) is rejected with `401 Unauthorized`.
5. Verify valid API Key in `X-API-Key` or `Authorization: ApiKey` passes authentication.
6. Verify invalid API Key returns `401 Unauthorized`.
7. Verify valid Basic Auth credentials pass authentication and sets `X-Authenticated-User`.
8. Verify invalid Basic Auth returns `401 Unauthorized` and sets `WWW-Authenticate: Basic realm="Toron"`.
9. Verify missing credentials return `401 Unauthorized` with structured JSON error.
