# REQ-049 - REST-to-gRPC Transcoding Engine

## Description

Toron Edge Gateway MUST provide a native, zero-dependency **REST-to-gRPC Transcoding Engine** (`pkg/transcoder`). The engine MUST transcode incoming RESTful JSON HTTP requests (e.g. `GET /v1/users/123`) into binary Protobuf-encoded HTTP/2 gRPC requests (e.g. `POST /user.UserService/GetUser`) and convert returning binary Protobuf payloads and `grpc-status` headers back into REST JSON responses.

## Acceptance Criteria

1. **Zero External Dependencies**: The engine MUST perform REST JSON payload parsing, URL path parameter extraction, gRPC 5-byte wire framing, and response translation using Go stdlib `encoding/binary`, `encoding/json`, `net/http`, and `toron/pkg/httpparser` packages only.
2. **URL Parameter Extraction**: The engine MUST extract path parameters (e.g. `:id` in `/v1/users/:id`) and query string parameters into the outgoing gRPC request payload structure.
3. **gRPC Wire Framing**: The engine MUST construct valid gRPC wire frames (`[1-byte compression flag][4-byte big-endian payload length] + payload`) and set `Content-Type: application/grpc`.
4. **Status Code Mapping**: The engine MUST map gRPC status codes (`grpc-status: 0` -> 200 OK, `grpc-status: 5` -> 404 Not Found, `grpc-status: 16` -> 401 Unauthorized) to standard HTTP status codes.
