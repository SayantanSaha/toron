# TC-106 - Verification Suite for Latency Timing Alignment (Eq. 7) and Repeated Statistical Distribution Trials

## 1. Test Suite Objectives

Verify that `benchmarks/fuzzer/diff_fuzzer.go` strictly adheres to Equation 7 by isolating socket dial latency from rejection latency measurements, correctly executes configurable warm-up and repeated trials ($K \ge 1,000$), computes exact statistical distribution metrics (Mean, Sample StdDev, Median, p90, p99, p99.9, and 95% Confidence Interval), and outputs detailed dispersion data in JSON and Markdown reports without external dependencies.

## 2. Test Cases

### TC-106-01: Equation 7 Timing Isolation Verification
- **Objective**: Confirm that artificial connection dial delay is completely excluded from measured rejection latency.
- **Methodology**: Deploy a mock TCP listener that introduces an artificial 50ms sleep during accept/dial before completing the connection, but responds instantly (<5ms) once bytes are written.
- **Expected Outcome**: `res.MeanLatencyUs < 15000` (15ms), proving the 50ms dial delay did not bleed into the measured latency.

### TC-106-02: Statistical Distribution Engine Mathematical Precision
- **Objective**: Validate the mathematical accuracy of `computeDistribution` against known reference inputs.
- **Input**: Static slice of 10 samples: `[10.0, 20.0, 30.0, 40.0, 50.0, 60.0, 70.0, 80.0, 90.0, 100.0]`.
- **Expected Outcome**:
  - `Mean`: $55.0 \pm 0.01$
  - `Median`: $55.0 \pm 0.01$
  - `StdDev`: $30.2765 \pm 0.01$ (sample standard deviation with $K-1$)
  - `P90`: $90.0 \pm 0.01$
  - `P99`: $100.0 \pm 0.01$
  - `CI95Margin`: $18.766 \pm 0.01$ ($1.96 \cdot \frac{30.2765}{\sqrt{10}}$)

### TC-106-03: Multi-Trial Execution & Warm-up Counting
- **Objective**: Verify that running with `-trials K` and `-warmup W` executes exactly $K + W$ iterations, discards the first $W$ runs, and records exactly $K$ samples.
- **Methodology**: Execute a mock server tracking received request count with $K=10$ and $W=3$.
- **Expected Outcome**: Mock server receives exactly 13 connections; `res.Trials == 10`, `res.WarmupRuns == 3`, `len(res.RawSamples) == 10`.

### TC-106-04: Multi-Stage Cache Vector Repeatability under Multiple Trials
- **Objective**: Verify that multi-stage test cases (`CACHE-001..003`) correctly execute preparatory stages on every trial iteration without cache state corruption.
- **Methodology**: Execute `CACHE-001` with $K=5$ against mock cache server.
- **Expected Outcome**: All 5 trials succeed; `res.Passed == true`.

### TC-106-05: Race Detector Cleanliness
- **Objective**: Execute test suite under race detector (`go test -v -race -count=1 ./benchmarks/fuzzer/...`).
- **Expected Outcome**: 100% pass rate with zero race condition warnings.
