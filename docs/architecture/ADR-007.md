# ADR-007 - Dummy Web Services Test Architecture

## Context

Testing reverse proxy routes and load balancing across 10 upstreams requires lightweight, non-blocking dummy HTTP servers running on separate ports.

## Decision

1. **Package Location**: Place all dummy services inside `dummy-services/`.
2. **Port Range**: Use fixed default ports `9001` to `9010` (`http://localhost:9001` through `http://localhost:9010`).
3. **Response Schema**: Each service returns JSON identifying its service name, port, path, method, and headers:
   ```json
   {
     "service": "dummy-service-1",
     "port": 9001,
     "path": "/api/users",
     "method": "GET",
     "headers": { ... }
   }
   ```
4. **Lifecycle Control**: Expose `StartAll(startPort, count)` and `StopAll()` functions in `dummy-services/services.go` for programmatic testing.

## Consequences

- **Positive**: Provides instant end-to-end integration testing for multi-target load balancing.
- **Negative**: Occupies local ports 9001–9010 during manual execution.
