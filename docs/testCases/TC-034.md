# TC-034 - Response Compression (Gzip & Deflate) Verification

## Test Objectives

1. Verify `Accept-Encoding: gzip` returns `Content-Encoding: gzip`, `Vary: Accept-Encoding`, and compresses response payloads exceeding `min_length`.
2. Verify compressed Gzip response decompresses cleanly to match original payload.
3. Verify `Accept-Encoding: deflate` returns `Content-Encoding: deflate` and compresses payload properly.
4. Verify requests without `Accept-Encoding` or with `Accept-Encoding: identity` are returned uncompressed.
5. Verify payloads below `min_length` threshold (e.g. 512 bytes) pass through uncompressed.
6. Verify already encoded responses (`Content-Encoding: gzip`) or image/binary MIME types are not re-compressed.
7. Verify WebSocket upgrade responses (`101 Switching Protocols`) are bypassed without modification.
8. Verify configuration parsing under `config.yaml` loads `server.compression` settings.
