# SR-038 - Security Review of Route-Level WAF Overrides and CIDR IP Access Lists

## Scope

Security assessment of the new CIDR-based IP access control lists in `pkg/waf/ip_acl.go`, route-level WAF overrides in `pkg/waf/waf.go`, middleware integration in `pkg/waf/middleware.go`, and router binding in `pkg/router/router.go`.

## Findings & Verifications

1. **Fast-Path DoS Mitigation**:
   - IP ACL checking runs before protocol integrity inspection, payload reading, or regex execution.
   - Malicious IP ranges are blocked in $O(1)$ without consuming CPU cycles for body parsing or regular expression matching.

2. **CIDR Parsing & Evaluation Integrity**:
   - `net.ParseCIDR` and `net.IPNet.Contains` are used for robust subnet matching without string truncation risks.
   - Single IP addresses are handled cleanly via `net.ParseIP` and equality checks.
   - Dual-stack IPv4 and IPv6 addresses are supported and properly separated.

3. **Client IP Spoofing Resistance**:
   - Client IP extraction prioritizes `X-Forwarded-For` (taking first client IP) / `X-Real-IP` and safely falls back to `net.Conn.RemoteAddr()`.
   - Host/port parsing uses standard `net.SplitHostPort` preventing malformed port injection.

4. **Rule Disabling Granularity**:
   - Disabling rules per route is strictly scoped to the route's dedicated `WAFEngine` instance; global edge protection remains unweakened.

## Verdict

**PASSED - Approved for Production.**
No critical, high, or medium vulnerabilities identified.
