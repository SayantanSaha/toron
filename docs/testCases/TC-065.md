# TC-065 - Verification of Upstream TLS Certificate Verification in WebSocket Proxy

## Objective

Verify that the reverse proxy enforces upstream TLS certificate verification during WebSocket upgrades over \`wss://\` / TLS connections, rejects untrusted/self-signed upstream certificates with HTTP 502 Bad Gateway by default, honors custom CA certificate pools when provided, and only permits certificate validation bypass when \`InsecureSkipVerify\` is explicitly set in configuration.

## Test Cases

### TC-065-01: Default Upstream TLS Certificate Rejection (Untrusted Self-Signed)
- **Setup**: Start a TLS WebSocket backend server presenting a self-signed certificate. Initialize \`ReverseProxy\` pointing to the \`https://\` target URL with default options (\`InsecureSkipVerify: false\`, \`TLSCACertPool: nil\`).
- **Action**: Client sends a WebSocket upgrade request (\`Upgrade: websocket\`, \`Connection: Upgrade\`, \`Sec-WebSocket-Key: ...\`, \`Sec-WebSocket-Version: 13\`).
- **Expected Outcome**:
  - Upstream TLS handshake fails due to untrusted authority.
  - Proxy returns \`HTTP 502 Bad Gateway\` to the client.
  - Connection is terminated safely without leak.

### TC-065-02: Custom CA Certificate Pool Validation
- **Setup**: Using the self-signed TLS WebSocket backend from TC-065-01, construct an \`x509.CertPool\` containing the backend's self-signed certificate and initialize \`ReverseProxy\` with \`TLSCACertPool\` set to this pool.
- **Action**: Client sends a WebSocket upgrade request.
- **Expected Outcome**:
  - Upstream TLS handshake succeeds using the custom root CA pool.
  - Proxy upgrades connection returning \`HTTP 101 Switching Protocols\`.
  - WebSocket frames pass bidirectionally.

### TC-065-03: Explicit InsecureSkipVerify Exemption
- **Setup**: Initialize \`ReverseProxy\` targeting the self-signed TLS WebSocket backend with \`InsecureSkipVerify: true\` explicitly configured.
- **Action**: Client sends a WebSocket upgrade request.
- **Expected Outcome**:
  - Upstream TLS handshake succeeds without custom CA pool.
  - Proxy returns \`HTTP 101 Switching Protocols\`.
