# REQ-002 - HTTP/1.1 Protocol Support and Request Handling

## Description

The system shall parse HTTP/1.1 request streams, extract method, request target, headers, and body, route requests to registered handlers, and construct valid HTTP/1.1 response streams.

## Acceptance Criteria

- Parses valid HTTP/1.1 methods (`GET`, `POST`, `HEAD`, `OPTIONS`, `PUT`, `DELETE`).
- Extracts query parameters, HTTP headers, and request payload bodies correctly.
- Constructs formatted HTTP/1.1 response status headers, Content-Type, Content-Length, and response body.
- Provides a simple HTTP handler routing mechanism to register endpoints (e.g., `/`, `/health`).
- Handles chunked transfer encoding or standard Content-Length responses.

## Rationale

HTTP/1.1 is the foundational protocol for Toron as a web server, enabling client-server web interactions.

## Constraints

- HTTP parser must work cleanly on streaming byte buffers without loading entire unbounded payloads into memory.

## Open Questions

- Should HTTP/2 support be planned in initial prototype or reserved for a future cycle?
