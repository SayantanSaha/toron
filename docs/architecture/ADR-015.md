# ADR-015 - Host Header Domain-Based Virtual Host Routing Architecture

## Context

Toron requires domain-based (Virtual Host) routing to dispatch incoming HTTP requests based on `Host` headers to distinct upstream target clusters or local handlers.

## Decision

1. **Host Extraction**:
   - `extractHost(req)` extracts `Host` from `req.Header.Get("Host")` or `req.Host`.
   - Strips port numbers if present (e.g. `api.toron.local:8080` $\rightarrow$ `api.toron.local`).
2. **Matching Evaluation Hierarchy**:
   - Domain + Headers + Path Prefix (highest specificity).
   - Domain + Path Prefix.
   - Catch-all (empty Host) + Headers + Path Prefix.
   - Default fallback handler (404 Not Found / 405 Method Not Allowed).
3. **Configuration Schema**:
   - `host` property in `routes.yaml` under individual proxy route definitions.

## Consequences

- **Positive**: High-performance virtual hosting and domain-based reverse proxy gateway routing on a single listening TCP port.
