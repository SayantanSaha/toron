## 2. Key Code Findings & Verifications

1. **Elimination of `DefaultMaxIdleConnsPerHost` (2) Bottleneck**:
   - `pkg/proxy/proxy.go` explicitly configures `MaxIdleConnsPerHost: 1000`, `MaxIdleConns: 10000`, and `MaxConnsPerHost: 0`.
   - Verified empirically: Socket churn dropped from ~10k reconnects/sec to near-zero reuse, tripling Toron's throughput from ~8.1k to ~24.5k RPS.
2. **Hop-by-Hop Response Header Sanitization**:
   - In `ServeHTTPWithPrefix`, upstream response headers matching RFC 7230 §6.1 `hopByHopHeaders` are stripped before assigning to `res.Header`. This prevents upstream connection close states from severing client-to-proxy keep-alive streams.
3. **Direct Upstream Dialing & Compression Bypass**:
   - `Proxy: nil` eliminates environment variable parsing and locking.
   - `DisableCompression: true` eliminates redundant decompression CPU overhead in the reverse proxy transit path.
4. **Zero-Allocation Serialization**:
   - In `pkg/httpparser/response.go`, `fmt.Fprintf` was replaced with direct string writes to `bytes.Buffer`, and `sanitizeHeader` now features a fast-path `strings.IndexByte` check, avoiding hundreds of thousands of heap allocations per second under load.
