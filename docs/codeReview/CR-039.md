   - `pkg/metrics` is updated cleanly to emit standard Prometheus text format (`toron_waf_blocked_requests_total`, `toron_waf_anomalies_detected_total`, `toron_waf_inspection_duration_seconds`).

3. **Test Coverage**:
   - Comprehensive unit tests in `metrics_test.go`, `audit_test.go`, and `middleware_test.go`.
   - 100% test pass rate across all project packages (`go test ./...`).
