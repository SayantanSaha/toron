# CR-057 - Code Review of HTTP Request Smuggling Prevention and Transfer-Encoding Guard

## Description

Engineering code review of `TASK-061` changes in `pkg/httpparser` and `pkg/server`.

## Scope

- Files reviewed:
  - `pkg/httpparser/parser.go`
  - `pkg/server/server.go`
  - `pkg/httpparser/parser_test.go`
  - `pkg/server/server_test.go`

## Key Observations & Review Findings

1. **Clean Error Hierarchy**:
   - `ErrUnsupportedTransferEncoding` is exported in `httpparser`, allowing callers to distinguish between malformed requests (`400`) and unsupported protocol features (`501`).
2. **Server Lifecycle Handling**:
   - In `pkg/server/server.go:handleConn`, `ErrUnsupportedTransferEncoding` sets `Connection: close` and `StatusNotImplemented`.
   - Returning `err` from `handleConn` guarantees the deferred `conn.Close()` executes, releasing operating system socket resources.
3. **Comprehensive Test Coverage**:
   - Unit tests verify parser-level error wrapping with `errors.Is`.
   - Integration tests verify raw TCP socket transmission, status line verification, and connection termination.
   - All tests pass cleanly (`go test -race ./...`).

## Verdict

Approved. Ready for merge and commit.
