# REQ-042 - Protocol Integrity and Request Smuggling Guard

## Description

The Toron web server and WAF subsystem shall enforce strict RFC 7230/9110 protocol integrity checks and HTTP Request Smuggling protection to guard against desynchronization attacks between edge reverse proxies and backend upstreams.

The subsystem shall provide:

1. **HTTP Request Smuggling Prevention (CL.TE / TE.CL / TE.TE Mitigation)**:
   - **Conflicting Transfer Headers**: Automatically reject requests containing both `Content-Length` and `Transfer-Encoding` headers with HTTP `400 Bad Request` (`REQ_SMUGGLING_CONFLICTING_HEADERS`).
   - **Multiple/Duplicate Content-Length Headers**: Reject requests with multiple or mismatched `Content-Length` header values.
   - **Obfuscated Transfer-Encoding**: Reject invalid or obfuscated `Transfer-Encoding` header values (e.g. `chunked, chunked`, whitespace padding before colon `Transfer-Encoding :`).
2. **Malformed Request Normalization & Control Character Guard**:
   - **Non-Printable Character Inspection**: Reject requests containing ASCII control characters (ASCII 0x00–0x1F except `\t` and ASCII 0x7F `DEL`) in URL paths, query parameters, or HTTP header names/values.
   - **Header Name Token Strictness**: Reject HTTP header keys containing invalid token characters (spaces, control chars, colons in key names).
3. **Payload Size Bounding & Per-Route Limits**:
   - **Header Size Bounding**: Enforce maximum single header value limit (`max_header_value_bytes`, default 4 KB) and maximum total header size limit (`max_header_bytes`, default 8 KB).
   - **Query & Parameter Bounding**: Enforce maximum query string byte size (`max_query_bytes`, default 4 KB) and maximum single parameter byte size (`max_param_bytes`, default 2 KB).
   - **Per-Route Request Body Bounding**: Enforce configurable `max_body_bytes` limits globally in `config.yaml` and per-route in `routes.yaml` (returning HTTP `413 Payload Too Large` when exceeded).

## Acceptance Criteria

- Requests containing both `Content-Length` and `Transfer-Encoding` headers are rejected with `400 Bad Request`.
- Requests with non-printable control characters in URL paths, query strings, or headers are rejected with `400 Bad Request`.
- Requests exceeding header, parameter, query, or body byte boundaries are rejected with `413 Payload Too Large`.
- Benign, compliant HTTP requests pass through protocol integrity inspection without status code mutation or performance degradation.
- All Go unit tests pass cleanly across all packages (`go test ./...`).
