# ADR-018 - HTTPS TLS Listener, ALPN Protocol Negotiation, and Dev Certificate Architecture

## Context

HTTPS transport encryption is required for secure web communication and standard browser HTTP/2 ALPN negotiation (`h2`).

## Decision

1. **TLS Listener Wrapper**:
   - `tls.NewListener(tcpListener, tlsConfig)` wraps the reactor's TCP listener.
   - Enforces modern TLS versions (`tls.VersionTLS12`, `tls.VersionTLS13`).
2. **ALPN Next-Protos Negotiation**:
   - Configures `NextProtos: []string{"h2", "http/1.1"}`.
   - In `handleConn`, inspects `tlsConn.ConnectionState().NegotiatedProtocol`. If `h2`, delegates connection to `http2.Server.ServeConn`.
3. **Zero-Config Development Certificates**:
   - If `auto_dev_cert: true` or cert/key paths are omitted, `pkg/server` dynamically generates an in-memory or file-backed self-signed ECDSA/RSA X.509 certificate for `localhost` / `127.0.0.1`.

## Consequences

- **Positive**: Zero-configuration local HTTPS development; production-ready TLS 1.2/1.3 security and seamless HTTP/2 ALPN.
