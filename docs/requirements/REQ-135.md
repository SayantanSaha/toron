# REQ-135 - Next-Generation High-Density Observability Dashboard and Zero-Allocation Telemetry Time-Series Engine

## 1. Description & Problem Statement

### 1.1 Background
Toron's current administrative interface at `/internal/dashboard` utilizes a basic Traefik-inspired tab layout. While functional, it lacks real-time traffic topology visualization, historical latency percentiles, error rate time-series curves, upstream health history timelines, request trace decomposition waterfalls, and runtime engine diagnostics.

A new demo dashboard specification (`toron-dashboard.html`) introduces a high-density, professional observability control plane powered by pure zero-dependency SVG graphics, an interactive Sankey traffic flow diagram, real-time request tailing, and slide-over inspector drawers.

### 1.2 Objective
Implement the new dashboard design in `public/` and enhance Toron's backend (`pkg/metrics`, `pkg/server`, `pkg/acme`) to expose live aggregated time-series telemetry, historical health probes, circular trace logs, and certificate statuses without degrading proxy data-plane throughput or introducing garbage collection pressure.

---

## 2. Functional Requirements

### 2.1 Frontend Observability Control Center (`public/`)
1. **Layout & Shell Navigation**:
   - Left-hand sticky navigation rail (`232px`), collapsible to `68px` on tablet viewports and a slide-out drawer on mobile viewports (`<760px`).
   - Top breadcrumbs bar with live timestamp, instance filter, time-range picker (`15m`, `1h`, `6h`, `24h`), Live/Pause toggle, and 3-state Theme Switcher (Light / Dark / System OS sync).
   - Right-side slide-over inspector drawer (`500px`) with modal scrim and smooth transition animation.
2. **Primary Views**:
   - **Overview**:
     - System status banner with operational badge, health summary, and quick action buttons.
     - **Interactive SVG Sankey Flow**: Ribbons showing live RPS from Listeners (`:443`, `:80`) $\to$ Routes $\to$ Upstream Pools with error-rate color coding and interactive hover highlighting.
     - **Key Signals Matrix**: 5 metric tiles (Requests/s, p95 Latency, 5xx Rate, Open Connections, Egress Mb/s) with trend sparklines and percentage delta vs. range average.
     - **Dual Time-Series Charts**: Weighted latency percentiles (p50, p95, p99) and stacked 4xx/5xx error volumes.
     - **Quick-Access Lists**: Upstream pools summary, active alerts, soonest-to-expire certificates.
   - **Routes**:
     - Sortable and filterable route table with inline sparklines, p95 latency, 5xx rate, and status pills.
     - Route inspector drawer with p95 vs. SLO reference curve, error rate chart, latency distribution histogram, timeout, and middleware tags.
   - **Upstreams**:
     - Upstream pool cards showing load balancing algorithms, health check definitions, healthy/total instance ratios.
     - Per-instance status cards with active connection counts, latency, and a **48-tick visual health check history strip**.
   - **Requests (Live Logs)**:
     - Real-time tailing log stream with search filter (path, upstream, trace ID), status code filter chips (`2xx`, `3xx`, `4xx`, `5xx`), "Over SLO" toggle, and route selector.
     - Request row click opens **Waterfall Trace Drawer** decomposing timing spans across HTTP parsing, TLS handshake, route matching, JWT verification, rate limiting, upstream connect, and response streaming.
   - **Certificates**:
     - ACME TLS certificate table showing domain, challenge type (HTTP-01, TLS-ALPN-01, DNS-01), expiry date, visual remaining time bar, and renewal status.
   - **Modules & Runtime**:
     - Compiled modules table with event throughput, queue depths, and handler latencies.
     - Go runtime metrics (Goroutines, Heap MB, GC pause p99, CPU%, Open file descriptors).
   - **Alerts**:
     - Active incidents with severity badges and direct deep-links.
     - Resolved incidents history over the last 48 hours.
   - **Interactive API Console**:
     - Integrated diagnostic debugger allowing administrators to dispatch internal HTTP test probes (`/internal/api/proxy-test`) and inspect responses.

### 2.2 Backend Telemetry & Data Plane Enhancements (`pkg/metrics`, `pkg/server`)
1. **Fixed-Size Metric Time-Series Ring Buffer**:
   - Maintain a preallocated 60-bucket rolling history in `pkg/metrics` for `rps`, `p50`, `p95`, `p99`, `4xx`, `5xx`, `cpu`, `goroutines`, `heap`, `gc_p99`, and `open_fds`.
   - Update snapshots via background ticker without acquiring locks on the hot request path.
2. **Upstream Health Probe History**:
   - Maintain a 48-sample historical bitmask/ring buffer per upstream target node.
3. **Circular Request & Trace Buffer**:
   - Maintain a preallocated in-memory circular buffer (300 items) recording recent request metadata and span timing breakdowns.
4. **Certificate & Runtime Metadata API**:
   - Enrich `/internal/api/status` with ACME certificate expiration dates, challenge states, and Go runtime stats.
5. **Security & Administrative Access Control**:
   - Preserve existing administrative authentication (`X-Toron-Admin-Key`, Bearer token, Basic auth) and CIDR subnet authorization on all `/internal/api/*` endpoints.
   - Maintain strict contextual HTML entity escaping (`escapeHTML`) on all rendered DOM fields to prevent XSS (CWE-79).

## 3. Acceptance Criteria

- [ ] `public/index.html`, `public/style.css`, and `public/app.js` render the full demo dashboard UI cleanly with zero external runtime dependencies.
- [ ] Overview Sankey flow, latency percentile charts, error charts, and signal sparklines render dynamically using pure SVG.
- [ ] Route table supports instant client-side filtering, column sorting, and opening the Route Detail Drawer.
- [ ] Upstreams view displays active instances and 48-tick health history strips.
- [ ] Requests view streams live logs with status/SLO filtering and opens the Waterfall Trace Drawer.
- [ ] `/internal/api/status` and `/internal/api/metrics` supply real-time and historical time-series data from Toron engine.
- [ ] Security audit invariants (subnet verification, admin auth, and contextual HTML escaping) are 100% preserved.
- [ ] All unit and integration tests pass with race detector clean (`go test -race -count=1 ./...`).

---

## 4. Constraints & Non-Functional Requirements

- **Zero External Runtime Dependencies**: Charting and UI must use native ES6 JavaScript and SVG; no Chart.js, D3, or npm libraries.
- **Zero GC Overhead on Hot Path**: Metric ring buffers and trace buffers must be fixed-capacity preallocated structures.
- **Sub-Millisecond Overhead**: Hot-path telemetry updates must execute in under $50\text{ ns}$ per request.
- **Security Compliance**: All user/request-derived strings must be sanitized through `escapeHTML()`.
