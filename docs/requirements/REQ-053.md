# REQ-053: Dynamic Upstream Health Matrix & Telemetry-Driven Gateway Dashboard

## Status
- **State**: APPROVED
- **Type**: Feature / Observability & Dashboard
- **Created**: 2026-09-01

## Description
Eliminate all hardcoded mock upstreams, fixed dummy ports, static route heuristics, and static dropdown items across the Toron static dashboard and internal management APIs. The dashboard must become 100% data-driven, reflecting live routes, real upstream health probes, dynamic OCI discovery, and real-time security configuration.

## Functional Requirements
1. **Dynamic Upstream Aggregator (`/internal/api/upstreams/health`)**:
   - Aggregate all active upstream target URLs configured in `routes.yaml` and discovered dynamically via OCI containers.
   - Concurrently probe all active upstream targets and report live HTTP status codes, latency in milliseconds, and circuit breaker trip states.
2. **Data-Driven Upstream Grid (`public/app.js`)**:
   - Eliminate hardcoded `UPSTREAM_SERVICES` array. Render cards purely from `/internal/api/upstreams/health`.
3. **Dynamic API Tester Dropdown**:
   - Populate testable endpoints directly from `/internal/api/routes`.
   - Automatically assign required `Host` headers when a route requires a specific virtual host.
4. **Dynamic Telemetry & Security Binding**:
   - Bind version, active OWASP rule counts, and anomaly threshold dynamically from `/internal/api/status`.
