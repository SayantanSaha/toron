# SR-048: Security Review for Dynamic Upstream Discovery & Data-Driven Dashboard

## Status
Approved

## Security Controls
- **Internal API Access Control**: `/internal/api/*` routes remain isolated to management plane requests and are excluded from external forwarding paths.
- **SSRF Defense on Health Probes**: Health probes only dispatch requests to targets explicitly declared in the server's own `routes.yaml` configuration or verified OCI container discovery providers.
- **Header Scoping**: `Host` header overrides in the interactive API tester are strictly applied to test requests and do not leak between subsequent queries.
