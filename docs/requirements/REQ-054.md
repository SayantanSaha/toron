# REQ-054: Dashboard v2.0 Redesign (Minimalist, Mobile-First, Light/Dark/System Theme Sync)

## Status
- **State**: APPROVED
- **Type**: Feature / UI & UX Redesign
- **Created**: 2026-09-01

## Description
Rework the Toron Control Center dashboard into a modern, minimalist, mobile-first administrative console built with semantic HTML5, modern Tailwind CSS, and vanilla JavaScript. The interface must support dynamic light and dark theme switching with seamless system preference synchronization.

## Functional Requirements
1. **Three-State Theme Engine**: Support `Light` (☀️), `Dark` (🌙), and `System` (💻) theme modes with automatic OS theme change detection via `window.matchMedia` and persistence in `localStorage`.
2. **Mobile-First Responsive Layout**: Optimized for mobile devices (single-column card stacks, horizontal touch-scrolling tab pill bar, touch targets >= 44px) scaling gracefully up to desktop 4K viewports.
3. **Route Search & Filtering**: Client-side instant search input to filter active routes by path prefix, host, or container name in real time.
4. **Live Data & Telemetry Integration**: Zero mock data. Render dynamic upstream nodes with health state, latency in milliseconds, live WAF incidents, and Prometheus metrics links.
5. **Interactive API Test Console**: Upgraded test console supporting HTTP methods (GET, POST, PUT, DELETE), custom headers, and formatted JSON response viewer with one-click clipboard copy.
