# SR-017 - Security Review of HTTP/2 Protocol Support and Frame Handling

## Scope

Security assessment of HTTP/2 protocol detection (`PRI * HTTP/2.0...`), stream limit enforcement, and frame size bounds in `pkg/server/server.go`.

## Findings

1. **Stream Limit & Frame Bounds**: Enforces `HTTP2MaxConcurrentStreams` (default 250) and `HTTP2MaxFrameSize` (default 16 KB) to prevent HTTP/2 Rapid Reset (CVE-2023-44487) and stream exhaustion DoS vectors.
2. **Safe Fallback**: Non-HTTP/2 connection initial bytes are preserved in a replay buffer (`prefixConn`) and passed safely to the HTTP/1.1 parser without data corruption or loss.

## Conclusion

Approved. No security vulnerabilities identified.
