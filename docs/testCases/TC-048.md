# TC-048 - Test Suite for Service Mesh Sidecar Mode

## Test Objectives

Verify that `pkg/sidecar` accurately enforces pod-to-pod mTLS certificate handshakes, distributes canary traffic according to integer weights (80/20 ratio), and proxies ingress/egress requests cleanly.

## Test Cases Executed

1. **`TestWeightedTrafficSplitter`**:
   - Verify that 1,000 requests distributed across 80% v1 / 20% v2 backends produce an exact ~800 / ~200 traffic split.
2. **`TestmTLSConfigGenerator`**:
   - Verify TLS config generation with root CA cert pools and strict client certificate verification.
3. **`TestSidecarProxyIngressEgress`**:
   - Spin up local test servers, establish mTLS sidecar connection, and verify HTTP payload delivery.
4. **Race Detector Validation**:
   - Run `go test -v -race ./pkg/sidecar/...`
