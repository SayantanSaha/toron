# TC-076 - Verification of Bounded Request Body Ingestion in HTTP/2 Ingress

## Objective

Verify that `http2AdapterHandler` bounds incoming request bodies to `s.config.MaxBodyBytes` and responds with `HTTP 413 Payload Too Large` when an oversized HTTP/2 payload is received.

## Test Cases

### TC-076-01: Compliant HTTP/2 Request Body Ingestion
- **Setup**: Start HTTP/2 server with `MaxBodyBytes: 1048576` (1MB).
- **Action**: Client sends HTTP/2 POST request with 512KB payload.
- **Expected Outcome**:
  - Request body is completely received.
  - Handler processes and routes request normally with HTTP 200 OK.

### TC-076-02: Oversized HTTP/2 Request Body Rejection
- **Setup**: Server with `MaxBodyBytes: 65536` (64KB).
- **Action**: Client sends HTTP/2 POST request with 128KB payload.
- **Expected Outcome**:
  - Server immediately halts body reading.
  - Response returns `413 Payload Too Large`.
  - Process memory remains bounded without excessive heap growth.
