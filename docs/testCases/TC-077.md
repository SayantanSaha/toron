# TC-077 - Verification of Non-Blocking Reactor Connection Dispatch

## Objective

Verify that the TCP reactor accepts and services concurrent connections even when multiple HTTP/1.1 connections remain open and idle across persistent keep-alive periods.

## Test Cases

### TC-077-01: High Idle Connection Concurrency
- **Setup**: Start reactor with `WorkerPoolSize: 10` and `IdleTimeout: 5s`.
- **Action**: Open 20 concurrent TCP connections and transmit valid HTTP/1.1 requests with `Connection: keep-alive`, leaving them idle.
- **Expected Outcome**:
  - All 20 initial connections receive valid responses.
  - Connection 21 connects immediately and receives an instant response without waiting for idle timeout on earlier connections.

### TC-077-02: Graceful Shutdown with Active Keep-Alive
- **Setup**: Active keep-alive connections connected.
- **Action**: Trigger `reactor.Shutdown(ctx)`.
- **Expected Outcome**:
  - Active connections are terminated cleanly.
  - Shutdown returns with zero goroutine leaks.
