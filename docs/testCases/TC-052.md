# TC-052: Test Cases for Prefix Management & Redirect/Cookie Rewriting

## Test Cases

### TC-052.1: `X-Forwarded-Prefix` & Relative 302 Redirect Rewriting
- **Action**: Send `GET /api/dashboard` to a proxy route with `prefix: "/api"`. Upstream returns `302 Found` with `Location: /login?ref=dashboard` and `Set-Cookie: session=abc; Path=/; HttpOnly`.
- **Expected**:
  - Upstream receives `X-Forwarded-Prefix: /api`.
  - Response `Location` is rewritten to `/api/login?ref=dashboard`.
  - Response `Set-Cookie` is rewritten to `session=abc; Path=/api; HttpOnly`.

### TC-052.2: Absolute Internal Target URL Rewriting
- **Action**: Upstream returns `301 Moved Permanently` with `Location: http://127.0.0.1:9001/auth/callback`. Client request has `Host: gateway.example.com` and `X-Forwarded-Proto: https`.
- **Expected**: Response `Location` is rewritten to `https://gateway.example.com/services/legacy/auth/callback`.

### TC-052.3: External Third-Party Redirect Preservation
- **Action**: Upstream returns `307 Temporary Redirect` with `Location: https://accounts.google.com/o/oauth2/v2/auth?client_id=123`.
- **Expected**: External `Location` URL is preserved completely untouched.

### TC-052.4: `strip_prefix: false` Full Path Passthrough
- **Action**: Send `GET /api/v1/users` to route with `strip_prefix: false`.
- **Expected**: Upstream backend receives the unstripped path `/api/v1/users`.

### TC-052.5: `rewrite_redirects: false` Passthrough
- **Action**: Send request to route with `rewrite_redirects: false`. Upstream returns `Location: /raw-backend-path`.
- **Expected**: Response `Location` remains `/raw-backend-path` without prefix modification.
