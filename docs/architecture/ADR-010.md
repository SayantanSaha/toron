# ADR-010 - Interactive REST Client HTTP Test Specification Architecture

## Context

Developers and QA engineers need a standardized, version-controlled file format for testing all Toron HTTP server endpoints interactively within IDEs (VS Code, Antigravity, JetBrains).

## Decision

1. **File Standard**: Use RFC 2616 standard HTTP file format (`test_endpoint.http`) placed at repository root.
2. **Variable Parameterization**: Define `@baseUrl = http://localhost:8080` for easy target switching.
3. **Coverage Scope**:
   - Section 1: Health & Engine Status
   - Section 2: Static Website Assets
   - Section 3: Header-Based Reverse Proxy Routing (v2 Load-Balanced & v1 Single)
   - Section 4: Path-Based Reverse Proxy Routing (Cluster Load-Balanced, Auth Single, Analytics Load-Balanced)
   - Section 5: HTTP Method Dispatching (POST payloads)

## Consequences

- **Positive**: Provides reproducible, one-click manual and automated integration test specifications.
