# TC-007 - Configuration Loader & YAML Parsing Verification

## Description

Verify that `pkg/config` correctly parses valid YAML configuration files, merges values into domain `Config` objects, applies default fallbacks for unspecified fields, and handles invalid syntax gracefully.

## Preconditions

- Temporary test YAML files written.

## Test Data

- Valid YAML file with custom port `9090` and worker pool `256`.
- Missing fields YAML file.
- Invalid syntax YAML file.

## Steps

1. Call `config.LoadFromFile(validYamlPath)` -> Verify port is `9090` and worker pool is `256`.
2. Call `config.LoadFromFile(missingFieldsYamlPath)` -> Verify missing fields take default values.
3. Call `config.LoadFromFile(invalidYamlPath)` -> Verify explicit parsing error returned.

## Expected Results

- Config loader parses valid YAML and falls back to safe defaults.

## Acceptance Criteria

- All unit tests in `pkg/config` pass.

## Rationale

Ensures robust configuration loading.

## Constraints

- Table-driven unit tests in `pkg/config`.

- None.
