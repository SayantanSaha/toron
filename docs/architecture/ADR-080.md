# ADR-080 - Kubernetes Ingress Route Scoping and Sensitive Endpoint Boundary Protection Architecture

## Context

In multi-tenant Kubernetes clusters, developers deploy Ingress resources within their designated namespaces. If the Ingress controller allows unhosted catch-all root (`host: ""` + `path: "/"`) or sensitive administrative prefixes (`/internal`, `/api/status`), any tenant can hijack the gateway's global ingress traffic or shadow internal management APIs. While container auto-discovery (`pkg/discovery/parser.go`) was hardened in `TASK-079`, `pkg/ingress/translator.go` remained unconstrained.

## Decision

1. **Path Canonicalization Layer (`path.Clean`)**:
   - Clean every incoming `pathRule.Path` with `path.Clean(prefix)` prior to matching or prefix registration.
   - Prevents bypasses using dot-segments (`/foo/../internal`) or double-slashes (`//internal`).

2. **Unhosted Root Prohibition**:
   - Ingress rules mapping to `/` or empty prefix with `host == ""` MUST be rejected.
   - A specific FQDN host (e.g. `web.company.com`) is mandatory for root prefix mapping.

3. **Strict System Prefix Exclusions**:
   - The `/internal` namespace is reserved for Toron Web Control Center, metrics, and security audit APIs.
   - The `/api/status` namespace is reserved for core gateway telemetry.
   - All rules targeting `/internal`, `/internal/*`, `/api/status`, `/api/status/*` are rejected unconditionally.
   - Unhosted (`host == ""`) rules targeting `/health` and `/metrics` are rejected to preserve core cluster probes.

4. **Rule-Level Error Isolation**:
   - Rejections occur at the rule level, skipping the invalid path while continuing to translate other valid paths within the same Ingress resource.

## Consequences

- **Positive**: Complete elimination of SEC-24 route hijacking and administrative shadowing.
- **Positive**: Multi-tenant isolation enforced against rogue Ingress declarations.
- **Positive**: Zero performance overhead on hot routing paths.
- **Negative**: Tenants attempting to expose `/` without a host must provide a specific domain name.
