# TC-044 - WAF Telemetry, Prometheus Metrics, and Security Audit Logging Verification

## Test Objectives

1. **Prometheus WAF Block Counters**: Verify `toron_waf_blocked_requests_total` increments when an attack (SQLi, XSS, Path Traversal, RCE, Protocol, IP ACL) is blocked, properly tagged with `category` and `route`.
2. **Prometheus WAF Anomaly Counters**: Verify `toron_waf_anomalies_detected_total` increments in `detection` mode.
3. **Prometheus WAF Duration Histogram**: Verify `toron_waf_inspection_duration_seconds` records bucket counts and total observations during inspection.
4. **Structured JSON Audit Logging**: Verify security events emit valid JSON entries with `timestamp`, `event`, `client_ip`, `method`, `path`, `category`, `rule_id`, `anomaly_score`, `action`, `location`, and `payload_snippet`.
5. **File Sink Writing**: Verify writing security audit entries to a designated log file path.
6. **Prometheus Text Format Output**: Verify `/metrics` endpoint exports all new WAF metrics adhering to standard Prometheus exposition syntax.

## Executed Tests

- `TestMetrics_WAFTelemetry` in `pkg/metrics/metrics_test.go`.
