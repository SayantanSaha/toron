# SR-037 - Security Review of Protocol Integrity and Request Smuggling Guard (Prototype 32)

## Summary

A security audit of `ValidateProtocolIntegrity` in `pkg/waf/protocol.go` and parser-level smuggling rejection in `pkg/httpparser/parser.go` was conducted.

## Audit Findings & Security Protections

1. **HTTP Request Smuggling (CL.TE / TE.CL / TE.TE Mitigation)**:
   - Evaluated dual-layer enforcement: Parser-level rejection in `pkg/httpparser/parser.go` and WAF-level rejection in `pkg/waf/protocol.go`.
   - Any request declaring both `Content-Length` and `Transfer-Encoding` is immediately aborted with `400 Bad Request`. Mismatched multiple `Content-Length` headers are similarly rejected.
2. **Malformed Control Character Guard**:
   - URL paths, query parameters, and header keys/values are scanned for non-printable ASCII control characters (`0x00–0x1F` except `\t`, and `0x7F DEL`).
   - Prevents CRLF header injection (`\r\n`), null-byte truncation attacks (`\x00`), and terminal sequence manipulation.
3. **Payload Size & Boundary Protections**:
   - Individual header values capped at `MaxHeaderValue` (default 4 KB).
   - URI query strings capped at `MaxQuerySize` (default 4 KB) and individual query parameters at `MaxParamSize` (default 2 KB).
   - Prevents RAM exhaustion and CPU-bound parsing attacks from malicious oversized parameters.

## Conclusion

The Protocol Integrity and Request Smuggling Guard meets all RFC 7230/9110 security requirements and is approved for production deployment.
