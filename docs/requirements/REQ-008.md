# REQ-008 - Native Go Benchmarking Suite for Throughput and Allocation Tracking

## Description

The Toron codebase shall include native Go benchmarks (`func BenchmarkXxx(b *testing.B)`) for measuring throughput (ns/op) and memory allocations (B/op, allocs/op) across the reactor engine, HTTP parser, router, and end-to-end server stack.

## Acceptance Criteria

- Native Go benchmark functions added to `pkg/reactor`, `pkg/httpparser`, `pkg/router`, and `pkg/server`.
- Includes `b.ReportAllocs()` in all benchmarks to measure memory allocations per operation.
- Supports running via standard Go command: `go test -bench=. ./...`.
- Benchmarks test HTTP request parsing, response serialization, route matching, and concurrent connection handling under load.

## Rationale

Ensures Toron maintains low-latency, zero-leak, high-throughput performance across software iterations, fulfilling the primary performance objective in `PRD.md`.

## Constraints

- Pure Go `testing.B` benchmarks without third-party framework dependencies.
